   60: =head1 DESCRIPTION
   61: 
   62: Every backend in C<Geo::Coder::Free> has the same problem: an address that is
   63: not in its data is not found on every call, and each call pays for the whole
   64: search again.  C<Geo::Coder::Free::MissCache> is the one place where the
   65: backends record those misses, so the process remembers the absence once and
   66: every later call - through any instance of any backend - answers without
   67: touching a database.
   68: 
   69: Entries are held in memory, in the process, and are not shared between
   70: processes.  They expire after an hour by default.  That is long enough to
   71: spare a batch, a web request or a test run the repeated work, and short enough
   72: that a process which stays up after its data is rebuilt does not keep
   73: answering from a stale memory forever; C<Geo::Coder::Free->clear_miss_cache()>
   74: empties the cache at once for that case.  Expired entries are discarded when
   75: they are next asked about, and a sweep runs at most once a minute as new
   76: misses are recorded.  A scope that reaches 100,000 live misses forgets them and
   77: starts again, so the cache does not grow without bound.
   78: 
   79: A miss is only ever remembered, never inferred: nothing here decides that an
   80: answer will be missing, it only stores that a backend has already found that
   81: it is.

   86:

   88: 
   89: Builds the name a backend stores its misses under.  The parts are joined with

  305: =head2 expires_after
  306: 
  307:     my $seconds = Geo::Coder::Free::MissCache->expires_after();
  308:     Geo::Coder::Free::MissCache->expires_after(600);
  309: 
  310: How long a remembered miss lasts, in seconds.  Without an argument it answers
  311: with the current setting, which is one hour.  Setting it to 0 makes every miss
  312: expire as soon as it is recorded, which turns the cache off.  It is a setting

  316: anything that is not a number croaks
