   48: =head1 DESCRIPTION
   49: 
   50: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
   51: using local SQLite databases built from free data sources - MaxMind/GeoNames,
   52: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
   53: database.  It deliberately avoids paid or rate-limited online geocoding services.
   54: The module is designed to be flexible, supporting both command-line and programmatic usage.
   55: It also includes a sample CGI script for a web-based geocoding service.
   56: 
   57: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
   58: 
   59: B<With OpenAddresses data:>
   60: 
   61: =over 4
   62: 
   63: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
   64: 
   65: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
   66: 
   67: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
   68: 
   69: =back
   70: 
   71: B<Without OpenAddresses data:>
   72: 
   73: =over 4
   74: 
   75: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
   76: 
   77: =back
   78: 
   79: The C<cgi-bin> directory contains a simple DIY geo-coding website:
   80: 
   81:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
   82: 
   83: The sample website is currently down while a new host is sought.
   84: When it returns, you will be able to test it with:
   85: 
   86:     curl 'https://geocode.nigelhorne.com/cgi-bin/page.fcgi?page=query&q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA'
   87: 
   88: =head1 LIMITATIONS
   89: 
   90: =over 4
   91: 
   92: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
   93: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
   94: 
   95: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
   96: user-editable config file.
   97: 
   98: =item * The address-regex scantext path misses birth-year sentences such as
   99: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  100: a preceding capital-letter word directly before the city.
  101: 
  102: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  103: not return meaningful results.
  104: 
  105: =item * The C<alternatives> map loop uses C<each %{$alt}>, which retains its
  106: iterator position across calls.  After a successful match and early C<return>,
  107: the next C<geocode()> call on the same input starts iterating from the key
  108: B<after> the matched one, potentially missing the match entirely until C<each>
  109: wraps around.  Workaround: call C<keys %{$alt}> once to reset the iterator
  110: before iterating.
  111: 
  112: =back
  113:

  255: =head2 valid_location
  256: 
  257: =head3 SYNOPSIS
  258: 
  259:     if ($geo->valid_location($row->{'place'})) {
  260:         push @found, $geo->geocode(location => $row->{'place'});
  261:     }
  262: 
  263: =head3 DESCRIPTION
  264: 
  265: Answers whether a string is something this module will even try to look up.
  266: It is the public form of the rule C<geocode()> applies before it touches a
  267: backend, so a caller working down a spreadsheet column can skip a row whose
  268: value is a bare number - or is empty - instead of catching the croak that
  269: would otherwise kill the whole run.
  270: 
  271: Only that cheap syntactic test is answered.  A true result means the string is
  272: not disqualified, B<not> that a backend knows it: C<'Ramsgate, Kent'> is valid
  273: and may still find nothing, while C<'0044'> is invalid and is never looked up.
  274: The rule rejects a string of digits only, which is what a numeric column holds
  275: when the wrong column has been read, so anything with a non-digit in it counts
  276: as valid - C<'3.14'> and C<'-'> included.  C<undef>, C<''> and a reference are
  277: not valid.
  278: 
  279: =head3 API SPECIFICATION
  280: 
  281: =head4 input
  282: 
  283:     location => { type => 'scalar', optional => 1 }  # the string to test
  284: 
  285: =head4 output
  286: 
  287:     { type => 'boolean' }  # false for undef, '' and a digit-only string
  288: 
  289: =head3 EXAMPLE
  290: 
  291:     my $geo = Geo::Coder::Free->new();
  292: 
  293:     $geo->valid_location('Ramsgate, Kent');   # true
  294:     $geo->valid_location('0044');             # false - never a location
  295:     $geo->valid_location('');                 # false
  296:     $geo->valid_location(undef);              # false
  297: 
  298: Accepts the three calling conventions the rest of this module does:
  299: 
  300:     $geo->valid_location('0044');
  301:     Geo::Coder::Free->valid_location('0044');
  302:     Geo::Coder::Free::valid_location('0044');
  303: 
  304: =cut

  306: sub valid_location {
  307: 	my $self = shift;
  308: 
  309: 	# The location is whichever argument is not the invocant, so that the
  310: 	# predicate reads the same whether it is called on an instance, on the
  311: 	# class or as a plain function.
  312: 	my $location;
  313: 	if (ref($self)) {
  314: 		$location = shift;
  315: 	} elsif (@_) {
  316: 		$location = shift;
  317: 	} elsif (defined($self) && $self ne __PACKAGE__) {
  318: 		$location = $self;
  319: 	}
  320: 
  321: 	return _valid_location($location) ? 1 : 0;
  322: }

  324: =head2 geocode
  325: 
  326: =head3 SYNOPSIS
  327: 
  328:     # Standard lookup (returns a Geo::Location::Point or undef)
  329:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  330:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  331: 
  332:     # Scantext - returns a list of Geo::Location::Point objects
  333:     my @hits = $geo->geocode(
  334:         scantext     => 'She lived in Ramsgate, Kent.',
  335:         region       => 'GB',
  336:         ignore_words => [qw(lived)],
  337:     );
  338: 
  339:     # Invocation flexibility (all equivalent)
  340:     $geo->geocode('Ramsgate, Kent, UK');
  341:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  342:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  343: 
  344:     # A batch caller with a dirty column: skip the row, do not kill the run
  345:     for my $place (@column) {
  346:         my $pt = $geo->geocode(location => $place, on_error => 'undef');
  347:         next unless defined $pt;
  348:         push @found, $pt;
  349:     }
  350: 
  351: =head3 DESCRIPTION
  352: 
  353: A location or a scantext that is not a location at all - a bare number, such as
  354: the C<0044> a numeric column holds - is refused before any backend is
  355: touched.  C<valid_location()> answers the same question, so a caller can filter
  356: first; C<on_error> chooses what happens when one gets through anyway:
  357: 
  358: =over 4
  359: 
  360: =item * C<'croak'> (the default) - C<Carp::croak>, the behaviour every existing
  361: caller already has.
  362: 
  363: =item * C<'undef'> - return C<undef>, so one bad row in a spreadsheet column is
  364: skipped rather than ending the run.  It changes the answer for B<only> the two
  365: documented input errors below; an exception from a backend is still an
  366: exception, and a malformed argument list still croaks.
  367: 
  368: =back
  369: 
  370: The option is deliberately narrow, so a batch caller wants C<valid_location()>
  371: with it: that predicate answers false for C<undef> and C<''> as well, which are
  372: the other two things an empty cell holds.  A call with neither a location nor a
  373: scantext is a usage error rather than an input error - the same croak as calling
  374: C<geocode()> with no arguments - and stays a croak on either setting.
  375: 
  376: =head3 API SPECIFICATION
  377: 
  378: =head4 input
  379: 
  380:     # Input schema (Params::Validate::Strict) - exactly one of location or scantext is required
  381:     location     => { type => 'scalar',   optional => 1 }  # address string (exclusive with scantext)
  382:     scantext     => { type => 'scalar',   optional => 1 }  # free text to scan for place names
  383:     region       => { type => 'scalar',   optional => 1 }  # ISO 3166-1 alpha-2 country code hint
  384:     ignore_words => { type => 'arrayref', optional => 1 }  # words to suppress during scantext scan
  385:     on_error     => { type => 'scalar',   optional => 1 }  # 'croak' (default) or 'undef'
  386: 
  387: =head4 output
  388: 
  389:     # Output schema (Return::Set)
  390:     # scalar context: { type => 'object',   isa => 'Geo::Location::Point', optional => 1 }
  391:     # list context:   { type => 'arrayref', of  => { isa => 'Geo::Location::Point' } }
  392: 
  393: =head4 provenance
  394: 
  395: Every result carries C<geocoder>, C<database>, C<confidence> and C<accuracy>
  396: (section 2.1 of F<BI-Phase6-Dependency-Specs.md>): which distribution produced
  397: it, which backend answered, how good the match was, and how precise the
  398: coordinate is.  C<provenance()> reads the four back.  C<location> is set by every
  399: path but the MaxMind cities one, and C<text> only by a scantext lookup; C<lat>,
  400: C<long> and C<lng> come from the value object itself.
  401: 
  402: =head3 MESSAGES
  403: 
  404:     Usage: ...::geocode(...)        No location or scantext argument given.
  405:     invalid location to geocode()   location is purely numeric.
  406:     invalid scantext to geocode()   scantext is purely numeric.
  407:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  408: 
  409: =head3 PSEUDOCODE
  410: 
  411:     if self is not a blessed object → delegate to new()->geocode(@args)
  412:     normalise @_ into %params
  413:     validate: on_error is 'croak' or 'undef' (croak if not)
  414:     validate: location is not purely numeric; scantext is not purely numeric
  415:               (undef instead of croaking when on_error is 'undef')
  416:     if openaddr backend is available:
  417:         if scantext:
  418:             try the raw scantext string as a direct location
  419:             build stopword set from %_COMMON_WORDS + ignore_words param
  420:             try 3-word windows (triplets) at confidence 0.8
  421:             try 2-word windows (duplets) at confidence 0.7
  422:             try the address-pattern regex at confidence 0.7
  423:             try region-specific address finders (GB / US / CA)
  424:             mark scantext as a miss; return undef
  425:         else:
  426:             try openaddr backend
  427:             try local backend
  428:             try __DATA__ alternatives map
  429:     try maxmind backend for location lookups
  430:     croak if no scantext and no location
  431: 
  432: =cut

  434: sub geocode {
  435: 	my $self = shift;
  436: 
  437: 	# Handle being called as a function rather than a method
  438: 	if (!ref($self)) {
  439: 		if (scalar @_) {
  440: 			return __PACKAGE__->new()->geocode(@_);
  441: 		} elsif (!defined($self)) {
  442: 			Carp::croak(_i18n('usage_geocode', __PACKAGE__));
  443: 		} elsif ($self eq __PACKAGE__) {
  444: 			Carp::croak(_i18n('usage_geocode', $self));
  445: 		}
  446: 		return __PACKAGE__->new()->geocode($self);
  447: 	} elsif (ref($self) eq 'HASH') {
  448: 		return __PACKAGE__->new()->geocode($self);
  449: 	}
  450: 
  451: 	my %params = _normalize_args(_i18n('usage_geocode', __PACKAGE__), 'location', @_);
  452: 
  453: 	# What to do with an input this module rejects before it touches a backend.
  454: 	# 'croak' is the historical behaviour and stays the default, so no existing
  455: 	# caller changes; 'undef' is for a batch caller working down a dirty column,
  456: 	# which wants the row skipped rather than the whole run killed.  Only the two
  457: 	# input errors below consult it: a backend that throws still throws, because
  458: 	# nothing here is wrapped in an eval (section 2.4 of
  459: 	# BI-Phase6-Dependency-Specs.md).
  460: 	my $on_error = $params{'on_error'} // 'croak';
  461: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  462: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  463: 
  464: 	# Reject pure-numeric inputs early — they are never valid addresses.
  465: 	# valid_location() answers the same question, so a caller can pre-filter
  466: 	# with it and never reach this croak at all.
  467: 	if (defined($params{'location'}) && !_valid_location($params{'location'})) {
  468: 		return if !length($params{'location'}) || ($on_error eq 'undef');
  469: 		Carp::croak(_i18n('invalid_location', __PACKAGE__, $params{'location'}));
  470: 	}
  471: 	if (defined($params{'scantext'}) && !_valid_location($params{'scantext'})) {
  472: 		return if !length($params{'scantext'}) || ($on_error eq 'undef');
  473: 		Carp::croak(_i18n('invalid_scantext', __PACKAGE__, $params{'scantext'}));
  474: 	}
  475: 
  476: 	if ($self->{'openaddr'}) {
  477: 		if (my $scantext = $params{'scantext'}) {
  478: 			return if $self->{'scantext_misses'}{$scantext};
  479: 
  480: 			# First try the whole scantext as a direct location lookup —
  481: 			# saves work when the text happens to be a valid address string.
  482: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  483: 			my @direct = grep { defined }
  484: 				$self->{'local'}->geocode($scantext),
  485: 				$self->{'openaddr'}->geocode($scantext),
  486: 				$self->{'maxmind'}->geocode($scantext);
  487: 			return @direct if @direct;
  488: 
  489: 			my $region = $params{'region'};
  490: 
  491: 			# Build the effective stopword set.  When the caller supplies no
  492: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  493: 			# at runtime) by using a reference to it directly.  Only when extra
  494: 			# words are needed do we allocate and populate a merged hash.
  495: 			my $ignore_words;
  496: 			if (my $iw = $params{'ignore_words'}) {
  497: 				my %merged = %_COMMON_WORDS;
  498: 				$merged{lc $_} = 1 for @{$iw};
  499: 				$ignore_words = \%merged;
  500: 			} else {
  501: 				$ignore_words = \%_COMMON_WORDS;
  502: 			}
  503: 
  504: 			my @rc;
  505: 
  506: 			# 3-word window search
  507: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  508: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  509: 			if (@{$res}) {
  510: 				return wantarray ? @{$res} : $res->[0];
  511: 			}
  512: 
  513: 			# 2-word window search
  514: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  515: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  516: 			if (@{$res}) {
  517: 				return wantarray ? @{$res} : $res->[0];
  518: 			}
  519: 
  520: 			# Regex-based address pattern — catches "City, ST"-style fragments.
  521: 			# Note: misses sentences like "born May 21, 1937 in Noblesville, IN"
  522: 			# because the pattern requires a capitalised word before the city.
  523: 			my @regex_matches = $scantext =~
  524: 				/\b(?:\d+\s+)?(?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*\.?),\s*
  525: 				 (?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*(?:,\s*[A-Z]{2,})*)\b/gx;
  526: 			my @places = grep { defined && $_ ne '' } @regex_matches;
  527: 			$res = $self->_resolve_scan_candidates(\@places, $region, $CONF_REGEX, $scantext);
  528: 			if (@{$res}) {
  529: 				return wantarray ? @{$res} : $res->[0];
  530: 			}
  531: 
  532: 			# Region-specific structured address patterns
  533: 			if ($region) {
  534: 				my @candidates;
  535: 				if    ($region eq 'GB') { @candidates = _find_gb_addresses($scantext) }
  536: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  537: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }
  538: 
  539: 				if (@candidates) {
  540: 					my @regional;
  541: 					for my $candidate (@candidates) {
  542: 						next if $ignore_words->{lc $candidate};
  543: 						my @hits = grep { defined }
  544: 							$self->{'openaddr'}->geocode("$candidate, $region");
  545: 						push @regional, @hits if @hits;
  546: 					}
  547: 					return @regional if @regional;
  548: 				}
  549: 			}
  550: 
  551: 			$self->{'scantext_misses'}{$scantext} = 1;
  552: 			return;
  553: 		}
  554: 
  555: 		# Standard (non-scantext) lookup path
  556: 		if (wantarray) {
  557: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  558: 			return @rc if @rc && $rc[0];
  559: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  560: 			@rc = $self->{'local'}->geocode(\%params);
  561: 			return @rc if @rc && $rc[0];
  562: 		} else {
  563: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  564: 				return $rc;
  565: 			}
  566: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  567: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  568: 				return $rc;
  569: 			}
  570: 		}
  571: 
  572: 		# Try the alternatives table — hand-curated mappings for locations that
  573: 		# the databases have under slightly different names.
  574: 		# M3 (transitive reduction): every scantext path inside this block returned
  575: 		# early above; at this point $params{'scantext'} is provably falsy, so the
  576: 		# former `if (!$params{'scantext'})` guard was a tautology — removed.
  577: 		if (my $alt = $self->{'alternatives'}) {
  578: 			my $location = $params{'location'};
  579: 			while (my ($key, $value) = each %{$alt}) {
  580: 				next unless $location =~ $key;
  581: 				(my $new_loc = $location) =~ s/$key/$value/;
  582: 				$params{'location'} = $new_loc;
  583: 				if (my $rc = $self->geocode(\%params)) {
  584: 					return $rc;
  585: 				}
  586: 				# Also try the comma-free variant ("Tyne and Wear" etc.)
  587: 				if ($value =~ /, /) {
  588: 					(my $flat = $value) =~ s/,//g;
  589: 					($new_loc = $location) =~ s/$key/$flat/;
  590: 					$params{'location'} = $new_loc;
  591: 					if (my $rc = $self->geocode(\%params)) {
  592: 						return $rc;
  593: 					}
  594: 				}
  595: 				# Restore for the next iteration
  596: 				$params{'location'} = $location;
  597: 			}
  598: 		}
  599: 	}
  600: 
  601: 	# Final fallback: MaxMind for location lookups.
  602: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;
  603: 	# a proper fix would warn here (see LIMITATIONS).
  604: 	# M8 (tautology elimination): both arms of the former wantarray ternary were
  605: 	# identical — collapsed to a single call; context propagates implicitly.
  606: 	if ($params{'location'}) {
  607: 		return $self->{'maxmind'}->geocode(\%params);
  608: 	}
  609: 
  610: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  611: 	return;
  612: }

  614: =head2 provenance
  615: 
  616:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
  617: 
  618: or, in scalar context, the same four as a hashref:
  619: 
  620:     my $provenance = $geocoder->provenance($point);
  621:     print $provenance->{'backend'};
  622: 
  623: Where a result came from and how good it is, so that a caller does not have to
  624: reach for the hash keys itself (section 2.1 of F<BI-Phase6-Dependency-Specs.md>):
  625: 
  626: =over 4
  627: 
  628: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
  629: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
  630: that passed it on, such as C<Geo::Coder::List>.
  631: 
  632: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
  633: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
  634: the distribution's prefix removed, so that the two spellings the backends use -
  635: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
  636: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
  637: consumers that already match on it.
  638: 
  639: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
  640: 
  641: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
  642: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
  643: 
  644: =back
  645: 
  646: Returns an empty list - and an empty hashref in scalar context - when handed
  647: something that is not a result.  A key a result does not carry comes back
  648: C<undef> rather than being guessed at, because a plain hash from another
  649: geocoder has no provenance to report.
  650: 
  651: =cut
  652: 
  653: sub provenance {
  654: 	my ($self, $point) = @_;
  655: 
  656: 	return wantarray ? () : {} unless defined($point) && ref($point)
  657: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
  658: 
  659: 	my $dist    = $point->{'geocoder'};
  660: 	my $backend = $point->{'database'};
  661: 	$backend =~ s/^Geo::Coder::Free::// if defined($backend);
  662: 
  663: 	my %provenance = (
  664: 		dist       => $dist,
  665: 		backend    => $backend,
  666: 		confidence => $point->{'confidence'},
  667: 		accuracy   => $point->{'accuracy'},
  668: 	);
  669: 
  670: 	return wantarray ? @provenance{qw(dist backend confidence accuracy)} : \%provenance;
  671: }

  673: =head2 reverse_geocode
  674: 
  675: =head3 SYNOPSIS
  676: 
  677:     my $loc = $geo->reverse_geocode(latlng => '51.3341,-1.4159');
  678: 
  679: =head3 DESCRIPTION
  680: 
  681: Translates a latitude/longitude pair back to a place name.
  682: B<Partially implemented>: the MaxMind backend does not return meaningful results.
  683: OpenAddresses is attempted first when available.
  684: 
  685: =head3 API SPECIFICATION
  686: 
  687: =head4 input
  688: 
  689:     # Input schema (Params::Validate::Strict) — latlng required
  690:     latlng => { type => 'scalar' }  # "$lat,$long" comma-separated decimal degrees
  691:     # NOTE: separate lat/lon/long keys are NOT supported at the Geo::Coder::Free
  692:     # (facade) level.  When no OpenAddresses backend is configured, passing
  693:     # lat/lon/long instead of latlng will croak "not yet supported".
  694:     # To use separate coordinates call Geo::Coder::Free::Local::reverse_geocode.
  695: 
  696: =head4 output
  697: 
  698:     # Output schema (Return::Set)
  699:     { type => 'object', isa => 'Geo::Location::Point', optional => 1 }
  700: 
  701: =cut
  702: 
  703: sub reverse_geocode {
  704: 	my $self = shift;
  705: 
  706: 	if (!ref($self)) {
  707: 		if (scalar @_) {
  708: 			return __PACKAGE__->new()->reverse_geocode(@_);
  709: 		} elsif (!defined($self)) {
  710: 			Carp::croak(_i18n('usage_reverse', __PACKAGE__));
  711: 		} elsif ($self eq __PACKAGE__) {
  712: 			Carp::croak(_i18n('usage_reverse', $self));
  713: 		}
  714: 		return __PACKAGE__->new()->reverse_geocode($self);
  715: 	} elsif (ref($self) eq 'HASH') {
  716: 		return __PACKAGE__->new()->reverse_geocode($self);
  717: 	}
  718: 
  719: 	my %params = _normalize_args(_i18n('usage_reverse', __PACKAGE__), 'latlng', @_);
  720: 
  721: 	# M8 (tautology — same pattern fixed in geocode): both arms are identical;
  722: 	# context propagates implicitly through return.
  723: 	if ($self->{'openaddr'}) {
  724: 		return $self->{'openaddr'}->reverse_geocode(\%params);
  725: 	}
  726: 	if ($params{'latlng'}) {
  727: 		return $self->{'maxmind'}->reverse_geocode(\%params);
  728: 	}
  729: 
  730: 	Carp::croak(_i18n('reverse_unsupported'));
  731: }

  751: sub run {
  752: 	require Data::Dumper;
  753: 
  754: 	my $class    = shift;
  755: 	my $location = join ' ', @_;
  756: 
  757: 	my @rc = $ENV{'OPENADDR_HOME'}
  758: 		? $class->new(openaddr => $ENV{'OPENADDR_HOME'})->geocode($location)
  759: 		: $class->new()->geocode($location);
  760: 
  761: 	Carp::croak(_i18n('geocoding_failed', $0)) unless @rc;
  762: 
  763: 	print Data::Dumper->new([\@rc])->Dump();
  764: }

  766: # -----------------------------------------------------------------------
  767: # Private helpers
  768: # -----------------------------------------------------------------------
  769: 
  770: # Purpose:  Decide whether a string could be a location at all.  This is the
  771: #           one definition of the rule geocode() rejects on, so that
  772: #           valid_location() and the guard that croaks cannot disagree, and
  773: #           the regex is no longer private to this file.
  774: # Entry:    $location — the candidate, in any form.
  775: # Exit:     True for anything with a non-digit character in it; false for undef,
  776: #           for a reference and for a string of digits only (a numeric column
  777: #           read by mistake, which is never an address).
  778: sub _valid_location {
  779: 	my $location = shift;
  780: 
  781: 	return 0 unless defined($location) && !ref($location) && length($location);
  782: 	return $location =~ /\D/ ? 1 : 0;
  783: }
  784: 
  785: # Purpose:  Return a formatted message string from the message table.
  786: #           Falls back to the raw key so call sites never die on a missing key.
  787: # Entry:    $key — message key; @args — sprintf format arguments.
  788: # Exit:     Formatted string.
  789: sub _i18n {
  790: 	my ($key, @args) = @_;
  791: 	my $fmt = $_MESSAGES{$key} // $key;
  792: 	return @args ? sprintf($fmt, @args) : $fmt;
  793: }
  794: 
  795: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
  796: #             hashref, even-length key-val list, odd-length list, single bare string.
  797: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
  798: #           $bare_key  — hash key to assign to a single bare string argument
  799: #                        ('location' for geocode, 'latlng' for reverse_geocode).
  800: #           @args — raw @_ after $self has been shifted.
  801: # Exit:     Flat key-value %params hash.
  802: # Side Effects: None; croaks on unsupported reference argument.
  803: sub _normalize_args {
  804: 	my ($error_msg, $bare_key, @args) = @_;
  805: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
  806: 	Carp::croak($error_msg)         if ref($args[0]);
  807: 	return @args                    if @args && @args % 2 == 0;
  808: 	return ($bare_key => $args[0])  if @args == 1;
  809: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
  810: 	# The former code silently returned () here, discarding the trailing elements.
  811: 	# Fail fast instead of propagating a malformed argument list downstream.
  812: 	Carp::croak($error_msg)         if @args;
  813: 	return ();
  814: }
  815: 
  816: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
  817: #           annotating every hit with location/text/confidence metadata and
  818: #           memoising misses to avoid re-querying the same failing string.
  819: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
  820: #           $candidates — arrayref of place-name strings to probe.
  821: #           $region     — optional ISO country code appended to each candidate.
  822: #           $confidence — numeric confidence score assigned to all hits.
  823: #           $scantext   — original free text (stored inside each result object).
  824: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
  825: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
  826: sub _resolve_scan_candidates {
  827: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
  828: 	my @results;
  829: 	for my $place (@{$candidates}) {
  830: 		my $location = $region ? "$place, $region" : $place;
  831: 		next if $self->{'scantext_misses'}{$location};
  832: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
  833: 		if (@res) {
  834: 			for my $entry (@res) {
  835: 				$entry->{'location'}   = $location;
  836: 				$entry->{'text'}       = $scantext;
  837: 				$entry->{'confidence'} = $confidence;
  838: 			}
  839: 			push @results, @res;
  840: 		} else {
  841: 			$self->{'scantext_misses'}{$location} = 1;
  842: 		}
  843: 	}
  844: 	return \@results;
  845: }
  846: 
  847: # Purpose:  Slide a window of $n words across $text and return all comma-joined
  848: #           n-grams, excluding pure-numeric tokens and stopwords.
  849: #           Replaces the former _find_word_triplets ($n=3) and
  850: #           _find_word_duplets ($n=2) which were identical except for window size
  851: #           and the duplets version was missing the lc() normalisation on stopwords.
  852: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
  853: # Exit:     Flat list of n-gram strings.
  854: sub _find_word_ngrams {
  855: 	my ($text, $n, $stop) = @_;
  856: 	$text =~ s/,+/ /g;
  857: 	$text =~ s/\s+/ /g;
  858: 	$text =~ s/^\s+|\s+$//g;
  859: 	my @words = grep { !/^\d+$/ && !$stop->{lc $_} } split /\s+/, $text;
  860: 	my @ngrams;
  861: 	for my $i (0 .. $#words - ($n - 1)) {
  862: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
  863: 	}
  864: 	return @ngrams;
  865: }

  867: # Purpose:  Extract structured US street addresses from free text.
  868: # Entry:    $text — arbitrary string.
  869: # Exit:     List of full address strings matching the US pattern.
  870: sub _find_us_addresses {
  871: 	my $text = shift;
  872: 	my @addresses;
  873: 	my $re = qr/
  874: 		\b \d{1,5} \s+                                      # house number
  875: 		(?:[A-Za-z0-9]+(?:\s+[A-Za-z0-9]+){0,6}) \s+       # street name: 1–7 words (bounded)
  876: 		(?:Avenue|Ave\.?|Boulevard|Blvd\.?|Road|Rd\.?|Lane|Ln\.?|Drive|Dr\.?|Street|St\.?)
  877: 		(?:\s+[A-Za-z]{2})? ,\s*
  878: 		(?:[A-Za-z]+(?:\s+[A-Za-z]+){0,3}) ,\s*            # city: 1–4 words
  879: 		[A-Z]{2} \s* (?:\d{5}(?:-\d{4})?)? \b              # state + optional zip
  880: 	/x;
  881: 	while ($text =~ /$re/g) {
  882: 		push @addresses, $&;
  883: 	}
  884: 	return @addresses;
  885: }
  886: 
  887: # Purpose:  Extract British-style addresses from free text.
  888: # Entry:    $text — arbitrary string.
  889: # Exit:     List of trimmed address strings.
  890: sub _find_gb_addresses {
  891: 	my $text = shift;
  892: 	my @addresses;
  893: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
  894: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
  895: 	# possible splits of a long string among 5 overlapping space-containing
  896: 	# groups, causing exponential backtracking.  Making commas mandatory
  897: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
  898: 	# All groups are non-capturing (only $& is used).
  899: 	my $re = qr/
  900: 		\b
  901: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
  902: 		\s+
  903: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
  904: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
  905: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
  906: 		\s*,\s*                                   # COMMA REQUIRED
  907: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
  908: 		\s*,\s*                                   # COMMA REQUIRED
  909: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
  910: 		\b
  911: 	/x;
  912: 	while ($text =~ /$re/g) {
  913: 		(my $addr = $&) =~ s/[,\s]+$//;
  914: 		push @addresses, $addr;
  915: 	}
  916: 	return @addresses;
  917: }

  919: # Purpose:  Extract Canadian street addresses from free text.
  920: # Entry:    $text — arbitrary string.
  921: # Exit:     List of full address strings matching the Canadian pattern.
  922: sub _find_ca_addresses {
  923: 	my $text = shift;
  924: 	my @addresses;
  925: 	my $re = qr/
  926: 		\b \d{1,5} \s+                                         # house number
  927: 		(?:[A-Za-z0-9]+(?:\s+[A-Za-z0-9]+){0,6}) \s+          # street name: 1–7 words (bounded)
  928: 		(?:Avenue|Ave\.?|Boulevard|Blvd\.?|Road|Rd\.?|Lane|Ln\.?|Drive|Dr\.?|Street|St\.?|Circle|Crescent|Cres\.?)
  929: 		\s*,\s*
  930: 		(?:[A-Za-z]+(?:\s+[A-Za-z]+){0,3}) \s*,\s*            # city: 1–4 words
  931: 		[A-Z]{2} \s*,?\s*
  932: 		(?:[A-Z]\d[A-Z]\s?\d[A-Z]\d)? \b                      # optional postal code
  933: 	/x;
  934: 	while ($text =~ /$re/g) {
  935: 		push @addresses, $&;
  936: 	}
  937: 	return @addresses;
  938: }

  942: =head1 GETTING STARTED
  943: 
  944: To download, import and set up the local database:
  945: before running C<make>, but after running C<perl Makefile.PL>, follow these instructions.
  946: 
  947: Optionally set C<OPENADDR_HOME> to point to an empty directory and download the data from
  948: L<http://results.openaddresses.io> into that directory; and
  949: optionally set C<WHOSONFIRST_HOME> to point to an empty directory and download the data using
  950: L<https://github.com/nigelhorne/NJH-Snippets/blob/master/bin/wof-clone>.
  951: The script C<bin/download_databases> (see below) will do those for you.
  952: You do not need to download the MaxMind data — that is downloaded automatically.
  953: 
  954: You will need to create the database used by C<Geo::Coder::Free>.
  955: 
  956: Install L<App::csv2sqlite> and L<https://github.com/nigelhorne/NJH-Snippets>.
  957: Run C<bin/create_sqlite> — this converts the MaxMind "cities" database from CSV to SQLite.
  958: 
  959: To use with MariaDB, set C<MARIADB_SERVER="$hostname;$port"> and
  960: C<MARIADB_USER="$user;$password"> (TODO: username/password should be asked for interactively).
  961: The code will use a database called C<geo_code_free>, which will be dropped and recreated if it exists.
  962: C<$user> needs only DROP, CREATE, SELECT, INSERT, and INDEX privileges on that database.
  963: 
  964: The following optional steps download and install large databases.
  965: This will take a long time and use a lot of disc space.
  966: 
  967: =over 4
  968: 
  969: =item 1
  970: 
  971: C<mkdir $WHOSONFIRST_HOME; cd $WHOSONFIRST_HOME> then run C<wof-clone> from NJH-Snippets.
  972: 
  973: This can take a long time because it contains many nested directories, which filesystem drivers
  974: can be slow to navigate (particularly on EXT4 and ZFS).
  975: 
  976: =item 2
  977: 
  978: Install L<https://github.com/dr5hn/countries-states-cities-database.git> into C<$DR5HN_HOME>.
  979: This data covers cities only, so it is not used when C<OSM_HOME> is set (OSM is far more
  980: comprehensive).  Only Australia, Canada, and the US are imported, as the UK data is difficult
  981: to parse.
  982: 
  983: =item 3
  984: 
  985: Run C<bin/download_databases> — this downloads the Who's On First, OpenAddr, OpenStreetMap,
  986: and dr5hn databases.
  987: OpenStreetMap now uses PBF files, so you will need C<apt install osmium-tool> first.
  988: Check the values of C<OSM_HOME>, C<OPENADDR_HOME>, C<DR5HN_HOME> and C<WHOSONFIRST_HOME>
  989: within that script and adjust them for your setup.
  990: The C<Makefile.PL> file downloads the MaxMind database automatically, as it is not optional.
  991: 
  992: =item 4
  993: 
  994: Run C<bin/create_db> — this creates the database used by C<Geo::Coder::Free> from the data you
  995: have just downloaded.
  996: The database is called C<openaddr.sql> for historical reasons (before Who's On First was added);
  997: it actually contains data from all sources above.
  998: 
  999: =back
 1000: 
 1001: Now you are ready to run C<make>.
 1002: See the comment at the start of C<createdatabase.PL> for further details.

 1043: =head2 new
 1044: 
 1045:     GeoCoderFreeState ::= ⟨⟨ maxmind     : MaxMind_Geocoder;
 1046:                               openaddr    : OpenAddr_Geocoder | undef;
 1047:                               alternatives: Map[STRING → STRING];
 1048:                               cache       : Cache | undef ⟩⟩
 1049: 
 1050:     Init : Params → GeoCoderFreeState
 1051:     ∀ p : Params •
 1052:       let oa_path == p.openaddr ∨ env.OPENADDR_HOME •
 1053:       GeoCoderFreeState.openaddr = if oa_path ≠ ∅ then OpenAddresses(oa_path) else undef fi
 1054: 
 1055: =head2 valid_location
 1056: 
 1057:     ValidLocation : Any → BOOLEAN
 1058:     ∀ x : Any •
 1059:       ValidLocation(x) = (x ≠ ∅ ∧ ¬ ref(x) ∧ x ≠ "" ∧ x ∋ non-digit)
 1060: 
 1061: =head2 geocode
 1062: 
 1063:     ErrorMode ::= "croak" | "undef"
 1064: 
 1065:     Geocode : Address × Region? × ErrorMode? → Point?
 1066:     ∀ addr : Address; r : Region?; e : ErrorMode? •
 1067:       let mode == e ∨ "croak" •
 1068:       let backends == (openaddr ≠ undef ⟹ [OpenAddresses, Local, MaxMind])
 1069:                     ∧ (openaddr = undef ⟹ [MaxMind]) •
 1070:       ¬ ValidLocation(addr) ⟹ (mode = "undef" ⟹ result = ∅ | mode = "croak" ⟹ ⊥)
 1071:       ∧ ValidLocation(addr) ⟹
 1072:       result = first { defined } map { b.geocode(addr, r) } backends
 1073:

 1075: 
 1076:     Provenance : Point? → (DISTRIBUTION?, BACKEND?, CONFIDENCE?, ACCURACY?)
 1077:     ∀ p : Point? •
 1078:       Provenance(p) = if p ≠ ∅ ∧ is_a_result(p)
 1079:                       then ⟨⟨ p.geocoder,
 1080:                               strip("Geo::Coder::Free::", p.database),
 1081:                               p.confidence,
 1082:                               p.accuracy ⟩⟩
 1083:                       else ∅ fi
