   54: =head1 DESCRIPTION
   55: 
   56: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
   57: using local SQLite databases built from free data sources - MaxMind/GeoNames,
   58: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
   59: database.  It deliberately avoids paid or rate-limited online geocoding services.
   60: The module is designed to be flexible, supporting both command-line and programmatic usage.
   61: It also includes a sample CGI script for a web-based geocoding service.
   62: 
   63: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
   64: 
   65: B<With OpenAddresses data:>
   66: 
   67: =over 4
   68: 
   69: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
   70: 
   71: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
   72: 
   73: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
   74: 
   75: =back
   76: 
   77: B<Without OpenAddresses data:>
   78: 
   79: =over 4
   80: 
   81: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
   82: 
   83: =back
   84: 
   85: The C<cgi-bin> directory contains a simple DIY geo-coding website:
   86: 
   87:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
   88: 
   89: The sample website is currently down while a new host is sought.
   90: When it returns, you will be able to test it with:
   91: 
   92:     curl 'https://geocode.nigelhorne.com/cgi-bin/page.fcgi?page=query&q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA'

   94: =head1 LIMITATIONS
   95: 
   96: =over 4
   97: 
   98: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
   99: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
  100: 
  101: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
  102: user-editable config file.
  103: 
  104: =item * The address-regex scantext path misses birth-year sentences such as
  105: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  106: a preceding capital-letter word directly before the city.
  107: 
  108: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  109: not return meaningful results.
  110: 
  111: =item * The C<alternatives> map loop uses C<each %{$alt}>, which retains its

  115: wraps around.  Workaround: call C<keys %{$alt}> once to reset the iterator
  116: before iterating.

  118: =back

  279: =head2 valid_location
  280: 
  281: =head3 SYNOPSIS
  282: 
  283:     if ($geo->valid_location($row->{'place'})) {
  284:         push @found, $geo->geocode(location => $row->{'place'});
  285:     }
  286: 
  287: =head3 DESCRIPTION
  288: 
  289: Answers whether a string is something this module will even try to look up.
  290: It is the public form of the rule C<geocode()> applies before it touches a
  291: backend, so a caller working down a spreadsheet column can skip a row whose
  292: value is a bare number - or is empty - instead of catching the croak that
  293: would otherwise kill the whole run.  That rule is defined once, in
  294: L<Geo::Location::Predicate>, and the backends apply it too: what
  295: C<valid_location()> refuses is refused wherever it is looked up.
  296: 
  297: Only that cheap syntactic test is answered.  A true result means the string is
  298: not disqualified, B<not> that a backend knows it: C<'Ramsgate, Kent'> is valid
  299: and may still find nothing, while C<'0044'> is invalid and is never looked up.
  300: The rule rejects a string of digits only, which is what a numeric column holds
  301: when the wrong column has been read, so anything with a non-digit in it counts
  302: as valid - C<'3.14'> and C<'-'> included.  C<undef>, C<''> and a reference are
  303: not valid.
  304: 
  305: =head3 API SPECIFICATION
  306: 
  307: =head4 input
  308: 
  309:     location => { type => 'scalar', optional => 1 }  # the string to test
  310: 
  311: =head4 output
  312: 
  313:     { type => 'boolean' }  # false for undef, '' and a digit-only string
  314: 
  315: =head3 EXAMPLE
  316: 
  317:     my $geo = Geo::Coder::Free->new();
  318: 
  319:     $geo->valid_location('Ramsgate, Kent');   # true
  320:     $geo->valid_location('0044');             # false - never a location
  321:     $geo->valid_location('');                 # false
  322:     $geo->valid_location(undef);              # false
  323: 
  324: Accepts the three calling conventions the rest of this module does:
  325: 
  326:     $geo->valid_location('0044');
  327:     Geo::Coder::Free->valid_location('0044');
  328:     Geo::Coder::Free::valid_location('0044');
  329: 
  330: =cut

  350: =head2 geocode
  351: 
  352: =head3 SYNOPSIS
  353: 
  354:     # Standard lookup (returns a Geo::Location::Point or undef)
  355:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  356:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  357: 
  358:     # Scantext - returns a list of Geo::Location::Point objects
  359:     my @hits = $geo->geocode(
  360:         scantext     => 'She lived in Ramsgate, Kent.',
  361:         region       => 'GB',
  362:         ignore_words => [qw(lived)],
  363:     );
  364: 
  365:     # Invocation flexibility (all equivalent)
  366:     $geo->geocode('Ramsgate, Kent, UK');
  367:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  368:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  369: 
  370:     # A batch caller with a dirty column: skip the row, do not kill the run
  371:     for my $place (@column) {
  372:         my $pt = $geo->geocode(location => $place, on_error => 'undef');
  373:         next unless defined $pt;
  374:         push @found, $pt;
  375:     }
  376: 
  377: =head3 DESCRIPTION
  378: 
  379: A location or a scantext that is not a location at all - a bare number, such as
  380: the C<0044> a numeric column holds - is refused before any backend is
  381: touched.  C<valid_location()> answers the same question, so a caller can filter
  382: first; C<on_error> chooses what happens when one gets through anyway:
  383: 
  384: =over 4
  385: 
  386: =item * C<'croak'> (the default) - C<Carp::croak>, the behaviour every existing
  387: caller already has.
  388: 
  389: =item * C<'undef'> - return C<undef>, so one bad row in a spreadsheet column is
  390: skipped rather than ending the run.  It changes the answer for B<only> the two
  391: documented input errors below; an exception from a backend is still an
  392: exception, and a malformed argument list still croaks.
  393: 
  394: =back
  395: 
  396: The option is deliberately narrow, so a batch caller wants C<valid_location()>
  397: with it: that predicate answers false for C<undef> and C<''> as well, which are
  398: the other two things an empty cell holds.  A call with neither a location nor a
  399: scantext is a usage error rather than an input error - the same croak as calling
  400: C<geocode()> with no arguments - and stays a croak on either setting.
  401:

  406:     # Input schema (Params::Validate::Strict) - exactly one of location or scantext is required

  460: sub geocode {
  461: 	my $self = shift;
  462: 
  463: 	# Handle being called as a function rather than a method
  464: 	if (!ref($self)) {
  465: 		if (scalar @_) {
  466: 			return __PACKAGE__->new()->geocode(@_);

  469: 		} elsif ($self eq __PACKAGE__) {
  470: 			Carp::croak(_i18n('usage_geocode', $self));
  471: 		}
  472: 		return __PACKAGE__->new()->geocode($self);
  473: 	} elsif (ref($self) eq 'HASH') {
  474: 		return __PACKAGE__->new()->geocode($self);
  475: 	}
  476: 
  477: 	my %params = _normalize_args(_i18n('usage_geocode', __PACKAGE__), 'location', @_);
  478: 
  479: 	# What to do with an input this module rejects before it touches a backend.
  480: 	# 'croak' is the historical behaviour and stays the default, so no existing
  481: 	# caller changes; 'undef' is for a batch caller working down a dirty column,
  482: 	# which wants the row skipped rather than the whole run killed.  Only the two
  483: 	# input errors below consult it: a backend that throws still throws, because
  484: 	# nothing here is wrapped in an eval
  485: 	my $on_error = $params{'on_error'} // 'croak';

  487: 		unless $on_error eq 'croak' || $on_error eq 'undef';

  490: 	# The rule is Geo::Location::Predicate's, the same one the backends
  491: 	# apply, and valid_location() answers it in public, so a caller can
  492: 	# pre-filter with it and never reach this croak at all.

  514: 
  515: 			my $region = $params{'region'};
  516: 
  517: 			# Build the effective stopword set.  When the caller supplies no
  518: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  519: 			# at runtime) by using a reference to it directly.  Only when extra
  520: 			# words are needed do we allocate and populate a merged hash.
  521: 			my $ignore_words;
  522: 			if (my $iw = $params{'ignore_words'}) {
  523: 				my %merged = %_COMMON_WORDS;
  524: 				$merged{lc $_} = 1 for @{$iw};
  525: 				$ignore_words = \%merged;
  526: 			} else {
  527: 				$ignore_words = \%_COMMON_WORDS;
  528: 			}
  529: 
  530: 			# 3-word window search
  531: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  532: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  533: 			if (@{$res}) {
  534: 				return wantarray ? @{$res} : $res->[0];
  535: 			}
  536: 
  537: 			# 2-word window search
  538: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  539: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  540: 			if (@{$res}) {
  541: 				return wantarray ? @{$res} : $res->[0];
  542: 			}
  543: 
  544: 			# Regex-based address pattern — catches "City, ST"-style fragments.
  545: 			# Note: misses sentences like "born May 21, 1937 in Noblesville, IN"
  546: 			# because the pattern requires a capitalised word before the city.
  547: 			my @regex_matches = $scantext =~
  548: 				/\b(?:\d+\s+)?(?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*\.?),\s*
  549: 				 (?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*(?:,\s*[A-Z]{2,})*)\b/gx;
  550: 			my @places = grep { defined && $_ ne '' } @regex_matches;
  551: 			$res = $self->_resolve_scan_candidates(\@places, $region, $CONF_REGEX, $scantext);
  552: 			if (@{$res}) {
  553: 				return wantarray ? @{$res} : $res->[0];
  554: 			}
  555: 
  556: 			# Region-specific structured address patterns
  557: 			if ($region) {
  558: 				my @candidates;
  559: 				if    ($region eq 'GB') { @candidates = _find_gb_addresses($scantext) }
  560: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  561: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }
  562: 
  563: 				if (@candidates) {
  564: 					my @regional;
  565: 					for my $candidate (@candidates) {
  566: 						next if $ignore_words->{lc $candidate};
  567: 						my @hits = grep { defined }
  568: 							$self->{'openaddr'}->geocode("$candidate, $region");
  569: 						push @regional, @hits if @hits;
  570: 					}
  571: 					return @regional if @regional;
  572: 				}
  573: 			}
  574: 
  575: 			$self->{'scantext_misses'}{$scantext} = 1;
  576: 			return;
  577: 		}
  578: 
  579: 		# Standard (non-scantext) lookup path
  580: 		if (wantarray) {
  581: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  582: 			return @rc if @rc && $rc[0];
  583: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  584: 			@rc = $self->{'local'}->geocode(\%params);
  585: 			return @rc if @rc && $rc[0];
  586: 		} else {
  587: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  588: 				return $rc;
  589: 			}
  590: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  591: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  592: 				return $rc;
  593: 			}
  594: 		}
  595: 
  596: 		# Try the alternatives table — hand-curated mappings for locations that
  597: 		# the databases have under slightly different names.
  598: 		# M3 (transitive reduction): every scantext path inside this block returned
  599: 		# early above; at this point $params{'scantext'} is provably falsy, so the
  600: 		# former `if (!$params{'scantext'})` guard was a tautology — removed.
  601: 		if (my $alt = $self->{'alternatives'}) {
  602: 			my $location = $params{'location'};
  603: 			while (my ($key, $value) = each %{$alt}) {
  604: 				next unless $location =~ $key;
  605: 				(my $new_loc = $location) =~ s/$key/$value/;
  606: 				$params{'location'} = $new_loc;
  607: 				if (my $rc = $self->geocode(\%params)) {
  608: 					return $rc;
  609: 				}
  610: 				# Also try the comma-free variant ("Tyne and Wear" etc.)
  611: 				if ($value =~ /, /) {
  612: 					(my $flat = $value) =~ s/,//g;
  613: 					($new_loc = $location) =~ s/$key/$flat/;
  614: 					$params{'location'} = $new_loc;
  615: 					if (my $rc = $self->geocode(\%params)) {
  616: 						return $rc;
  617: 					}
  618: 				}
  619: 				# Restore for the next iteration
  620: 				$params{'location'} = $location;
  621: 			}
  622: 		}
  623: 	}
  624: 
  625: 	# Final fallback: MaxMind for location lookups.
  626: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;
  627: 	# a proper fix would warn here (see LIMITATIONS).
  628: 	# M8 (tautology elimination): both arms of the former wantarray ternary were
  629: 	# identical — collapsed to a single call; context propagates implicitly.
  630: 	if ($params{'location'}) {
  631: 		return $self->{'maxmind'}->geocode(\%params);
  632: 	}
  633: 
  634: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  635: 	return;
  636: }

  638: =head2 geocode_many
  639: 
  640: =head3 SYNOPSIS
  641: 
  642:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  643: 
  644:     for my $place (@places) {
  645:         my $pt = $batch->{$place};              # a Geo::Location::Point, or undef
  646:         next unless defined $pt;
  647:         printf "%s is at %.4f, %.4f\n", $place, $pt->lat(), $pt->long();
  648:     }
  649: 
  650:     printf "geocoded %d of %d places in %d lookups\n",
  651:         $batch->{'resolved'},
  652:         $batch->{'resolved'} + $batch->{'unresolved'},
  653:         $batch->{'lookups'};
  654: 
  655: =head3 DESCRIPTION
  656: 
  657: The loop a batch caller writes around C<geocode()>, run for it: one lookup per
  658: B<distinct> value, with the same options and the same results, plus the counts
  659: that caller would otherwise keep itself - how many values made a backend read,
  660: how many resolved, how many did not, which ones, and which backend read for them
  661: 
  662: The hashref returned holds one entry per distinct value given, keyed by the
  663: value, plus five keys of its own:
  664: 
  665: =over 4
  666: 
  667: =item * C<< $batch->{$value} >> - the C<Geo::Location::Point> the value resolved
  668: to, or C<undef> if nothing did.  Every distinct value in the input is keyed, so
  669: a caller walking a column can look each row up without first asking whether the
  670: batch covered it.  An C<undef> in the input has no key of its own and shares the
  671: entry of the empty string, which is not a location either.
  672: 
  673: =item * C<lookups> - how many distinct values made a backend read to answer
  674: them: one per value, however many backends looked at it.  A value the module
  675: refuses before any backend is touched - a bare number, C<''>, C<undef>, a
  676: reference - is not counted, and neither is a value a backend answered from a
  677: cache or from a hand-curated entry, because nothing was read for it.  This is
  678: what makes the count the work a caller is capping rather than the work it asked
  679: for.  A value repeated in the batch is one lookup.  Every backend reports its
  680: reads through C<reads()>, and a value every backend has already missed is
  681: remembered in L<Geo::Coder::Free::MissCache>, one process-level cache that all
  682: backends and instances share, whose entries expire after an hour and can be
  683: emptied early with L</clear_miss_cache>.  A later batch in the same process is
  684: answered from those caches and so reports the reads it needed, often none, in
  685: place of the ones the first batch made.
  686: 
  687: =item * C<reads> - how many reads each backend made for the batch, keyed by the
  688: name C<provenance()> reports that backend under: C<MaxMind>, C<Local> or
  689: C<OpenAddresses>.  Every backend the object holds is named, at zero for one that
  690: read nothing, so a batch answered from a cache names its backends at zero rather
  691: than naming none.  C<lookups> counts values and this counts reads - a value that
  692: made two backends read is one lookup and a read for each of them, so these
  693: numbers can add up to more than C<lookups> - and the two vocabularies are the
  694: same, so a caller can put the backend that read a value beside the backend a
  695: result came from.
  696: 
  697: =item * C<resolved> - how many distinct values produced a point.
  698: 
  699: =item * C<unresolved> - how many produced nothing, the refused values included.
  700: 
  701: =item * C<unresolved_values> - those values, in the order they were first seen,
  702: so that a caller can record them as tried-and-failed rather than retrying them
  703: on every request.  Section 2.5 sketches this list under the name C<unresolved>;
  704: here C<unresolved> is the count a "geocoded N of M" message needs and the values
  705: themselves are C<unresolved_values>.
  706: 
  707: =back
  708: 
  709: C<resolved> and C<unresolved> always add up to the number of distinct values
  710: given, and the five keys above are reserved: a value equal to one of them is
  711: refused by name, before anything is looked up, rather than allowed to overwrite
  712: a count.
  713: 
  714: C<region> and C<on_error> are handed to every lookup and mean there what they
  715: mean in C<geocode()>, including the rule that a backend exception is still an
  716: exception - nothing here is wrapped in an C<eval>.  C<on_error> defaults to
  717: C<'croak'> for the same reason it does there: a batch should not quietly plot
  718: fewer points than its column holds unless the caller asked it to, and a caller
  719: working down a dirty column asks for C<'undef'>.  The two settings do not differ
  720: in which values are looked up, only in what happens to a value the module
  721: refuses: C<'croak'> dies on it with the message C<geocode()> gives for it,
  722: C<'undef'> counts it unresolved and carries on.
  723: 
  724: A batch of no values is not an error: the counts come back zero.
  725: 
  726: The values are treated as a set.  Repeating a value in the input looks it up
  727: once and every row is keyed to the same point object, so a column that repeats
  728: the same handful of places thousands of times costs the handful of lookups.
  729: 
  730: =head3 API SPECIFICATION
  731: 
  732: =head4 input
  733: 
  734:     # Input schema (Params::Validate::Strict) - values required, options optional
  735:     values   => { type => 'arrayref' }                  # location strings, one per row
  736:     region   => { type => 'scalar', optional => 1 }     # ISO 3166-1 alpha-2 country code hint
  737:     on_error => { type => 'scalar', optional => 1 }     # 'croak' (the default) or 'undef'
  738: 
  739: =head4 output
  740: 
  741:     # Output schema (Return::Set)
  742:     { type => 'hashref' }
  743:     #   $result->{$value}            => { isa => 'Geo::Location::Point', optional => 1 }
  744:     #   $result->{lookups}           => { type => 'integer' }
  745:     #   $result->{reads}             => { type => 'hashref' }
  746:     #   $result->{resolved}          => { type => 'integer' }
  747:     #   $result->{unresolved}        => { type => 'integer' }
  748:     #   $result->{unresolved_values} => { type => 'arrayref' }
  749: 
  750: =head3 MESSAGES
  751: 
  752:     Usage: ...::geocode_many(...)   No values argument, one that is not an arrayref,
  753:                                     or options that are neither a list nor a hashref.
  754:     invalid location to geocode()   A value refused under on_error => 'croak', with the
  755:                                     message geocode() gives for that value.
  756:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  757:     <value> is one of the keys ...  A value spelled like one of the five returned keys.
  758: 
  759: =head3 EXAMPLE
  760: 
  761:     my $geo = Geo::Coder::Free->new(openaddr => $ENV{OPENADDR_HOME});
  762: 
  763:     # A log file's place column: repeats, a few unreadable values, one empty cell.
  764:     my @places = ('Ramsgate, Kent', '0044', 'Nowhere, Imaginary, ZZ',
  765:                   'Ramsgate, Kent', undef);
  766: 
  767:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  768: 
  769:     printf "geocoded %d of %d distinct places in %d lookups\n",
  770:         $batch->{'resolved'},
  771:         $batch->{'resolved'} + $batch->{'unresolved'},
  772:         $batch->{'lookups'};        # 4 distinct places, 2 of them looked up
  773: 
  774:     # Which backend did the reading, and which answered from a cache: a backend
  775:     # at zero answered nothing by reading.
  776:     while (my ($backend, $reads) = each %{$batch->{'reads'}}) {
  777:         print "$backend read $reads times\n";
  778:     }
  779: 
  780:     for my $place ($batch->{'unresolved_values'}) {
  781:         warn "no coordinates for '" . (defined($place) ? $place : '') . "'\n";
  782:     }

  786: sub geocode_many {
  787: 	my $self = shift;
  788: 
  789: 	# The same calling conventions as the rest of the module, with the batch's
  790: 	# own spelling for the plain-function form: the values are always an
  791: 	# arrayref, so that is what a function call arrives holding.
  792: 	if (!Scalar::Util::blessed($self)) {
  793: 		return __PACKAGE__->new()->geocode_many($self, @_)
  794: 			if ref($self) eq 'ARRAY';
  795: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless @_;
  796: 		return __PACKAGE__->new()->geocode_many(@_);
  797: 	}
  798: 
  799: 	my $values = shift;
  800: 	Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless ref($values) eq 'ARRAY';
  801: 
  802: 	# Options are a hashref or an even list.  A lone scalar is neither: there is
  803: 	# no bare-string form of a batch, so it is refused rather than guessed at.
  804: 	my $opts;
  805: 	if (@_ == 1 && ref($_[0]) eq 'HASH') {
  806: 		$opts = { %{$_[0]} };
  807: 	} elsif ((scalar @_) % 2 == 0 && !grep { ref } @_) {
  808: 		$opts = { @_ };
  809: 	} else {
  810: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__));
  811: 	}
  812: 
  813: 	my $on_error = $opts->{'on_error'} // 'croak';
  814: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  815: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  816: 
  817: 	my $region = $opts->{'region'};
  818: 
  819: 	# A value spelled like one of the keys this method answers with would
  820: 	# overwrite it, so it is refused by name - before anything is looked up,
  821: 	# rather than after a count has been lost.
  822: 	my %reserved = map { $_ => 1 } @RESULT_KEYS;
  823: 	for my $value (@{$values}) {
  824: 		my $key = defined($value) ? $value : '';
  825: 		Carp::croak(_i18n('reserved_location', __PACKAGE__, $key)) if $reserved{$key};
  826: 	}
  827: 
  828: 	my %results = map { $_ => 0 } @RESULT_KEYS;
  829: 	$results{'unresolved_values'} = [];
  830: 	$results{'reads'} = {};
  831: 
  832: 	# A batch is a set: a value repeated in the input is looked up once, and
  833: 	# every row holding it is keyed to the same object.
  834: 	my %seen;
  835: 	for my $value (@{$values}) {
  836: 		# undef has no key of its own, and the empty string it shares is not a
  837: 		# location either, so it is unresolved without reaching a backend.
  838: 		my $key = defined($value) ? $value : '';
  839: 		next if $seen{$key}++;
  840: 
  841: 		# What geocode() makes of this value on this setting is asked of
  842: 		# geocode() rather than written out again here: the guard, its message and
  843: 		# the choice of backend are all its own.  The backends' read counters are
  844: 		# taken around the call, so the value is counted as a lookup only if one of
  845: 		# them actually read: a value answered from a cache, or from a hand-curated
  846: 		# entry, is not counted as work the batch did not do.  Taking them per
  847: 		# backend rather than in total says which backend read, and which answered
  848: 		# from somewhere else: a read is added to the name of the backend that made
  849: 		# it, so a value two backends read through is one lookup and a read each.
  850: 		my $reads_before = $self->_backend_reads();
  851: 		my $point = $self->geocode(
  852: 			location => $key,
  853: 			defined($region) ? (region => $region) : (),
  854: 			on_error => $on_error,
  855: 		);
  856: 		my $reads_after = $self->_backend_reads();
  857: 
  858: 		my $read = 0;
  859: 		foreach my $backend (keys %{$reads_after}) {
  860: 			my $reads = $reads_after->{$backend} - ($reads_before->{$backend} // 0);
  861: 			next unless $reads > 0;
  862: 			$results{'reads'}{$backend} += $reads;
  863: 			$read += $reads;
  864: 		}
  865: 
  866: 		# A value the module refuses is not a lookup: it never reached a backend,
  867: 		# so it does not count against the work a caller is capping.
  868: 		$results{'lookups'}++ if _valid_location($key) && $read;
  869: 		$results{$key} = $point;
  870: 
  871: 		if (defined($point)) {
  872: 			$results{'resolved'}++;
  873: 		} else {
  874: 			$results{'unresolved'}++;
  875: 			push @{$results{'unresolved_values'}}, $value;
  876: 		}
  877: 	}
  878: 
  879: 	# A backend that read nothing is reported as well, at zero: what a caller is
  880: 	# asking is which backend read and which answered from a cache, and a backend
  881: 	# left out of the answer cannot be told from one that answered from one.
  882: 	# Local is built the first time a lookup falls through to it, so it appears
  883: 	# once it has been consulted, whether or not it found anything.
  884: 	foreach my $backend (keys %{$self->_backend_reads()}) {
  885: 		$results{'reads'}{$backend} //= 0;
  886: 	}
  887: 
  888: 	return \%results;
  889: }
  890: 
  891: # How much reading each backend has done so far, by the name it is reported
  892: # under.  Counters rather than flags: the change across a call says which
  893: # backend read for that value, and a backend that was never called cannot leave
  894: # a stale flag behind.  A backend object may not exist yet - Local is built on
  895: # first use - and a test may hand the facade a stand-in, so each slot is asked
  896: # only if it holds something that can answer.
  897: sub _backend_reads {
  898: 	my $self = shift;
  899: 
  900: 	my %reads;
  901: 	foreach my $slot (sort keys %_BACKEND_NAMES) {
  902: 		my $backend = $self->{$slot} or next;
  903: 		next unless Scalar::Util::blessed($backend) && $backend->can('reads');
  904: 		$reads{$_BACKEND_NAMES{$slot}} = $backend->reads() // 0;
  905: 	}
  906: 
  907: 	return \%reads;
  908: }

  910: =head2 clear_miss_cache
  911: 
  912:     Geo::Coder::Free->clear_miss_cache();
  913:     $geo->clear_miss_cache();
  914:     Geo::Coder::Free->clear_miss_cache('OpenAddresses');
  915: 
  916: Forgets the lookups that found nothing.  Each backend remembers a miss in
  917: L<Geo::Coder::Free::MissCache>, one process-level cache that every backend and
  918: every instance shares, so an address that is not in the data is searched for
  919: once per process rather than once per call.  Entries expire after an hour; this
  920: method empties them now, for a caller that has rebuilt a database or downloaded
  921: a data set while the process is running.
  922: 
  923: With a scope - C<OpenAddresses>, C<Local> or C<MaxMind> - only that backend's
  924: entries go; C<OpenAddresses> covers every OpenAddresses directory this process
  925: has opened.  A scope that names no backend, such as
  926: C<clear_miss_cache('Nonsense')>, forgets nothing and is not an error.  Returns
  927: true.
  928: 
  929: =head3 API SPECIFICATION
  930: 
  931: =head4 input
  932: 
  933:     scope => { type => 'string', optional => 1 }  # OpenAddresses, Local or MaxMind
  934: 
  935: =head4 output
  936: 
  937:     { type => 'boolean', value => 1 }
  938: 
  939: =cut
  940: 
  941: sub clear_miss_cache {
  942: 	# The invocant is $_[0] and is not needed; anything after it is the scope.
  943: 	Geo::Coder::Free::MissCache->clear(@_ > 1 ? $_[1] : undef);
  944: 
  945: 	return 1;
  946: }

  948: =head2 provenance
  949: 
  950:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
  951: 
  952: or, in scalar context, the same four as a hashref:
  953: 
  954:     my $provenance = $geocoder->provenance($point);
  955:     print $provenance->{'backend'};
  956: 
  957: Where a result came from and how good it is, so that a caller does not have to
  958: reach for the hash keys itself:
  959: 
  960: =over 4
  961: 
  962: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
  963: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
  964: that passed it on, such as C<Geo::Coder::List>.
  965: 
  966: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
  967: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
  968: the distribution's prefix removed, so that the two spellings the backends use -
  969: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
  970: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
  971: consumers that already match on it.
  972: 
  973: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
  974: 
  975: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
  976: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
  977: 
  978: =back
  979: 
  980: Returns an empty list - and an empty hashref in scalar context - when handed
  981: something that is not a result.  A key a result does not carry comes back
  982: C<undef> rather than being guessed at, because a plain hash from another
  983: geocoder has no provenance to report.
  984: 
  985: =head3 API SPECIFICATION
  986: 
  987: =head4 input
  988: 
  989:     point => { type => 'hashref', optional => 1 }  # a result, usually a Geo::Location::Point
  990: 
  991: =head4 output
  992: 
  993:     # list context
  994:     { type => 'array', min => 0, max => 4 }   # dist, backend, confidence, accuracy; or ()
  995: 
  996:     # scalar context
  997:     {
  998:         type   => 'hashref',
  999:         schema => {
 1000:             dist       => { type => 'string', optional => 1 },
 1001:             backend    => { type => 'string', optional => 1 },
 1002:             confidence => { type => 'number', optional => 1, min => 0, max => 1 },
 1003:             accuracy   => { type => 'string', optional => 1 },
 1004:         },
 1005:     }   # {} when handed something that is not a result
 1006: 
 1007: =cut
 1008: 
 1009: sub provenance {
 1010: 	my ($self, $point) = @_;
 1011: 
 1012: 	return wantarray ? () : {} unless defined($point) && ref($point)
 1013: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
 1014: 
 1015: 	my $dist    = $point->{'geocoder'};
 1016: 	my $backend = $point->{'database'};
 1017: 	$backend =~ s/^Geo::Coder::Free::// if defined($backend);
 1018: 
 1019: 	my %provenance = (
 1020: 		dist       => $dist,
 1021: 		backend    => $backend,
 1022: 		confidence => $point->{'confidence'},
 1023: 		accuracy   => $point->{'accuracy'},
 1024: 	);
 1025: 
 1026: 	return wantarray ? @provenance{qw(dist backend confidence accuracy)} : \%provenance;
 1027: }

 1059: sub reverse_geocode {
 1060: 	my $self = shift;
 1061: 
 1062: 	if (!ref($self)) {
 1063: 		if (scalar @_) {
 1064: 			return __PACKAGE__->new()->reverse_geocode(@_);
 1065: 		} elsif (!defined($self)) {
 1066: 			Carp::croak(_i18n('usage_reverse', __PACKAGE__));
 1067: 		} elsif ($self eq __PACKAGE__) {
 1068: 			Carp::croak(_i18n('usage_reverse', $self));
 1069: 		}
 1070: 		return __PACKAGE__->new()->reverse_geocode($self);
 1071: 	} elsif (ref($self) eq 'HASH') {
 1072: 		return __PACKAGE__->new()->reverse_geocode($self);
 1073: 	}
 1074: 
 1075: 	my %params = _normalize_args(_i18n('usage_reverse', __PACKAGE__), 'latlng', @_);

 1078: 	# context propagates implicitly through return.

 1084: 	}

 1086: 	Carp::croak(_i18n('reverse_unsupported'));

 1126: # The rule geocode() rejects on - whether a string could be a location at all -
 1127: # is defined in Geo::Location::Predicate, and imported above.  It is not
 1128: # written out here as well: the backends ask the same question of what a caller
 1129: # hands them, so one definition is what keeps valid_location(), the guard that
 1130: # croaks and the backends from disagreeing about it.
 1131: 
 1132: # Purpose:  Return a formatted message string from the message table.
 1133: #           Falls back to the raw key so call sites never die on a missing key.
 1134: # Entry:    $key — message key; @args — sprintf format arguments.
 1135: # Exit:     Formatted string.
 1136: sub _i18n {
 1137: 	my ($key, @args) = @_;
 1138: 	my $fmt = $_MESSAGES{$key} // $key;
 1139: 	return @args ? sprintf($fmt, @args) : $fmt;
 1140: }

 1142: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
 1143: #             hashref, even-length key-val list, odd-length list, single bare string.
 1144: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
 1145: #           $bare_key  — hash key to assign to a single bare string argument
 1146: #                        ('location' for geocode, 'latlng' for reverse_geocode).
 1147: #           @args — raw @_ after $self has been shifted.
 1148: # Exit:     Flat key-value %params hash.
 1149: # Side Effects: None; croaks on unsupported reference argument.
 1150: sub _normalize_args {
 1151: 	my ($error_msg, $bare_key, @args) = @_;
 1152: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
 1153: 	Carp::croak($error_msg)         if ref($args[0]);
 1154: 	return @args                    if @args && @args % 2 == 0;
 1155: 	return ($bare_key => $args[0])  if @args == 1;
 1156: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
 1157: 	# The former code silently returned () here, discarding the trailing elements.
 1158: 	# Fail fast instead of propagating a malformed argument list downstream.
 1159: 	Carp::croak($error_msg)         if @args;
 1160: 	return ();
 1161: }

 1163: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
 1164: #           annotating every hit with location/text/confidence metadata and
 1165: #           memoising misses to avoid re-querying the same failing string.
 1166: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
 1167: #           $candidates — arrayref of place-name strings to probe.
 1168: #           $region     — optional ISO country code appended to each candidate.
 1169: #           $confidence — numeric confidence score assigned to all hits.
 1170: #           $scantext   — original free text (stored inside each result object).
 1171: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
 1172: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
 1173: sub _resolve_scan_candidates {
 1174: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
 1175: 	my @results;
 1176: 	for my $place (@{$candidates}) {
 1177: 		my $location = $region ? "$place, $region" : $place;
 1178: 		next if $self->{'scantext_misses'}{$location};
 1179: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
 1180: 		if (@res) {
 1181: 			for my $entry (@res) {
 1182: 				$entry->{'location'}   = $location;
 1183: 				$entry->{'text'}       = $scantext;
 1184: 				$entry->{'confidence'} = $confidence;
 1185: 			}
 1186: 			push @results, @res;
 1187: 		} else {
 1188: 			$self->{'scantext_misses'}{$location} = 1;
 1189: 		}
 1190: 	}
 1191: 	return \@results;
 1192: }

 1194: # Purpose:  Slide a window of $n words across $text and return all comma-joined
 1195: #           n-grams, excluding pure-numeric tokens and stopwords.  A token of
 1196: #           digits only is not a word of a place name, which is the question
 1197: #           Geo::Location::Predicate::_valid_location() answers, so it is asked
 1198: #           there rather than spelled out here (t/location-rule.t fails if the
 1199: #           rule is written out again).
 1200: #           Replaces the former _find_word_triplets ($n=3) and
 1201: #           _find_word_duplets ($n=2) which were identical except for window size
 1202: #           and the duplets version was missing the lc() normalisation on stopwords.
 1203: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
 1204: # Exit:     Flat list of n-gram strings.
 1205: sub _find_word_ngrams {
 1206: 	my ($text, $n, $stop) = @_;
 1207: 	$text =~ s/,+/ /g;
 1208: 	$text =~ s/\s+/ /g;
 1209: 	$text =~ s/^\s+|\s+$//g;
 1210: 	my @words = grep { !$stop->{lc $_} && _valid_location($_) } split /\s+/, $text;
 1211: 	my @ngrams;
 1212: 	for my $i (0 .. $#words - ($n - 1)) {
 1213: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
 1214: 	}
 1215: 	return @ngrams;
 1216: }

 1222: 	my $text = shift;

 1238: # Purpose:  Extract British-style addresses from free text.
 1239: # Entry:    $text — arbitrary string.
 1240: # Exit:     List of trimmed address strings.
 1241: sub _find_gb_addresses {
 1242: 	my $text = shift;
 1243: 	my @addresses;
 1244: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
 1245: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
 1246: 	# possible splits of a long string among 5 overlapping space-containing
 1247: 	# groups, causing exponential backtracking.  Making commas mandatory
 1248: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
 1249: 	# All groups are non-capturing (only $& is used).
 1250: 	my $re = qr/
 1251: 		\b
 1252: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
 1253: 		\s+
 1254: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
 1255: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
 1256: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
 1257: 		\s*,\s*                                   # COMMA REQUIRED
 1258: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
 1259: 		\s*,\s*                                   # COMMA REQUIRED
 1260: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
 1261: 		\b
 1262: 	/x;
 1263: 	while ($text =~ /$re/g) {
 1264: 		(my $addr = $&) =~ s/[,\s]+$//;
 1265: 		push @addresses, $addr;
 1266: 	}
 1267: 	return @addresses;
 1268: }
