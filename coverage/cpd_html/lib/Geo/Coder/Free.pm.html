  107: =head1 DESCRIPTION
  108: 
  109: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
  110: using local SQLite databases built from free data sources - MaxMind/GeoNames,
  111: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
  112: database.  It deliberately avoids paid or rate-limited online geocoding services.
  113: The module is designed to be flexible, supporting both command-line and programmatic usage.
  114: It also includes a sample CGI script for a web-based geocoding service.
  115: 
  116: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
  117: 
  118: B<With OpenAddresses data:>
  119: 
  120: =over 4
  121: 
  122: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
  123: 
  124: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
  125: 
  126: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
  127: 
  128: =back
  129: 
  130: B<Without OpenAddresses data:>
  131: 
  132: =over 4
  133: 
  134: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
  135: 
  136: =back
  137: 
  138: The C<cgi-bin> directory contains a simple DIY geo-coding website:
  139: 
  140:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
  141: 
  142: The sample website is currently down while a new host is sought.
  143: When it returns, you will be able to test it with:
  144: 
  145:     curl 'https://geocode.nigelhorne.com/cgi-bin/page.fcgi?page=query&q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA'
  146: 
  147: =head1 LIMITATIONS
  148: 
  149: =over 4
  150: 
  151: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
  152: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
  153: 
  154: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
  155: user-editable config file.
  156: 
  157: =item * The address-regex scantext path misses birth-year sentences such as
  158: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  159: a preceding capital-letter word directly before the city.
  160: 
  161: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  162: not return meaningful results.
  163: 
  164: =item * Without OpenAddresses data, a two-part C<"City, Country"> location is
  165: often answered wrongly.  The MaxMind backend reads the first part as a region
  166: when it can, and answers with the first row it finds in that region, not with
  167: the city: C<"Berlin, Germany"> and C<"Munich, Germany"> both come back at
  168: 52.08, 7.38, and C<"Toronto, Canada"> comes back in British Columbia.  Some
  169: others, such as C<"Paris, France">, are not found at all.  These results carry
  170: C<< accuracy => 'region' >> and C<< confidence => 0.1 >>, so a caller that needs
  171: a city should check L</provenance> and reject them.  Naming the region as well,
  172: as in C<"Munich, Bavaria, Germany">, gives the right answer.
  173: 
  174: =item * Place names are matched as they are spelled in the data, with no
  175: folding of accents: C<"ZE<uuml>rich, Switzerland"> is found and C<"Zurich, Switzerland">
  176: is not.  Pass locations as Perl character strings (decoded, for example by
  177: C<use utf8> or an C<:encoding(UTF-8)> layer), not as undecoded UTF-8 bytes,
  178: since a byte string does not match the name in the data.
  179: 
  180: =back

  345: =head2 valid_location
  346: 
  347: =head3 SYNOPSIS
  348: 
  349:     if ($geo->valid_location($row->{'place'})) {
  350:         push @found, $geo->geocode(location => $row->{'place'});
  351:     }
  352: 
  353: =head3 DESCRIPTION
  354: 
  355: Answers whether a string is something this module will even try to look up.
  356: It is the public form of the rule C<geocode()> applies before it touches a
  357: backend, so a caller working down a spreadsheet column can skip a row whose
  358: value is a bare number - or is empty - instead of catching the croak that
  359: would otherwise kill the whole run.  That rule is defined once, in
  360: L<Geo::Location::Predicate>, and the backends apply it too: what
  361: C<valid_location()> refuses is refused wherever it is looked up.
  362: 
  363: Only that cheap syntactic test is answered.  A true result means the string is
  364: not disqualified, B<not> that a backend knows it: C<'Ramsgate, Kent'> is valid
  365: and may still find nothing, while C<'0044'> is invalid and is never looked up.
  366: The rule rejects a string of digits only, which is what a numeric column holds
  367: when the wrong column has been read, so anything with a non-digit in it counts
  368: as valid - C<'3.14'> and C<'-'> included.  C<undef>, C<''> and a reference are
  369: not valid.
  370: 
  371: =head3 API SPECIFICATION
  372: 
  373: =head4 input
  374: 
  375:     location => { type => 'scalar', optional => 1 }  # the string to test
  376: 
  377: =head4 output
  378: 
  379:     { type => 'boolean' }  # false for undef, '' and a digit-only string
  380: 
  381: =head3 EXAMPLE
  382: 
  383:     my $geo = Geo::Coder::Free->new();
  384: 
  385:     $geo->valid_location('Ramsgate, Kent');   # true
  386:     $geo->valid_location('0044');             # false - never a location
  387:     $geo->valid_location('');                 # false
  388:     $geo->valid_location(undef);              # false

  391: 
  392:     $geo->valid_location('0044');

  394:     Geo::Coder::Free::valid_location('0044');

  402: 	# predicate reads the same whether it is called on an instance, on the

  416: =head2 geocode
  417: 
  418: =head3 SYNOPSIS
  419: 
  420:     # Standard lookup (returns a Geo::Location::Point or undef)
  421:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  422:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  423: 
  424:     # Scantext - returns a list of Geo::Location::Point objects
  425:     my @hits = $geo->geocode(
  426:         scantext     => 'She lived in Ramsgate, Kent.',
  427:         region       => 'GB',
  428:         ignore_words => [qw(lived)],
  429:     );
  430: 
  431:     # Invocation flexibility (all equivalent)
  432:     $geo->geocode('Ramsgate, Kent, UK');
  433:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  434:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  435: 
  436:     # A batch caller with a dirty column: skip the row, do not kill the run
  437:     for my $place (@column) {
  438:         my $pt = $geo->geocode(location => $place, on_error => 'undef');
  439:         next unless defined $pt;
  440:         push @found, $pt;
  441:     }
  442: 
  443: =head3 DESCRIPTION
  444: 
  445: A location or a scantext that is not a location at all - a bare number, such as
  446: the C<0044> a numeric column holds - is refused before any backend is
  447: touched.  C<valid_location()> answers the same question, so a caller can filter
  448: first; C<on_error> chooses what happens when one gets through anyway:
  449: 
  450: =over 4
  451: 
  452: =item * C<'croak'> (the default) - C<Carp::croak>, the behaviour every existing
  453: caller already has.
  454: 
  455: =item * C<'undef'> - return C<undef>, so one bad row in a spreadsheet column is
  456: skipped rather than ending the run.  It changes the answer for B<only> the two
  457: documented input errors below; an exception from a backend is still an
  458: exception, and a malformed argument list still croaks.
  459: 
  460: =back
  461: 
  462: The option is deliberately narrow, so a batch caller wants C<valid_location()>
  463: with it: that predicate answers false for C<undef> and C<''> as well, which are
  464: the other two things an empty cell holds.  A call with neither a location nor a
  465: scantext is a usage error rather than an input error - the same croak as calling
  466: C<geocode()> with no arguments - and stays a croak on either setting.
  467:

  474:     scantext     => { type => 'scalar',   optional => 1 }  # free text to scan for place names
  475:     region       => { type => 'scalar',   optional => 1 }  # ISO 3166-1 alpha-2 country code hint

  505:     validate: on_error is 'croak' or 'undef' (croak if not)
  506:     validate: location is not purely numeric; scantext is not purely numeric
  507:               (undef instead of croaking when on_error is 'undef')
  508:     if openaddr backend is available:
  509:         if scantext:
  510:             try the raw scantext string as a direct location
  511:             build stopword set from %_COMMON_WORDS + ignore_words param
  512:             try 3-word windows (triplets) at confidence 0.8
  513:             try 2-word windows (duplets) at confidence 0.7
  514:             try the address-pattern regex at confidence 0.7
  515:             try region-specific address finders (GB / US / CA)
  516:             mark scantext as a miss; return undef
  517:         else:
  518:             try openaddr backend
  519:             try local backend
  520:             try __DATA__ alternatives map
  521:     try maxmind backend for location lookups
  522:     croak if no scantext and no location
  523: 
  524: =cut

  526: sub geocode {
  527: 	my $self = shift;
  528: 
  529: 	# Handle being called as a function rather than a method
  530: 	if (!ref($self)) {
  531: 		if (scalar @_) {
  532: 			return __PACKAGE__->new()->geocode(@_);
  533: 		} elsif (!defined($self)) {
  534: 			Carp::croak(_i18n('usage_geocode', __PACKAGE__));
  535: 		} elsif ($self eq __PACKAGE__) {
  536: 			Carp::croak(_i18n('usage_geocode', $self));
  537: 		}
  538: 		return __PACKAGE__->new()->geocode($self);
  539: 	} elsif (ref($self) eq 'HASH') {
  540: 		return __PACKAGE__->new()->geocode($self);
  541: 	}
  542: 
  543: 	my %params = _normalize_args(_i18n('usage_geocode', __PACKAGE__), 'location', @_);
  544: 
  545: 	# What to do with an input this module rejects before it touches a backend.
  546: 	# 'croak' is the historical behaviour and stays the default, so no existing
  547: 	# caller changes; 'undef' is for a batch caller working down a dirty column,
  548: 	# which wants the row skipped rather than the whole run killed.  Only the two
  549: 	# input errors below consult it: a backend that throws still throws, because
  550: 	# nothing here is wrapped in an eval
  551: 	my $on_error = $params{'on_error'} // 'croak';
  552: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  553: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  554: 
  555: 	# Reject pure-numeric inputs early — they are never valid addresses.
  556: 	# The rule is Geo::Location::Predicate's, the same one the backends
  557: 	# apply, and valid_location() answers it in public, so a caller can
  558: 	# pre-filter with it and never reach this croak at all.
  559: 	if (defined($params{'location'}) && !_valid_location($params{'location'})) {
  560: 		return if !length($params{'location'}) || ($on_error eq 'undef');
  561: 		Carp::croak(_i18n('invalid_location', __PACKAGE__, $params{'location'}));
  562: 	}
  563: 	if (defined($params{'scantext'}) && !_valid_location($params{'scantext'})) {
  564: 		return if !length($params{'scantext'}) || ($on_error eq 'undef');
  565: 		Carp::croak(_i18n('invalid_scantext', __PACKAGE__, $params{'scantext'}));
  566: 	}
  567: 
  568: 	if ($self->{'openaddr'}) {
  569: 		if (my $scantext = $params{'scantext'}) {
  570: 			return if $self->{'scantext_misses'}{$scantext};
  571: 
  572: 			# First try the whole scantext as a direct location lookup —
  573: 			# saves work when the text happens to be a valid address string.
  574: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  575: 			my @direct = grep { defined }
  576: 				$self->{'local'}->geocode($scantext),
  577: 				$self->{'openaddr'}->geocode($scantext),
  578: 				$self->{'maxmind'}->geocode($scantext);
  579: 			return @direct if @direct;
  580: 
  581: 			my $region = $params{'region'};
  582: 
  583: 			# Build the effective stopword set.  When the caller supplies no
  584: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  585: 			# at runtime) by using a reference to it directly.  Only when extra
  586: 			# words are needed do we allocate and populate a merged hash.
  587: 			my $ignore_words;
  588: 			if (my $iw = $params{'ignore_words'}) {
  589: 				my %merged = %_COMMON_WORDS;
  590: 				$merged{lc $_} = 1 for @{$iw};
  591: 				$ignore_words = \%merged;
  592: 			} else {
  593: 				$ignore_words = \%_COMMON_WORDS;
  594: 			}
  595: 
  596: 			# 3-word window search
  597: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  598: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  599: 			if (@{$res}) {
  600: 				return wantarray ? @{$res} : $res->[0];
  601: 			}
  602: 
  603: 			# 2-word window search
  604: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  605: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  606: 			if (@{$res}) {
  607: 				return wantarray ? @{$res} : $res->[0];
  608: 			}
  609: 
  610: 			# Regex-based address pattern — catches "City, ST"-style fragments.
  611: 			# Note: misses sentences like "born May 21, 1937 in Noblesville, IN"
  612: 			# because the pattern requires a capitalised word before the city.
  613: 			my @regex_matches = $scantext =~
  614: 				/\b(?:\d+\s+)?(?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*\.?),\s*
  615: 				 (?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*(?:,\s*[A-Z]{2,})*)\b/gx;
  616: 			my @places = grep { defined && $_ ne '' } @regex_matches;
  617: 			$res = $self->_resolve_scan_candidates(\@places, $region, $CONF_REGEX, $scantext);
  618: 			if (@{$res}) {
  619: 				return wantarray ? @{$res} : $res->[0];
  620: 			}
  621: 
  622: 			# Region-specific structured address patterns
  623: 			if ($region) {
  624: 				my @candidates;
  625: 				if    ($region eq 'GB') { @candidates = _find_gb_addresses($scantext) }
  626: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  627: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }
  628: 
  629: 				if (@candidates) {
  630: 					my @regional;
  631: 					for my $candidate (@candidates) {
  632: 						next if $ignore_words->{lc $candidate};
  633: 						my @hits = grep { defined }
  634: 							$self->{'openaddr'}->geocode("$candidate, $region");
  635: 						push @regional, @hits if @hits;
  636: 					}
  637: 					return @regional if @regional;
  638: 				}
  639: 			}
  640: 
  641: 			$self->{'scantext_misses'}{$scantext} = 1;
  642: 			return;
  643: 		}
  644: 
  645: 		# Standard (non-scantext) lookup path
  646: 		if (wantarray) {
  647: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  648: 			return @rc if @rc && $rc[0];
  649: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  650: 			@rc = $self->{'local'}->geocode(\%params);
  651: 			return @rc if @rc && $rc[0];
  652: 		} else {
  653: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  654: 				return $rc;
  655: 			}
  656: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  657: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  658: 				return $rc;
  659: 			}
  660: 		}
  661: 
  662: 		# Try the alternatives table — hand-curated mappings for locations that
  663: 		# the databases have under slightly different names.
  664: 		# M3 (transitive reduction): every scantext path inside this block returned
  665: 		# early above; at this point $params{'scantext'} is provably falsy, so the
  666: 		# former `if (!$params{'scantext'})` guard was a tautology — removed.
  667: 		if (my $alt = $self->{'alternatives'}) {
  668: 			my $location = $params{'location'};
  669: 			# Not each(): the recursive geocode() calls below walk the same
  670: 			# hash, sharing and resetting its iterator, so an each() loop here
  671: 			# would start again from the top and retry the same key forever.
  672: 			foreach my $key (sort keys %{$alt}) {
  673: 				my $value = $alt->{$key};
  674: 				next unless $location =~ $key;
  675: 				(my $new_loc = $location) =~ s/$key/$value/;
  676: 				$params{'location'} = $new_loc;
  677: 				if (my $rc = $self->geocode(\%params)) {
  678: 					return $rc;
  679: 				}
  680: 				# Also try the comma-free variant ("Tyne and Wear" etc.)
  681: 				if ($value =~ /, /) {
  682: 					(my $flat = $value) =~ s/,//g;
  683: 					($new_loc = $location) =~ s/$key/$flat/;
  684: 					$params{'location'} = $new_loc;
  685: 					if (my $rc = $self->geocode(\%params)) {
  686: 						return $rc;
  687: 					}
  688: 				}
  689: 				# Restore for the next iteration
  690: 				$params{'location'} = $location;
  691: 			}
  692: 		}
  693: 	}
  694: 
  695: 	# Final fallback: MaxMind for location lookups.
  696: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;
  697: 	# a proper fix would warn here (see LIMITATIONS).
  698: 	# M8 (tautology elimination): both arms of the former wantarray ternary were
  699: 	# identical — collapsed to a single call; context propagates implicitly.
  700: 	if ($params{'location'}) {
  701: 		return $self->{'maxmind'}->geocode(\%params);
  702: 	}
  703: 
  704: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  705: 	return;
  706: }

  708: =head2 geocode_many
  709: 
  710: =head3 SYNOPSIS
  711: 
  712:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  713: 
  714:     for my $place (@places) {
  715:         my $pt = $batch->{$place};              # a Geo::Location::Point, or undef
  716:         next unless defined $pt;
  717:         printf "%s is at %.4f, %.4f\n", $place, $pt->lat(), $pt->long();
  718:     }
  719: 
  720:     printf "geocoded %d of %d places in %d lookups\n",
  721:         $batch->{'resolved'},
  722:         $batch->{'resolved'} + $batch->{'unresolved'},
  723:         $batch->{'lookups'};
  724: 
  725: =head3 DESCRIPTION
  726: 
  727: The loop a batch caller writes around C<geocode()>, run for it: one lookup per
  728: B<distinct> value, with the same options and the same results, plus the counts
  729: that caller would otherwise keep itself - how many values made a backend read,
  730: how many resolved, how many did not, which ones, and which backend read for them
  731: 
  732: The hashref returned holds one entry per distinct value given, keyed by the
  733: value, plus five keys of its own:
  734: 
  735: =over 4
  736: 
  737: =item * C<< $batch->{$value} >> - the C<Geo::Location::Point> the value resolved
  738: to, or C<undef> if nothing did.  Every distinct value in the input is keyed, so
  739: a caller walking a column can look each row up without first asking whether the
  740: batch covered it.  An C<undef> in the input has no key of its own and shares the
  741: entry of the empty string, which is not a location either.
  742: 
  743: =item * C<lookups> - how many distinct values made a backend read to answer
  744: them: one per value, however many backends looked at it.  A value the module
  745: refuses before any backend is touched - a bare number, C<''>, C<undef>, a
  746: reference - is not counted, and neither is a value a backend answered from a
  747: cache or from a hand-curated entry, because nothing was read for it.  This is
  748: what makes the count the work a caller is capping rather than the work it asked
  749: for.  A value repeated in the batch is one lookup.  Every backend reports its
  750: reads through C<reads()>, and a value every backend has already missed is
  751: remembered in L<Geo::Coder::Free::MissCache>, one process-level cache that all
  752: backends and instances share, whose entries expire after an hour and can be
  753: emptied early with L</clear_miss_cache>.  A later batch in the same process is
  754: answered from those caches and so reports the reads it needed, often none, in
  755: place of the ones the first batch made.
  756: 
  757: =item * C<reads> - how many reads each backend made for the batch, keyed by the
  758: name C<provenance()> reports that backend under: C<MaxMind>, C<Local> or
  759: C<OpenAddresses>.  Every backend the object holds is named, at zero for one that
  760: read nothing, so a batch answered from a cache names its backends at zero rather
  761: than naming none.  C<lookups> counts values and this counts reads - a value that
  762: made two backends read is one lookup and a read for each of them, so these
  763: numbers can add up to more than C<lookups> - and the two vocabularies are the
  764: same, so a caller can put the backend that read a value beside the backend a
  765: result came from.
  766: 
  767: =item * C<resolved> - how many distinct values produced a point.
  768: 
  769: =item * C<unresolved> - how many produced nothing, the refused values included.
  770: 
  771: =item * C<unresolved_values> - those values, in the order they were first seen,
  772: so that a caller can record them as tried-and-failed rather than retrying them
  773: on every request.  Section 2.5 sketches this list under the name C<unresolved>;
  774: here C<unresolved> is the count a "geocoded N of M" message needs and the values
  775: themselves are C<unresolved_values>.
  776: 
  777: =back
  778: 
  779: C<resolved> and C<unresolved> always add up to the number of distinct values
  780: given, and the five keys above are reserved: a value equal to one of them is
  781: refused by name, before anything is looked up, rather than allowed to overwrite
  782: a count.
  783: 
  784: C<region> and C<on_error> are handed to every lookup and mean there what they
  785: mean in C<geocode()>, including the rule that a backend exception is still an
  786: exception - nothing here is wrapped in an C<eval>.  C<on_error> defaults to
  787: C<'croak'> for the same reason it does there: a batch should not quietly plot
  788: fewer points than its column holds unless the caller asked it to, and a caller
  789: working down a dirty column asks for C<'undef'>.  The two settings do not differ
  790: in which values are looked up, only in what happens to a value the module
  791: refuses: C<'croak'> dies on it with the message C<geocode()> gives for it,
  792: C<'undef'> counts it unresolved and carries on.
  793: 
  794: A batch of no values is not an error: the counts come back zero.
  795: 
  796: The values are treated as a set.  Repeating a value in the input looks it up
  797: once and every row is keyed to the same point object, so a column that repeats
  798: the same handful of places thousands of times costs the handful of lookups.
  799: 
  800: =head3 API SPECIFICATION
  801: 
  802: =head4 input
  803: 
  804:     # Input schema (Params::Validate::Strict) - values required, options optional
  805:     values   => { type => 'arrayref' }                  # location strings, one per row
  806:     region   => { type => 'scalar', optional => 1 }     # ISO 3166-1 alpha-2 country code hint
  807:     on_error => { type => 'scalar', optional => 1 }     # 'croak' (the default) or 'undef'
  808: 
  809: =head4 output
  810: 
  811:     # Output schema (Return::Set)
  812:     { type => 'hashref' }
  813:     #   $result->{$value}            => { isa => 'Geo::Location::Point', optional => 1 }
  814:     #   $result->{lookups}           => { type => 'integer' }
  815:     #   $result->{reads}             => { type => 'hashref' }
  816:     #   $result->{resolved}          => { type => 'integer' }
  817:     #   $result->{unresolved}        => { type => 'integer' }
  818:     #   $result->{unresolved_values} => { type => 'arrayref' }
  819: 
  820: =head3 MESSAGES
  821: 
  822:     Usage: ...::geocode_many(...)   No values argument, one that is not an arrayref,
  823:                                     or options that are neither a list nor a hashref.
  824:     invalid location to geocode()   A value refused under on_error => 'croak', with the
  825:                                     message geocode() gives for that value.
  826:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  827:     <value> is one of the keys ...  A value spelled like one of the five returned keys.
  828: 
  829: =head3 EXAMPLE
  830: 
  831:     my $geo = Geo::Coder::Free->new(openaddr => $ENV{OPENADDR_HOME});
  832: 
  833:     # A log file's place column: repeats, a few unreadable values, one empty cell.
  834:     my @places = ('Ramsgate, Kent', '0044', 'Nowhere, Imaginary, ZZ',
  835:                   'Ramsgate, Kent', undef);
  836: 
  837:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  838: 
  839:     printf "geocoded %d of %d distinct places in %d lookups\n",
  840:         $batch->{'resolved'},
  841:         $batch->{'resolved'} + $batch->{'unresolved'},
  842:         $batch->{'lookups'};        # 4 distinct places, 2 of them looked up
  843: 
  844:     # Which backend did the reading, and which answered from a cache: a backend
  845:     # at zero answered nothing by reading.
  846:     while (my ($backend, $reads) = each %{$batch->{'reads'}}) {
  847:         print "$backend read $reads times\n";
  848:     }
  849: 
  850:     for my $place (@{$batch->{'unresolved_values'}}) {
  851:         warn "no coordinates for '" . (defined($place) ? $place : '') . "'\n";
  852:     }

  856: sub geocode_many {
  857: 	my $self = shift;
  858: 
  859: 	# The same calling conventions as the rest of the module, with the batch's
  860: 	# own spelling for the plain-function form: the values are always an
  861: 	# arrayref, so that is what a function call arrives holding.
  862: 	if (!Scalar::Util::blessed($self)) {
  863: 		return __PACKAGE__->new()->geocode_many($self, @_)
  864: 			if ref($self) eq 'ARRAY';
  865: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless @_;
  866: 		return __PACKAGE__->new()->geocode_many(@_);
  867: 	}
  868: 
  869: 	my $values = shift;
  870: 	Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless ref($values) eq 'ARRAY';
  871: 
  872: 	# Options are a hashref or an even list.  A lone scalar is neither: there is
  873: 	# no bare-string form of a batch, so it is refused rather than guessed at.
  874: 	my $opts;
  875: 	if (@_ == 1 && ref($_[0]) eq 'HASH') {
  876: 		$opts = { %{$_[0]} };
  877: 	} elsif ((scalar @_) % 2 == 0 && !grep { ref } @_) {
  878: 		$opts = { @_ };
  879: 	} else {
  880: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__));
  881: 	}
  882: 
  883: 	my $on_error = $opts->{'on_error'} // 'croak';
  884: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  885: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  886: 
  887: 	my $region = $opts->{'region'};
  888: 
  889: 	# A value spelled like one of the keys this method answers with would
  890: 	# overwrite it, so it is refused by name - before anything is looked up,
  891: 	# rather than after a count has been lost.
  892: 	my %reserved = map { $_ => 1 } @RESULT_KEYS;
  893: 	for my $value (@{$values}) {
  894: 		my $key = defined($value) ? $value : '';
  895: 		Carp::croak(_i18n('reserved_location', __PACKAGE__, $key)) if $reserved{$key};
  896: 	}
  897: 
  898: 	my %results = map { $_ => 0 } @RESULT_KEYS;
  899: 	$results{'unresolved_values'} = [];
  900: 	$results{'reads'} = {};
  901: 
  902: 	# A batch is a set: a value repeated in the input is looked up once, and
  903: 	# every row holding it is keyed to the same object.
  904: 	my %seen;
  905: 	for my $value (@{$values}) {
  906: 		# undef has no key of its own, and the empty string it shares is not a
  907: 		# location either, so it is unresolved without reaching a backend.
  908: 		my $key = defined($value) ? $value : '';
  909: 		next if $seen{$key}++;
  910: 
  911: 		# What geocode() makes of this value on this setting is asked of
  912: 		# geocode() rather than written out again here: the guard, its message and
  913: 		# the choice of backend are all its own.  The backends' read counters are
  914: 		# taken around the call, so the value is counted as a lookup only if one of
  915: 		# them actually read: a value answered from a cache, or from a hand-curated
  916: 		# entry, is not counted as work the batch did not do.  Taking them per
  917: 		# backend rather than in total says which backend read, and which answered
  918: 		# from somewhere else: a read is added to the name of the backend that made
  919: 		# it, so a value two backends read through is one lookup and a read each.
  920: 		my $reads_before = $self->_backend_reads();
  921: 		my $point = $self->geocode(
  922: 			location => $key,
  923: 			defined($region) ? (region => $region) : (),
  924: 			on_error => $on_error,
  925: 		);
  926: 		my $reads_after = $self->_backend_reads();
  927: 
  928: 		my $read = 0;
  929: 		foreach my $backend (keys %{$reads_after}) {
  930: 			my $reads = $reads_after->{$backend} - ($reads_before->{$backend} // 0);
  931: 			next unless $reads > 0;
  932: 			$results{'reads'}{$backend} += $reads;
  933: 			$read += $reads;
  934: 		}
  935: 
  936: 		# A value the module refuses is not a lookup: it never reached a backend,
  937: 		# so it does not count against the work a caller is capping.
  938: 		$results{'lookups'}++ if _valid_location($key) && $read;
  939: 		$results{$key} = $point;
  940: 
  941: 		if (defined($point)) {
  942: 			$results{'resolved'}++;
  943: 		} else {
  944: 			$results{'unresolved'}++;
  945: 			push @{$results{'unresolved_values'}}, $value;
  946: 		}
  947: 	}
  948: 
  949: 	# A backend that read nothing is reported as well, at zero: what a caller is
  950: 	# asking is which backend read and which answered from a cache, and a backend
  951: 	# left out of the answer cannot be told from one that answered from one.
  952: 	# Local is built the first time a lookup falls through to it, so it appears
  953: 	# once it has been consulted, whether or not it found anything.
  954: 	foreach my $backend (keys %{$self->_backend_reads()}) {
  955: 		$results{'reads'}{$backend} //= 0;
  956: 	}
  957: 
  958: 	return \%results;
  959: }

  961: # How much reading each backend has done so far, by the name it is reported
  962: # under.  Counters rather than flags: the change across a call says which
  963: # backend read for that value, and a backend that was never called cannot leave
  964: # a stale flag behind.  A backend object may not exist yet - Local is built on
  965: # first use - and a test may hand the facade a stand-in, so each slot is asked
  966: # only if it holds something that can answer.
  967: sub _backend_reads {
  968: 	my $self = shift;
  969: 
  970: 	my %reads;
  971: 	foreach my $slot (sort keys %_BACKEND_NAMES) {
  972: 		my $backend = $self->{$slot} or next;
  973: 		next unless Scalar::Util::blessed($backend) && $backend->can('reads');
  974: 		$reads{$_BACKEND_NAMES{$slot}} = $backend->reads() // 0;
  975: 	}
  976: 
  977: 	return \%reads;
  978: }

  980: =head2 clear_miss_cache
  981: 
  982:     Geo::Coder::Free->clear_miss_cache();
  983:     $geo->clear_miss_cache();
  984:     Geo::Coder::Free->clear_miss_cache('OpenAddresses');
  985: 
  986: Forgets the lookups that found nothing.  Each backend remembers a miss in
  987: L<Geo::Coder::Free::MissCache>, one process-level cache that every backend and
  988: every instance shares, so an address that is not in the data is searched for
  989: once per process rather than once per call.  Entries expire after an hour; this
  990: method empties them now, for a caller that has rebuilt a database or downloaded
  991: a data set while the process is running.
  992: 
  993: With a scope - C<OpenAddresses>, C<Local> or C<MaxMind> - only that backend's
  994: entries go; C<OpenAddresses> covers every OpenAddresses directory this process
  995: has opened.  A scope that names no backend, such as
  996: C<clear_miss_cache('Nonsense')>, forgets nothing and is not an error.  Returns
  997: true.

 1000: 
 1001: =head4 input
 1002: 
 1003:     scope => { type => 'string', optional => 1 }  # OpenAddresses, Local or MaxMind
 1004: 
 1005: =head4 output
 1006: 
 1007:     { type => 'boolean', value => 1 }
 1008: 
 1009: =cut

 1018: =head2 provenance
 1019: 
 1020:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
 1021: 
 1022: or, in scalar context, the same four as a hashref:
 1023: 
 1024:     my $provenance = $geocoder->provenance($point);
 1025:     print $provenance->{'backend'};
 1026: 
 1027: Where a result came from and how good it is, so that a caller does not have to
 1028: reach for the hash keys itself:
 1029: 
 1030: =over 4
 1031: 
 1032: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
 1033: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
 1034: that passed it on, such as C<Geo::Coder::List>.
 1035: 
 1036: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
 1037: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
 1038: the distribution's prefix removed, so that the two spellings the backends use -
 1039: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
 1040: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
 1041: consumers that already match on it.
 1042: 
 1043: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
 1044: 
 1045: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
 1046: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
 1047: 
 1048: =back
 1049: 
 1050: Returns an empty list - and an empty hashref in scalar context - when handed
 1051: something that is not a result.  A key a result does not carry comes back
 1052: C<undef> rather than being guessed at, because a plain hash from another
 1053: geocoder has no provenance to report.
 1054: 
 1055: =head3 API SPECIFICATION
 1056: 
 1057: =head4 input
 1058: 
 1059:     point => { type => 'hashref', optional => 1 }  # a result, usually a Geo::Location::Point
 1060: 
 1061: =head4 output
 1062: 
 1063:     # list context
 1064:     { type => 'array', min => 0, max => 4 }   # dist, backend, confidence, accuracy; or ()
 1065: 
 1066:     # scalar context
 1067:     {
 1068:         type   => 'hashref',
 1069:         schema => {
 1070:             dist       => { type => 'string', optional => 1 },
 1071:             backend    => { type => 'string', optional => 1 },
 1072:             confidence => { type => 'number', optional => 1, min => 0, max => 1 },
 1073:             accuracy   => { type => 'string', optional => 1 },
 1074:         },
 1075:     }   # {} when handed something that is not a result
 1076: 
 1077: =cut
 1078: 
 1079: sub provenance {
 1080: 	my ($self, $point) = @_;
 1081: 
 1082: 	return wantarray ? () : {} unless defined($point) && ref($point)
 1083: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
 1084: 
 1085: 	my $dist    = $point->{'geocoder'};
 1086: 	my $backend = $point->{'database'};
 1087: 	$backend =~ s/^Geo::Coder::Free::// if defined($backend);
 1088: 
 1089: 	my %provenance = (
 1090: 		dist       => $dist,
 1091: 		backend    => $backend,
 1092: 		confidence => $point->{'confidence'},
 1093: 		accuracy   => $point->{'accuracy'},
 1094: 	);
 1095: 
 1096: 	return wantarray ? @provenance{qw(dist backend confidence accuracy)} : \%provenance;
 1097: }

 1232: # Purpose:  Return a formatted message string from the message table.

 1242: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
 1243: #             hashref, even-length key-val list, odd-length list, single bare string.
 1244: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
 1245: #           $bare_key  — hash key to assign to a single bare string argument
 1246: #                        ('location' for geocode, 'latlng' for reverse_geocode).
 1247: #           @args — raw @_ after $self has been shifted.
 1248: # Exit:     Flat key-value %params hash.
 1249: # Side Effects: None; croaks on unsupported reference argument.
 1250: sub _normalize_args {
 1251: 	my ($error_msg, $bare_key, @args) = @_;
 1252: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
 1253: 	Carp::croak($error_msg)         if ref($args[0]);
 1254: 	return @args                    if @args && @args % 2 == 0;
 1255: 	return ($bare_key => $args[0])  if @args == 1;
 1256: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
 1257: 	# The former code silently returned () here, discarding the trailing elements.
 1258: 	# Fail fast instead of propagating a malformed argument list downstream.
 1259: 	Carp::croak($error_msg)         if @args;
 1260: 	return ();
 1261: }

 1263: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
 1264: #           annotating every hit with location/text/confidence metadata and
 1265: #           memoising misses to avoid re-querying the same failing string.
 1266: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
 1267: #           $candidates — arrayref of place-name strings to probe.
 1268: #           $region     — optional ISO country code appended to each candidate.
 1269: #           $confidence — numeric confidence score assigned to all hits.
 1270: #           $scantext   — original free text (stored inside each result object).
 1271: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
 1272: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
 1273: sub _resolve_scan_candidates {
 1274: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
 1275: 	my @results;
 1276: 	for my $place (@{$candidates}) {
 1277: 		my $location = $region ? "$place, $region" : $place;
 1278: 		next if $self->{'scantext_misses'}{$location};
 1279: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
 1280: 		if (@res) {
 1281: 			for my $entry (@res) {
 1282: 				$entry->{'location'}   = $location;
 1283: 				$entry->{'text'}       = $scantext;
 1284: 				$entry->{'confidence'} = $confidence;
 1285: 			}
 1286: 			push @results, @res;
 1287: 		} else {
 1288: 			$self->{'scantext_misses'}{$location} = 1;
 1289: 		}
 1290: 	}
 1291: 	return \@results;
 1292: }

 1294: # Purpose:  Slide a window of $n words across $text and return all comma-joined
 1295: #           n-grams, excluding pure-numeric tokens and stopwords.  A token of
 1296: #           digits only is not a word of a place name, which is the question
 1297: #           Geo::Location::Predicate::_valid_location() answers, so it is asked
 1298: #           there rather than spelled out here (t/location-rule.t fails if the
 1299: #           rule is written out again).
 1300: #           Replaces the former _find_word_triplets ($n=3) and
 1301: #           _find_word_duplets ($n=2) which were identical except for window size
 1302: #           and the duplets version was missing the lc() normalisation on stopwords.
 1303: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
 1304: # Exit:     Flat list of n-gram strings.
 1305: sub _find_word_ngrams {
 1306: 	my ($text, $n, $stop) = @_;
 1307: 	$text =~ s/,+/ /g;
 1308: 	$text =~ s/\s+/ /g;
 1309: 	$text =~ s/^\s+|\s+$//g;
 1310: 	my @words = grep { !$stop->{lc $_} && _valid_location($_) } split /\s+/, $text;
 1311: 	my @ngrams;
 1312: 	for my $i (0 .. $#words - ($n - 1)) {
 1313: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
 1314: 	}
 1315: 	return @ngrams;
 1316: }

 1338: # Purpose:  Extract British-style addresses from free text.
 1339: # Entry:    $text — arbitrary string.
 1340: # Exit:     List of trimmed address strings.
 1341: sub _find_gb_addresses {
 1342: 	my $text = shift;
 1343: 	my @addresses;
 1344: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
 1345: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
 1346: 	# possible splits of a long string among 5 overlapping space-containing
 1347: 	# groups, causing exponential backtracking.  Making commas mandatory
 1348: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
 1349: 	# All groups are non-capturing (only $& is used).
 1350: 	my $re = qr/
 1351: 		\b
 1352: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
 1353: 		\s+
 1354: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
 1355: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
 1356: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
 1357: 		\s*,\s*                                   # COMMA REQUIRED
 1358: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
 1359: 		\s*,\s*                                   # COMMA REQUIRED
 1360: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
 1361: 		\b
 1362: 	/x;
 1363: 	while ($text =~ /$re/g) {
 1364: 		(my $addr = $&) =~ s/[,\s]+$//;
 1365: 		push @addresses, $addr;
 1366: 	}
 1367: 	return @addresses;

 1393: =head1 GETTING STARTED
 1394: 
 1395: To download, import and set up the local database:
 1396: before running C<make>, but after running C<perl Makefile.PL>, follow these instructions.
 1397: 
 1398: Optionally set C<OPENADDR_HOME> to point to an empty directory and download the data from
 1399: L<http://results.openaddresses.io> into that directory; and
 1400: optionally set C<WHOSONFIRST_HOME> to point to an empty directory and download the data using
 1401: L<https://github.com/nigelhorne/NJH-Snippets/blob/master/bin/wof-clone>.
 1402: The script C<bin/download_databases> (see below) will do those for you.
 1403: You do not need to download the MaxMind data - that is downloaded automatically.
 1404: 
 1405: You will need to create the database used by C<Geo::Coder::Free>.
 1406: 
 1407: Install L<App::csv2sqlite> and L<https://github.com/nigelhorne/NJH-Snippets>.
 1408: Run C<bin/create_sqlite> - this converts the MaxMind "cities" database from CSV to SQLite.
 1409: 
 1410: To use with MariaDB, set C<MARIADB_SERVER="$hostname;$port"> and
 1411: C<MARIADB_USER="$user;$password"> (TODO: username/password should be asked for interactively).
 1412: The code will use a database called C<geo_code_free>, which will be dropped and recreated if it exists.
 1413: C<$user> needs only DROP, CREATE, SELECT, INSERT, and INDEX privileges on that database.
 1414: 
 1415: The following optional steps download and install large databases.
 1416: This will take a long time and use a lot of disc space.
 1417: 
 1418: =over 4
 1419: 
 1420: =item 1
 1421: 
 1422: C<mkdir $WHOSONFIRST_HOME; cd $WHOSONFIRST_HOME> then run C<wof-clone> from NJH-Snippets.
 1423: 
 1424: This can take a long time because it contains many nested directories, which filesystem drivers
 1425: can be slow to navigate (particularly on EXT4 and ZFS).
 1426: 
 1427: =item 2
 1428: 
 1429: Install L<https://github.com/dr5hn/countries-states-cities-database.git> into C<$DR5HN_HOME>.
 1430: This data covers cities only, so it is not used when C<OSM_HOME> is set (OSM is far more
 1431: comprehensive).  Only Australia, Canada, and the US are imported, as the UK data is difficult
 1432: to parse.

 1434: =item 3
 1435:

 1439: Check the values of C<OSM_HOME>, C<OPENADDR_HOME>, C<DR5HN_HOME> and C<WHOSONFIRST_HOME>
 1440: within that script and adjust them for your setup.
 1441: The C<Makefile.PL> file downloads the MaxMind database automatically, as it is not optional.
 1442: 
 1443: =item 4
 1444: 
 1445: Run C<bin/create_db> - this creates the database used by C<Geo::Coder::Free> from the data you
 1446: have just downloaded.
 1447: The database is called C<openaddr.sql> for historical reasons (before Who's On First was added);
 1448: it actually contains data from all sources above.
 1449: 
 1450: =back
