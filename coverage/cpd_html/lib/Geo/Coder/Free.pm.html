   50: =head1 DESCRIPTION
   51: 
   52: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
   53: using local SQLite databases built from free data sources - MaxMind/GeoNames,
   54: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
   55: database.  It deliberately avoids paid or rate-limited online geocoding services.
   56: The module is designed to be flexible, supporting both command-line and programmatic usage.
   57: It also includes a sample CGI script for a web-based geocoding service.
   58: 
   59: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
   60: 
   61: B<With OpenAddresses data:>
   62: 
   63: =over 4
   64: 
   65: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
   66: 
   67: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
   68: 
   69: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
   70: 
   71: =back
   72: 
   73: B<Without OpenAddresses data:>
   74: 
   75: =over 4
   76: 
   77: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
   78: 
   79: =back
   80: 
   81: The C<cgi-bin> directory contains a simple DIY geo-coding website:
   82: 
   83:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
   84: 
   85: The sample website is currently down while a new host is sought.
   86: When it returns, you will be able to test it with:
   87: 
   88:     curl 'https://geocode.nigelhorne.com/cgi-bin/page.fcgi?page=query&q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA'
   89: 
   90: =head1 LIMITATIONS
   91: 
   92: =over 4
   93: 
   94: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
   95: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
   96: 
   97: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
   98: user-editable config file.
   99: 
  100: =item * The address-regex scantext path misses birth-year sentences such as
  101: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  102: a preceding capital-letter word directly before the city.
  103: 
  104: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  105: not return meaningful results.
  106: 
  107: =item * The C<alternatives> map loop uses C<each %{$alt}>, which retains its
  108: iterator position across calls.  After a successful match and early C<return>,
  109: the next C<geocode()> call on the same input starts iterating from the key
  110: B<after> the matched one, potentially missing the match entirely until C<each>
  111: wraps around.  Workaround: call C<keys %{$alt}> once to reset the iterator
  112: before iterating.
  113: 
  114: =back

  275: =head2 valid_location
  276: 
  277: =head3 SYNOPSIS
  278: 
  279:     if ($geo->valid_location($row->{'place'})) {
  280:         push @found, $geo->geocode(location => $row->{'place'});
  281:     }
  282: 
  283: =head3 DESCRIPTION
  284: 
  285: Answers whether a string is something this module will even try to look up.
  286: It is the public form of the rule C<geocode()> applies before it touches a
  287: backend, so a caller working down a spreadsheet column can skip a row whose
  288: value is a bare number - or is empty - instead of catching the croak that
  289: would otherwise kill the whole run.  That rule is defined once, in
  290: L<Geo::Location::Predicate>, and the backends apply it too: what
  291: C<valid_location()> refuses is refused wherever it is looked up.
  292: 
  293: Only that cheap syntactic test is answered.  A true result means the string is
  294: not disqualified, B<not> that a backend knows it: C<'Ramsgate, Kent'> is valid
  295: and may still find nothing, while C<'0044'> is invalid and is never looked up.
  296: The rule rejects a string of digits only, which is what a numeric column holds
  297: when the wrong column has been read, so anything with a non-digit in it counts
  298: as valid - C<'3.14'> and C<'-'> included.  C<undef>, C<''> and a reference are
  299: not valid.
  300: 
  301: =head3 API SPECIFICATION
  302: 
  303: =head4 input
  304: 
  305:     location => { type => 'scalar', optional => 1 }  # the string to test
  306: 
  307: =head4 output
  308: 
  309:     { type => 'boolean' }  # false for undef, '' and a digit-only string
  310: 
  311: =head3 EXAMPLE
  312: 
  313:     my $geo = Geo::Coder::Free->new();
  314: 
  315:     $geo->valid_location('Ramsgate, Kent');   # true
  316:     $geo->valid_location('0044');             # false - never a location
  317:     $geo->valid_location('');                 # false
  318:     $geo->valid_location(undef);              # false
  319: 
  320: Accepts the three calling conventions the rest of this module does:
  321: 
  322:     $geo->valid_location('0044');
  323:     Geo::Coder::Free->valid_location('0044');
  324:     Geo::Coder::Free::valid_location('0044');
  325: 
  326: =cut

  332: 	# predicate reads the same whether it is called on an instance, on the

  346: =head2 geocode
  347: 
  348: =head3 SYNOPSIS
  349: 
  350:     # Standard lookup (returns a Geo::Location::Point or undef)
  351:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  352:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  353: 
  354:     # Scantext - returns a list of Geo::Location::Point objects
  355:     my @hits = $geo->geocode(
  356:         scantext     => 'She lived in Ramsgate, Kent.',
  357:         region       => 'GB',
  358:         ignore_words => [qw(lived)],
  359:     );
  360: 
  361:     # Invocation flexibility (all equivalent)
  362:     $geo->geocode('Ramsgate, Kent, UK');
  363:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  364:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  365: 
  366:     # A batch caller with a dirty column: skip the row, do not kill the run
  367:     for my $place (@column) {
  368:         my $pt = $geo->geocode(location => $place, on_error => 'undef');
  369:         next unless defined $pt;
  370:         push @found, $pt;
  371:     }
  372: 
  373: =head3 DESCRIPTION
  374: 
  375: A location or a scantext that is not a location at all - a bare number, such as
  376: the C<0044> a numeric column holds - is refused before any backend is
  377: touched.  C<valid_location()> answers the same question, so a caller can filter
  378: first; C<on_error> chooses what happens when one gets through anyway:
  379: 
  380: =over 4
  381: 
  382: =item * C<'croak'> (the default) - C<Carp::croak>, the behaviour every existing
  383: caller already has.
  384: 
  385: =item * C<'undef'> - return C<undef>, so one bad row in a spreadsheet column is
  386: skipped rather than ending the run.  It changes the answer for B<only> the two
  387: documented input errors below; an exception from a backend is still an
  388: exception, and a malformed argument list still croaks.
  389: 
  390: =back
  391: 
  392: The option is deliberately narrow, so a batch caller wants C<valid_location()>
  393: with it: that predicate answers false for C<undef> and C<''> as well, which are
  394: the other two things an empty cell holds.  A call with neither a location nor a
  395: scantext is a usage error rather than an input error - the same croak as calling
  396: C<geocode()> with no arguments - and stays a croak on either setting.
  397: 
  398: =head3 API SPECIFICATION
  399: 
  400: =head4 input
  401: 
  402:     # Input schema (Params::Validate::Strict) - exactly one of location or scantext is required
  403:     location     => { type => 'scalar',   optional => 1 }  # address string (exclusive with scantext)
  404:     scantext     => { type => 'scalar',   optional => 1 }  # free text to scan for place names
  405:     region       => { type => 'scalar',   optional => 1 }  # ISO 3166-1 alpha-2 country code hint
  406:     ignore_words => { type => 'arrayref', optional => 1 }  # words to suppress during scantext scan
  407:     on_error     => { type => 'scalar',   optional => 1 }  # 'croak' (default) or 'undef'
  408: 
  409: =head4 output
  410: 
  411:     # Output schema (Return::Set)
  412:     # scalar context: { type => 'object',   isa => 'Geo::Location::Point', optional => 1 }
  413:     # list context:   { type => 'arrayref', of  => { isa => 'Geo::Location::Point' } }
  414: 
  415: =head4 provenance
  416: 
  417: Every result carries C<geocoder>, C<database>, C<confidence> and C<accuracy>
  418: which distribution produced
  419: it, which backend answered, how good the match was, and how precise the
  420: coordinate is.  C<provenance()> reads the four back.  C<location> is set by every
  421: path but the MaxMind cities one, and C<text> only by a scantext lookup; C<lat>,
  422: C<long> and C<lng> come from the value object itself.
  423: 
  424: =head3 MESSAGES
  425: 
  426:     Usage: ...::geocode(...)        No location or scantext argument given.
  427:     invalid location to geocode()   location is purely numeric.
  428:     invalid scantext to geocode()   scantext is purely numeric.
  429:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  430: 
  431: =head3 PSEUDOCODE
  432: 
  433:     if self is not a blessed object → delegate to new()->geocode(@args)
  434:     normalise @_ into %params
  435:     validate: on_error is 'croak' or 'undef' (croak if not)
  436:     validate: location is not purely numeric; scantext is not purely numeric
  437:               (undef instead of croaking when on_error is 'undef')
  438:     if openaddr backend is available:
  439:         if scantext:
  440:             try the raw scantext string as a direct location
  441:             build stopword set from %_COMMON_WORDS + ignore_words param
  442:             try 3-word windows (triplets) at confidence 0.8
  443:             try 2-word windows (duplets) at confidence 0.7
  444:             try the address-pattern regex at confidence 0.7
  445:             try region-specific address finders (GB / US / CA)
  446:             mark scantext as a miss; return undef
  447:         else:
  448:             try openaddr backend
  449:             try local backend
  450:             try __DATA__ alternatives map
  451:     try maxmind backend for location lookups
  452:     croak if no scantext and no location
  453: 
  454: =cut

  456: sub geocode {
  457: 	my $self = shift;
  458: 
  459: 	# Handle being called as a function rather than a method
  460: 	if (!ref($self)) {
  461: 		if (scalar @_) {
  462: 			return __PACKAGE__->new()->geocode(@_);
  463: 		} elsif (!defined($self)) {
  464: 			Carp::croak(_i18n('usage_geocode', __PACKAGE__));
  465: 		} elsif ($self eq __PACKAGE__) {
  466: 			Carp::croak(_i18n('usage_geocode', $self));
  467: 		}
  468: 		return __PACKAGE__->new()->geocode($self);
  469: 	} elsif (ref($self) eq 'HASH') {
  470: 		return __PACKAGE__->new()->geocode($self);
  471: 	}
  472: 
  473: 	my %params = _normalize_args(_i18n('usage_geocode', __PACKAGE__), 'location', @_);
  474: 
  475: 	# What to do with an input this module rejects before it touches a backend.
  476: 	# 'croak' is the historical behaviour and stays the default, so no existing
  477: 	# caller changes; 'undef' is for a batch caller working down a dirty column,
  478: 	# which wants the row skipped rather than the whole run killed.  Only the two
  479: 	# input errors below consult it: a backend that throws still throws, because
  480: 	# nothing here is wrapped in an eval
  481: 	my $on_error = $params{'on_error'} // 'croak';
  482: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  483: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  484: 
  485: 	# Reject pure-numeric inputs early — they are never valid addresses.
  486: 	# The rule is Geo::Location::Predicate's, the same one the backends
  487: 	# apply, and valid_location() answers it in public, so a caller can
  488: 	# pre-filter with it and never reach this croak at all.
  489: 	if (defined($params{'location'}) && !_valid_location($params{'location'})) {
  490: 		return if !length($params{'location'}) || ($on_error eq 'undef');
  491: 		Carp::croak(_i18n('invalid_location', __PACKAGE__, $params{'location'}));
  492: 	}
  493: 	if (defined($params{'scantext'}) && !_valid_location($params{'scantext'})) {
  494: 		return if !length($params{'scantext'}) || ($on_error eq 'undef');
  495: 		Carp::croak(_i18n('invalid_scantext', __PACKAGE__, $params{'scantext'}));
  496: 	}
  497: 
  498: 	if ($self->{'openaddr'}) {
  499: 		if (my $scantext = $params{'scantext'}) {
  500: 			return if $self->{'scantext_misses'}{$scantext};
  501: 
  502: 			# First try the whole scantext as a direct location lookup —
  503: 			# saves work when the text happens to be a valid address string.
  504: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  505: 			my @direct = grep { defined }
  506: 				$self->{'local'}->geocode($scantext),
  507: 				$self->{'openaddr'}->geocode($scantext),
  508: 				$self->{'maxmind'}->geocode($scantext);
  509: 			return @direct if @direct;
  510: 
  511: 			my $region = $params{'region'};
  512: 
  513: 			# Build the effective stopword set.  When the caller supplies no
  514: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  515: 			# at runtime) by using a reference to it directly.  Only when extra
  516: 			# words are needed do we allocate and populate a merged hash.
  517: 			my $ignore_words;
  518: 			if (my $iw = $params{'ignore_words'}) {
  519: 				my %merged = %_COMMON_WORDS;
  520: 				$merged{lc $_} = 1 for @{$iw};
  521: 				$ignore_words = \%merged;
  522: 			} else {
  523: 				$ignore_words = \%_COMMON_WORDS;
  524: 			}
  525: 
  526: 			my @rc;
  527: 
  528: 			# 3-word window search
  529: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  530: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  531: 			if (@{$res}) {
  532: 				return wantarray ? @{$res} : $res->[0];
  533: 			}
  534: 
  535: 			# 2-word window search
  536: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  537: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  538: 			if (@{$res}) {
  539: 				return wantarray ? @{$res} : $res->[0];
  540: 			}
  541: 
  542: 			# Regex-based address pattern — catches "City, ST"-style fragments.
  543: 			# Note: misses sentences like "born May 21, 1937 in Noblesville, IN"
  544: 			# because the pattern requires a capitalised word before the city.
  545: 			my @regex_matches = $scantext =~
  546: 				/\b(?:\d+\s+)?(?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*\.?),\s*
  547: 				 (?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*(?:,\s*[A-Z]{2,})*)\b/gx;
  548: 			my @places = grep { defined && $_ ne '' } @regex_matches;
  549: 			$res = $self->_resolve_scan_candidates(\@places, $region, $CONF_REGEX, $scantext);
  550: 			if (@{$res}) {
  551: 				return wantarray ? @{$res} : $res->[0];
  552: 			}
  553: 
  554: 			# Region-specific structured address patterns
  555: 			if ($region) {
  556: 				my @candidates;
  557: 				if    ($region eq 'GB') { @candidates = _find_gb_addresses($scantext) }
  558: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  559: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }
  560: 
  561: 				if (@candidates) {
  562: 					my @regional;
  563: 					for my $candidate (@candidates) {
  564: 						next if $ignore_words->{lc $candidate};
  565: 						my @hits = grep { defined }
  566: 							$self->{'openaddr'}->geocode("$candidate, $region");
  567: 						push @regional, @hits if @hits;
  568: 					}
  569: 					return @regional if @regional;
  570: 				}
  571: 			}
  572: 
  573: 			$self->{'scantext_misses'}{$scantext} = 1;
  574: 			return;
  575: 		}
  576: 
  577: 		# Standard (non-scantext) lookup path
  578: 		if (wantarray) {
  579: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  580: 			return @rc if @rc && $rc[0];
  581: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  582: 			@rc = $self->{'local'}->geocode(\%params);
  583: 			return @rc if @rc && $rc[0];
  584: 		} else {
  585: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  586: 				return $rc;
  587: 			}
  588: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  589: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  590: 				return $rc;
  591: 			}
  592: 		}
  593: 
  594: 		# Try the alternatives table — hand-curated mappings for locations that
  595: 		# the databases have under slightly different names.
  596: 		# M3 (transitive reduction): every scantext path inside this block returned
  597: 		# early above; at this point $params{'scantext'} is provably falsy, so the
  598: 		# former `if (!$params{'scantext'})` guard was a tautology — removed.
  599: 		if (my $alt = $self->{'alternatives'}) {
  600: 			my $location = $params{'location'};
  601: 			while (my ($key, $value) = each %{$alt}) {
  602: 				next unless $location =~ $key;
  603: 				(my $new_loc = $location) =~ s/$key/$value/;
  604: 				$params{'location'} = $new_loc;
  605: 				if (my $rc = $self->geocode(\%params)) {
  606: 					return $rc;
  607: 				}
  608: 				# Also try the comma-free variant ("Tyne and Wear" etc.)
  609: 				if ($value =~ /, /) {
  610: 					(my $flat = $value) =~ s/,//g;
  611: 					($new_loc = $location) =~ s/$key/$flat/;
  612: 					$params{'location'} = $new_loc;
  613: 					if (my $rc = $self->geocode(\%params)) {
  614: 						return $rc;
  615: 					}
  616: 				}
  617: 				# Restore for the next iteration
  618: 				$params{'location'} = $location;
  619: 			}
  620: 		}
  621: 	}
  622: 
  623: 	# Final fallback: MaxMind for location lookups.
  624: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;
  625: 	# a proper fix would warn here (see LIMITATIONS).
  626: 	# M8 (tautology elimination): both arms of the former wantarray ternary were
  627: 	# identical — collapsed to a single call; context propagates implicitly.
  628: 	if ($params{'location'}) {
  629: 		return $self->{'maxmind'}->geocode(\%params);
  630: 	}
  631: 
  632: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  633: 	return;
  634: }

  636: =head2 geocode_many
  637: 
  638: =head3 SYNOPSIS
  639: 
  640:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  641: 
  642:     for my $place (@places) {
  643:         my $pt = $batch->{$place};              # a Geo::Location::Point, or undef
  644:         next unless defined $pt;
  645:         printf "%s is at %.4f, %.4f\n", $place, $pt->lat(), $pt->long();
  646:     }
  647: 
  648:     printf "geocoded %d of %d places in %d lookups\n",
  649:         $batch->{'resolved'},
  650:         $batch->{'resolved'} + $batch->{'unresolved'},
  651:         $batch->{'lookups'};
  652: 
  653: =head3 DESCRIPTION
  654: 
  655: The loop a batch caller writes around C<geocode()>, run for it: one lookup per
  656: B<distinct> value, with the same options and the same results, plus the counts
  657: that caller would otherwise keep itself - how many values made a backend read,
  658: how many resolved, how many did not, which ones, and which backend read for them
  659: 
  660: The hashref returned holds one entry per distinct value given, keyed by the
  661: value, plus five keys of its own:
  662: 
  663: =over 4
  664: 
  665: =item * C<< $batch->{$value} >> - the C<Geo::Location::Point> the value resolved
  666: to, or C<undef> if nothing did.  Every distinct value in the input is keyed, so
  667: a caller walking a column can look each row up without first asking whether the
  668: batch covered it.  An C<undef> in the input has no key of its own and shares the
  669: entry of the empty string, which is not a location either.
  670: 
  671: =item * C<lookups> - how many distinct values made a backend read to answer
  672: them: one per value, however many backends looked at it.  A value the module
  673: refuses before any backend is touched - a bare number, C<''>, C<undef>, a
  674: reference - is not counted, and neither is a value a backend answered from a
  675: cache or from a hand-curated entry, because nothing was read for it.  This is
  676: what makes the count the work a caller is capping rather than the work it asked
  677: for.  A value repeated in the batch is one lookup.  Every backend reports its
  678: reads through C<reads()>, and a value every backend has already missed is
  679: remembered in L<Geo::Coder::Free::MissCache>, one process-level cache that all
  680: backends and instances share, whose entries expire after an hour and can be
  681: emptied early with L</clear_miss_cache>.  A later batch in the same process is
  682: answered from those caches and so reports the reads it needed, often none, in
  683: place of the ones the first batch made.
  684: 
  685: =item * C<reads> - how many reads each backend made for the batch, keyed by the
  686: name C<provenance()> reports that backend under: C<MaxMind>, C<Local> or
  687: C<OpenAddresses>.  Every backend the object holds is named, at zero for one that
  688: read nothing, so a batch answered from a cache names its backends at zero rather
  689: than naming none.  C<lookups> counts values and this counts reads - a value that
  690: made two backends read is one lookup and a read for each of them, so these
  691: numbers can add up to more than C<lookups> - and the two vocabularies are the
  692: same, so a caller can put the backend that read a value beside the backend a
  693: result came from.
  694: 
  695: =item * C<resolved> - how many distinct values produced a point.
  696: 
  697: =item * C<unresolved> - how many produced nothing, the refused values included.
  698: 
  699: =item * C<unresolved_values> - those values, in the order they were first seen,
  700: so that a caller can record them as tried-and-failed rather than retrying them
  701: on every request.  Section 2.5 sketches this list under the name C<unresolved>;
  702: here C<unresolved> is the count a "geocoded N of M" message needs and the values
  703: themselves are C<unresolved_values>.
  704: 
  705: =back
  706: 
  707: C<resolved> and C<unresolved> always add up to the number of distinct values
  708: given, and the five keys above are reserved: a value equal to one of them is
  709: refused by name, before anything is looked up, rather than allowed to overwrite
  710: a count.
  711: 
  712: C<region> and C<on_error> are handed to every lookup and mean there what they
  713: mean in C<geocode()>, including the rule that a backend exception is still an
  714: exception - nothing here is wrapped in an C<eval>.  C<on_error> defaults to
  715: C<'croak'> for the same reason it does there: a batch should not quietly plot
  716: fewer points than its column holds unless the caller asked it to, and a caller
  717: working down a dirty column asks for C<'undef'>.  The two settings do not differ
  718: in which values are looked up, only in what happens to a value the module
  719: refuses: C<'croak'> dies on it with the message C<geocode()> gives for it,
  720: C<'undef'> counts it unresolved and carries on.
  721: 
  722: A batch of no values is not an error: the counts come back zero.
  723: 
  724: The values are treated as a set.  Repeating a value in the input looks it up
  725: once and every row is keyed to the same point object, so a column that repeats
  726: the same handful of places thousands of times costs the handful of lookups.
  727: 
  728: =head3 API SPECIFICATION
  729: 
  730: =head4 input
  731: 
  732:     # Input schema (Params::Validate::Strict) — values required, options optional
  733:     values   => { type => 'arrayref' }                  # location strings, one per row
  734:     region   => { type => 'scalar', optional => 1 }     # ISO 3166-1 alpha-2 country code hint
  735:     on_error => { type => 'scalar', optional => 1 }     # 'croak' (the default) or 'undef'
  736: 
  737: =head4 output
  738: 
  739:     # Output schema (Return::Set)
  740:     { type => 'hashref' }
  741:     #   $result->{$value}            => { isa => 'Geo::Location::Point', optional => 1 }
  742:     #   $result->{lookups}           => { type => 'integer' }
  743:     #   $result->{reads}             => { type => 'hashref' }
  744:     #   $result->{resolved}          => { type => 'integer' }
  745:     #   $result->{unresolved}        => { type => 'integer' }
  746:     #   $result->{unresolved_values} => { type => 'arrayref' }
  747: 
  748: =head3 MESSAGES
  749: 
  750:     Usage: ...::geocode_many(...)   No values argument, one that is not an arrayref,
  751:                                     or options that are neither a list nor a hashref.
  752:     invalid location to geocode()   A value refused under on_error => 'croak', with the
  753:                                     message geocode() gives for that value.
  754:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  755:     <value> is one of the keys ...  A value spelled like one of the five returned keys.
  756: 
  757: =head3 EXAMPLE
  758: 
  759:     my $geo = Geo::Coder::Free->new(openaddr => $ENV{OPENADDR_HOME});
  760: 
  761:     # A log file's place column: repeats, a few unreadable values, one empty cell.
  762:     my @places = ('Ramsgate, Kent', '0044', 'Nowhere, Imaginary, ZZ',
  763:                   'Ramsgate, Kent', undef);
  764: 
  765:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  766: 
  767:     printf "geocoded %d of %d distinct places in %d lookups\n",
  768:         $batch->{'resolved'},
  769:         $batch->{'resolved'} + $batch->{'unresolved'},
  770:         $batch->{'lookups'};        # 4 distinct places, 2 of them looked up
  771: 
  772:     # Which backend did the reading, and which answered from a cache: a backend
  773:     # at zero answered nothing by reading.
  774:     while (my ($backend, $reads) = each %{$batch->{'reads'}}) {
  775:         print "$backend read $reads times\n";
  776:     }
  777: 
  778:     for my $place ($batch->{'unresolved_values'}) {
  779:         warn "no coordinates for '" . (defined($place) ? $place : '') . "'\n";
  780:     }

  784: sub geocode_many {
  785: 	my $self = shift;
  786: 
  787: 	# The same calling conventions as the rest of the module, with the batch's
  788: 	# own spelling for the plain-function form: the values are always an
  789: 	# arrayref, so that is what a function call arrives holding.
  790: 	if (!Scalar::Util::blessed($self)) {
  791: 		return __PACKAGE__->new()->geocode_many($self, @_)
  792: 			if ref($self) eq 'ARRAY';
  793: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless @_;
  794: 		return __PACKAGE__->new()->geocode_many(@_);
  795: 	}
  796: 
  797: 	my $values = shift;
  798: 	Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless ref($values) eq 'ARRAY';
  799: 
  800: 	# Options are a hashref or an even list.  A lone scalar is neither: there is
  801: 	# no bare-string form of a batch, so it is refused rather than guessed at.
  802: 	my $opts;
  803: 	if (@_ == 1 && ref($_[0]) eq 'HASH') {
  804: 		$opts = { %{$_[0]} };
  805: 	} elsif ((scalar @_) % 2 == 0 && !grep { ref } @_) {
  806: 		$opts = { @_ };
  807: 	} else {
  808: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__));
  809: 	}
  810: 
  811: 	my $on_error = $opts->{'on_error'} // 'croak';
  812: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  813: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  814: 
  815: 	my $region = $opts->{'region'};
  816: 
  817: 	# A value spelled like one of the keys this method answers with would
  818: 	# overwrite it, so it is refused by name - before anything is looked up,
  819: 	# rather than after a count has been lost.
  820: 	my %reserved = map { $_ => 1 } @RESULT_KEYS;
  821: 	for my $value (@{$values}) {
  822: 		my $key = defined($value) ? $value : '';
  823: 		Carp::croak(_i18n('reserved_location', __PACKAGE__, $key)) if $reserved{$key};
  824: 	}
  825: 
  826: 	my %results = map { $_ => 0 } @RESULT_KEYS;
  827: 	$results{'unresolved_values'} = [];
  828: 	$results{'reads'} = {};
  829: 
  830: 	# A batch is a set: a value repeated in the input is looked up once, and
  831: 	# every row holding it is keyed to the same object.
  832: 	my %seen;
  833: 	for my $value (@{$values}) {
  834: 		# undef has no key of its own, and the empty string it shares is not a
  835: 		# location either, so it is unresolved without reaching a backend.
  836: 		my $key = defined($value) ? $value : '';
  837: 		next if $seen{$key}++;
  838: 
  839: 		# What geocode() makes of this value on this setting is asked of
  840: 		# geocode() rather than written out again here: the guard, its message and
  841: 		# the choice of backend are all its own.  The backends' read counters are
  842: 		# taken around the call, so the value is counted as a lookup only if one of
  843: 		# them actually read: a value answered from a cache, or from a hand-curated
  844: 		# entry, is not counted as work the batch did not do.  Taking them per
  845: 		# backend rather than in total says which backend read, and which answered
  846: 		# from somewhere else: a read is added to the name of the backend that made
  847: 		# it, so a value two backends read through is one lookup and a read each.
  848: 		my $reads_before = $self->_backend_reads();
  849: 		my $point = $self->geocode(
  850: 			location => $key,
  851: 			defined($region) ? (region => $region) : (),
  852: 			on_error => $on_error,
  853: 		);
  854: 		my $reads_after = $self->_backend_reads();
  855: 
  856: 		my $read = 0;
  857: 		foreach my $backend (keys %{$reads_after}) {
  858: 			my $reads = $reads_after->{$backend} - ($reads_before->{$backend} // 0);
  859: 			next unless $reads > 0;
  860: 			$results{'reads'}{$backend} += $reads;
  861: 			$read += $reads;
  862: 		}
  863: 
  864: 		# A value the module refuses is not a lookup: it never reached a backend,
  865: 		# so it does not count against the work a caller is capping.
  866: 		$results{'lookups'}++ if _valid_location($key) && $read;
  867: 		$results{$key} = $point;
  868: 
  869: 		if (defined($point)) {
  870: 			$results{'resolved'}++;
  871: 		} else {
  872: 			$results{'unresolved'}++;
  873: 			push @{$results{'unresolved_values'}}, $value;
  874: 		}
  875: 	}
  876: 
  877: 	# A backend that read nothing is reported as well, at zero: what a caller is
  878: 	# asking is which backend read and which answered from a cache, and a backend
  879: 	# left out of the answer cannot be told from one that answered from one.
  880: 	# Local is built the first time a lookup falls through to it, so it appears
  881: 	# once it has been consulted, whether or not it found anything.
  882: 	foreach my $backend (keys %{$self->_backend_reads()}) {
  883: 		$results{'reads'}{$backend} //= 0;
  884: 	}
  885: 
  886: 	return \%results;
  887: }
  888: 
  889: # How much reading each backend has done so far, by the name it is reported
  890: # under.  Counters rather than flags: the change across a call says which
  891: # backend read for that value, and a backend that was never called cannot leave
  892: # a stale flag behind.  A backend object may not exist yet - Local is built on
  893: # first use - and a test may hand the facade a stand-in, so each slot is asked
  894: # only if it holds something that can answer.
  895: sub _backend_reads {
  896: 	my $self = shift;
  897: 
  898: 	my %reads;
  899: 	foreach my $slot (sort keys %_BACKEND_NAMES) {
  900: 		my $backend = $self->{$slot} or next;
  901: 		next unless Scalar::Util::blessed($backend) && $backend->can('reads');
  902: 		$reads{$_BACKEND_NAMES{$slot}} = $backend->reads() // 0;
  903: 	}
  904: 
  905: 	return \%reads;
  906: }

  908: =head2 clear_miss_cache
  909: 
  910:     Geo::Coder::Free->clear_miss_cache();
  911:     $geo->clear_miss_cache();
  912:     Geo::Coder::Free->clear_miss_cache('OpenAddresses');
  913: 
  914: Forgets the lookups that found nothing.  Each backend remembers a miss in
  915: L<Geo::Coder::Free::MissCache>, one process-level cache that every backend and
  916: every instance shares, so an address that is not in the data is searched for
  917: once per process rather than once per call.  Entries expire after an hour; this
  918: method empties them now, for a caller that has rebuilt a database or downloaded
  919: a data set while the process is running.
  920: 
  921: With a scope - C<OpenAddresses>, C<Local> or C<MaxMind> - only that backend's
  922: entries go; C<OpenAddresses> covers every OpenAddresses directory this process
  923: has opened.  Returns true.
  924: 
  925: =cut
  926: 
  927: sub clear_miss_cache {
  928: 	# The invocant is $_[0] and is not needed; anything after it is the scope.
  929: 	Geo::Coder::Free::MissCache->clear(@_ > 1 ? $_[1] : undef);
  930: 
  931: 	return 1;
  932: }

  934: =head2 provenance
  935: 
  936:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
  937: 
  938: or, in scalar context, the same four as a hashref:
  939: 
  940:     my $provenance = $geocoder->provenance($point);
  941:     print $provenance->{'backend'};
  942: 
  943: Where a result came from and how good it is, so that a caller does not have to
  944: reach for the hash keys itself:
  945: 
  946: =over 4
  947: 
  948: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
  949: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
  950: that passed it on, such as C<Geo::Coder::List>.
  951: 
  952: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
  953: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
  954: the distribution's prefix removed, so that the two spellings the backends use -
  955: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
  956: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
  957: consumers that already match on it.
  958: 
  959: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
  960: 
  961: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
  962: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
  963: 
  964: =back
  965: 
  966: Returns an empty list - and an empty hashref in scalar context - when handed
  967: something that is not a result.  A key a result does not carry comes back
  968: C<undef> rather than being guessed at, because a plain hash from another
  969: geocoder has no provenance to report.
  970: 
  971: =cut

  973: sub provenance {
  974: 	my ($self, $point) = @_;
  975: 
  976: 	return wantarray ? () : {} unless defined($point) && ref($point)
  977: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
  978: 
  979: 	my $dist    = $point->{'geocoder'};
  980: 	my $backend = $point->{'database'};

 1092: # written out here as well: the backends ask the same question of what a caller

 1096: # Purpose:  Return a formatted message string from the message table.
 1097: #           Falls back to the raw key so call sites never die on a missing key.
 1098: # Entry:    $key — message key; @args — sprintf format arguments.
 1099: # Exit:     Formatted string.
 1100: sub _i18n {
 1101: 	my ($key, @args) = @_;
 1102: 	my $fmt = $_MESSAGES{$key} // $key;
 1103: 	return @args ? sprintf($fmt, @args) : $fmt;
 1104: }

 1106: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
 1107: #             hashref, even-length key-val list, odd-length list, single bare string.
 1108: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
 1109: #           $bare_key  — hash key to assign to a single bare string argument
 1110: #                        ('location' for geocode, 'latlng' for reverse_geocode).
 1111: #           @args — raw @_ after $self has been shifted.
 1112: # Exit:     Flat key-value %params hash.
 1113: # Side Effects: None; croaks on unsupported reference argument.
 1114: sub _normalize_args {
 1115: 	my ($error_msg, $bare_key, @args) = @_;
 1116: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
 1117: 	Carp::croak($error_msg)         if ref($args[0]);
 1118: 	return @args                    if @args && @args % 2 == 0;
 1119: 	return ($bare_key => $args[0])  if @args == 1;
 1120: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
 1121: 	# The former code silently returned () here, discarding the trailing elements.
 1122: 	# Fail fast instead of propagating a malformed argument list downstream.
 1123: 	Carp::croak($error_msg)         if @args;
 1124: 	return ();
 1125: }

 1127: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
 1128: #           annotating every hit with location/text/confidence metadata and
 1129: #           memoising misses to avoid re-querying the same failing string.
 1130: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
 1131: #           $candidates — arrayref of place-name strings to probe.
 1132: #           $region     — optional ISO country code appended to each candidate.
 1133: #           $confidence — numeric confidence score assigned to all hits.
 1134: #           $scantext   — original free text (stored inside each result object).
 1135: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
 1136: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
 1137: sub _resolve_scan_candidates {
 1138: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
 1139: 	my @results;
 1140: 	for my $place (@{$candidates}) {
 1141: 		my $location = $region ? "$place, $region" : $place;
 1142: 		next if $self->{'scantext_misses'}{$location};
 1143: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
 1144: 		if (@res) {
 1145: 			for my $entry (@res) {
 1146: 				$entry->{'location'}   = $location;
 1147: 				$entry->{'text'}       = $scantext;
 1148: 				$entry->{'confidence'} = $confidence;
 1149: 			}
 1150: 			push @results, @res;
 1151: 		} else {
 1152: 			$self->{'scantext_misses'}{$location} = 1;
 1153: 		}
 1154: 	}
 1155: 	return \@results;
 1156: }

 1158: # Purpose:  Slide a window of $n words across $text and return all comma-joined
 1159: #           n-grams, excluding pure-numeric tokens and stopwords.  A token of
 1160: #           digits only is not a word of a place name, which is the question
 1161: #           Geo::Location::Predicate::_valid_location() answers, so it is asked
 1162: #           there rather than spelled out here (t/location-rule.t fails if the
 1163: #           rule is written out again).
 1164: #           Replaces the former _find_word_triplets ($n=3) and
 1165: #           _find_word_duplets ($n=2) which were identical except for window size
 1166: #           and the duplets version was missing the lc() normalisation on stopwords.
 1167: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
 1168: # Exit:     Flat list of n-gram strings.
 1169: sub _find_word_ngrams {
 1170: 	my ($text, $n, $stop) = @_;
 1171: 	$text =~ s/,+/ /g;
 1172: 	$text =~ s/\s+/ /g;
 1173: 	$text =~ s/^\s+|\s+$//g;
 1174: 	my @words = grep { !$stop->{lc $_} && _valid_location($_) } split /\s+/, $text;
 1175: 	my @ngrams;
 1176: 	for my $i (0 .. $#words - ($n - 1)) {
 1177: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
 1178: 	}
 1179: 	return @ngrams;
 1180: }

 1202: # Purpose:  Extract British-style addresses from free text.
 1203: # Entry:    $text — arbitrary string.
 1204: # Exit:     List of trimmed address strings.
 1205: sub _find_gb_addresses {
 1206: 	my $text = shift;
 1207: 	my @addresses;
 1208: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
 1209: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
 1210: 	# possible splits of a long string among 5 overlapping space-containing
 1211: 	# groups, causing exponential backtracking.  Making commas mandatory
 1212: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
 1213: 	# All groups are non-capturing (only $& is used).
 1214: 	my $re = qr/
 1215: 		\b
 1216: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
 1217: 		\s+
 1218: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
 1219: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
 1220: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
 1221: 		\s*,\s*                                   # COMMA REQUIRED
 1222: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
 1223: 		\s*,\s*                                   # COMMA REQUIRED
 1224: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
 1225: 		\b
 1226: 	/x;
 1227: 	while ($text =~ /$re/g) {
 1228: 		(my $addr = $&) =~ s/[,\s]+$//;
 1229: 		push @addresses, $addr;
 1230: 	}
 1231: 	return @addresses;
 1232: }

 1257: =head1 GETTING STARTED
 1258: 
 1259: To download, import and set up the local database:
 1260: before running C<make>, but after running C<perl Makefile.PL>, follow these instructions.
 1261: 
 1262: Optionally set C<OPENADDR_HOME> to point to an empty directory and download the data from
 1263: L<http://results.openaddresses.io> into that directory; and
 1264: optionally set C<WHOSONFIRST_HOME> to point to an empty directory and download the data using
 1265: L<https://github.com/nigelhorne/NJH-Snippets/blob/master/bin/wof-clone>.
 1266: The script C<bin/download_databases> (see below) will do those for you.
 1267: You do not need to download the MaxMind data — that is downloaded automatically.
 1268: 
 1269: You will need to create the database used by C<Geo::Coder::Free>.
 1270: 
 1271: Install L<App::csv2sqlite> and L<https://github.com/nigelhorne/NJH-Snippets>.
 1272: Run C<bin/create_sqlite> — this converts the MaxMind "cities" database from CSV to SQLite.
 1273: 
 1274: To use with MariaDB, set C<MARIADB_SERVER="$hostname;$port"> and
 1275: C<MARIADB_USER="$user;$password"> (TODO: username/password should be asked for interactively).
 1276: The code will use a database called C<geo_code_free>, which will be dropped and recreated if it exists.
 1277: C<$user> needs only DROP, CREATE, SELECT, INSERT, and INDEX privileges on that database.
 1278: 
 1279: The following optional steps download and install large databases.
 1280: This will take a long time and use a lot of disc space.
 1281: 
 1282: =over 4
 1283: 
 1284: =item 1
 1285: 
 1286: C<mkdir $WHOSONFIRST_HOME; cd $WHOSONFIRST_HOME> then run C<wof-clone> from NJH-Snippets.
 1287: 
 1288: This can take a long time because it contains many nested directories, which filesystem drivers
 1289: can be slow to navigate (particularly on EXT4 and ZFS).
 1290: 
 1291: =item 2
 1292: 
 1293: Install L<https://github.com/dr5hn/countries-states-cities-database.git> into C<$DR5HN_HOME>.
 1294: This data covers cities only, so it is not used when C<OSM_HOME> is set (OSM is far more
 1295: comprehensive).  Only Australia, Canada, and the US are imported, as the UK data is difficult
 1296: to parse.
 1297: 
 1298: =item 3
 1299: 
 1300: Run C<bin/download_databases> — this downloads the Who's On First, OpenAddr, OpenStreetMap,
 1301: and dr5hn databases.
 1302: OpenStreetMap now uses PBF files, so you will need C<apt install osmium-tool> first.
 1303: Check the values of C<OSM_HOME>, C<OPENADDR_HOME>, C<DR5HN_HOME> and C<WHOSONFIRST_HOME>
 1304: within that script and adjust them for your setup.
 1305: The C<Makefile.PL> file downloads the MaxMind database automatically, as it is not optional.
 1306: 
 1307: =item 4
 1308: 
 1309: Run C<bin/create_db> — this creates the database used by C<Geo::Coder::Free> from the data you

 1311: The database is called C<openaddr.sql> for historical reasons (before Who's On First was added);
 1312: it actually contains data from all sources above.
