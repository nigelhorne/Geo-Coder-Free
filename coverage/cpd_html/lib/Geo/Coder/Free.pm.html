   48: =head1 DESCRIPTION
   49: 
   50: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
   51: using local SQLite databases built from free data sources - MaxMind/GeoNames,
   52: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
   53: database.  It deliberately avoids paid or rate-limited online geocoding services.
   54: The module is designed to be flexible, supporting both command-line and programmatic usage.
   55: It also includes a sample CGI script for a web-based geocoding service.
   56: 
   57: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
   58: 
   59: B<With OpenAddresses data:>
   60: 
   61: =over 4
   62: 
   63: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
   64: 
   65: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
   66: 
   67: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
   68: 
   69: =back
   70: 
   71: B<Without OpenAddresses data:>
   72: 
   73: =over 4
   74: 
   75: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
   76: 
   77: =back
   78: 
   79: The C<cgi-bin> directory contains a simple DIY geo-coding website:
   80: 
   81:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
   82: 
   83: The sample website is currently down while a new host is sought.
   84: When it returns, you will be able to test it with:
   85: 
   86:     curl 'https://geocode.nigelhorne.com/cgi-bin/page.fcgi?page=query&q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA'
   87: 
   88: =head1 LIMITATIONS
   89: 
   90: =over 4
   91: 
   92: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
   93: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
   94: 
   95: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
   96: user-editable config file.
   97: 
   98: =item * The address-regex scantext path misses birth-year sentences such as
   99: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  100: a preceding capital-letter word directly before the city.
  101: 
  102: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  103: not return meaningful results.
  104: 
  105: =item * The C<alternatives> map loop uses C<each %{$alt}>, which retains its
  106: iterator position across calls.  After a successful match and early C<return>,
  107: the next C<geocode()> call on the same input starts iterating from the key
  108: B<after> the matched one, potentially missing the match entirely until C<each>
  109: wraps around.  Workaround: call C<keys %{$alt}> once to reset the iterator
  110: before iterating.
  111: 
  112: =back
  113:

  258:     # Standard lookup (returns a Geo::Location::Point or undef)
  259:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  260:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  261: 
  262:     # Scantext - returns a list of Geo::Location::Point objects
  263:     my @hits = $geo->geocode(
  264:         scantext     => 'She lived in Ramsgate, Kent.',
  265:         region       => 'GB',
  266:         ignore_words => [qw(lived)],
  267:     );
  268: 
  269:     # Invocation flexibility (all equivalent)
  270:     $geo->geocode('Ramsgate, Kent, UK');
  271:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  272:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  273: 
  274: =head3 API SPECIFICATION
  275: 
  276: =head4 input
  277: 
  278:     # Input schema (Params::Validate::Strict) - exactly one of location or scantext is required
  279:     location     => { type => 'scalar',   optional => 1 }  # address string (exclusive with scantext)
  280:     scantext     => { type => 'scalar',   optional => 1 }  # free text to scan for place names
  281:     region       => { type => 'scalar',   optional => 1 }  # ISO 3166-1 alpha-2 country code hint
  282:     ignore_words => { type => 'arrayref', optional => 1 }  # words to suppress during scantext scan
  283: 
  284: =head4 output
  285: 
  286:     # Output schema (Return::Set)
  287:     # scalar context: { type => 'object',   isa => 'Geo::Location::Point', optional => 1 }
  288:     # list context:   { type => 'arrayref', of  => { isa => 'Geo::Location::Point' } }
  289: 
  290: =head4 provenance
  291: 
  292: Every result carries C<geocoder>, C<database>, C<confidence> and C<accuracy>
  293: (section 2.1 of F<BI-Phase6-Dependency-Specs.md>): which distribution produced
  294: it, which backend answered, how good the match was, and how precise the
  295: coordinate is.  C<provenance()> reads the four back.  C<location> is set by every
  296: path but the MaxMind cities one, and C<text> only by a scantext lookup; C<lat>,
  297: C<long> and C<lng> come from the value object itself.
  298: 
  299: =head3 MESSAGES
  300: 
  301:     Usage: ...::geocode(...)        No location or scantext argument given.
  302:     invalid location to geocode()   location is purely numeric.
  303:     invalid scantext to geocode()   scantext is purely numeric.
  304: 
  305: =head3 PSEUDOCODE
  306: 
  307:     if self is not a blessed object → delegate to new()->geocode(@args)
  308:     normalise @_ into %params
  309:     validate: location is not purely numeric; scantext is not purely numeric
  310:     if openaddr backend is available:
  311:         if scantext:
  312:             try the raw scantext string as a direct location
  313:             build stopword set from %_COMMON_WORDS + ignore_words param
  314:             try 3-word windows (triplets) at confidence 0.8
  315:             try 2-word windows (duplets) at confidence 0.7
  316:             try the address-pattern regex at confidence 0.7
  317:             try region-specific address finders (GB / US / CA)
  318:             mark scantext as a miss; return undef
  319:         else:
  320:             try openaddr backend
  321:             try local backend
  322:             try __DATA__ alternatives map
  323:     try maxmind backend for location lookups
  324:     croak if no scantext and no location
  325: 
  326: =cut

  328: sub geocode {
  329: 	my $self = shift;
  330: 
  331: 	# Handle being called as a function rather than a method
  332: 	if (!ref($self)) {
  333: 		if (scalar @_) {
  334: 			return __PACKAGE__->new()->geocode(@_);
  335: 		} elsif (!defined($self)) {
  336: 			Carp::croak(_i18n('usage_geocode', __PACKAGE__));
  337: 		} elsif ($self eq __PACKAGE__) {
  338: 			Carp::croak(_i18n('usage_geocode', $self));
  339: 		}
  340: 		return __PACKAGE__->new()->geocode($self);
  341: 	} elsif (ref($self) eq 'HASH') {
  342: 		return __PACKAGE__->new()->geocode($self);
  343: 	}
  344: 
  345: 	my %params = _normalize_args(_i18n('usage_geocode', __PACKAGE__), 'location', @_);
  346: 
  347: 	# Reject pure-numeric inputs early — they are never valid addresses
  348: 	if (defined($params{'location'}) && $params{'location'} !~ /\D/) {
  349: 		Carp::croak(_i18n('invalid_location', __PACKAGE__, $params{'location'}))
  350: 			if length($params{'location'});
  351: 		return;
  352: 	}
  353: 	if (defined($params{'scantext'}) && $params{'scantext'} !~ /\D/) {
  354: 		Carp::croak(_i18n('invalid_scantext', __PACKAGE__, $params{'scantext'}))
  355: 			if length($params{'scantext'});
  356: 		return;
  357: 	}
  358: 
  359: 	if ($self->{'openaddr'}) {
  360: 		if (my $scantext = $params{'scantext'}) {
  361: 			return if $self->{'scantext_misses'}{$scantext};
  362: 
  363: 			# First try the whole scantext as a direct location lookup —
  364: 			# saves work when the text happens to be a valid address string.
  365: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  366: 			my @direct = grep { defined }
  367: 				$self->{'local'}->geocode($scantext),
  368: 				$self->{'openaddr'}->geocode($scantext),
  369: 				$self->{'maxmind'}->geocode($scantext);
  370: 			return @direct if @direct;
  371: 
  372: 			my $region = $params{'region'};
  373: 
  374: 			# Build the effective stopword set.  When the caller supplies no
  375: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  376: 			# at runtime) by using a reference to it directly.  Only when extra
  377: 			# words are needed do we allocate and populate a merged hash.
  378: 			my $ignore_words;
  379: 			if (my $iw = $params{'ignore_words'}) {
  380: 				my %merged = %_COMMON_WORDS;
  381: 				$merged{lc $_} = 1 for @{$iw};
  382: 				$ignore_words = \%merged;
  383: 			} else {
  384: 				$ignore_words = \%_COMMON_WORDS;
  385: 			}
  386: 
  387: 			my @rc;
  388: 
  389: 			# 3-word window search
  390: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  391: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  392: 			if (@{$res}) {
  393: 				return wantarray ? @{$res} : $res->[0];
  394: 			}
  395: 
  396: 			# 2-word window search
  397: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  398: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  399: 			if (@{$res}) {
  400: 				return wantarray ? @{$res} : $res->[0];
  401: 			}
  402:

  405: 			# because the pattern requires a capitalised word before the city.
  406: 			my @regex_matches = $scantext =~

  411: 			if (@{$res}) {
  412: 				return wantarray ? @{$res} : $res->[0];
  413: 			}

  419: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  420: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }

  422: 				if (@candidates) {

  425: 						next if $ignore_words->{lc $candidate};

  427: 							$self->{'openaddr'}->geocode("$candidate, $region");
  428: 						push @regional, @hits if @hits;
  429: 					}
  430: 					return @regional if @regional;
  431: 				}
  432: 			}
  433: 
  434: 			$self->{'scantext_misses'}{$scantext} = 1;
  435: 			return;
  436: 		}
  437: 
  438: 		# Standard (non-scantext) lookup path
  439: 		if (wantarray) {
  440: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  441: 			return @rc if @rc && $rc[0];
  442: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  443: 			@rc = $self->{'local'}->geocode(\%params);
  444: 			return @rc if @rc && $rc[0];
  445: 		} else {
  446: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  447: 				return $rc;
  448: 			}
  449: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  450: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  451: 				return $rc;
  452: 			}
  453: 		}
  454: 
  455: 		# Try the alternatives table — hand-curated mappings for locations that
  456: 		# the databases have under slightly different names.
  457: 		# M3 (transitive reduction): every scantext path inside this block returned
  458: 		# early above; at this point $params{'scantext'} is provably falsy, so the

  460: 		if (my $alt = $self->{'alternatives'}) {
  461: 			my $location = $params{'location'};
  462: 			while (my ($key, $value) = each %{$alt}) {
  463: 				next unless $location =~ $key;
  464: 				(my $new_loc = $location) =~ s/$key/$value/;
  465: 				$params{'location'} = $new_loc;
  466: 				if (my $rc = $self->geocode(\%params)) {
  467: 					return $rc;
  468: 				}

  470: 				if ($value =~ /, /) {
  471: 					(my $flat = $value) =~ s/,//g;
  472: 					($new_loc = $location) =~ s/$key/$flat/;
  473: 					$params{'location'} = $new_loc;
  474: 					if (my $rc = $self->geocode(\%params)) {
  475: 						return $rc;
  476: 					}
  477: 				}
  478: 				# Restore for the next iteration
  479: 				$params{'location'} = $location;
  480: 			}
  481: 		}
  482: 	}

  485: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;

  490: 		return $self->{'maxmind'}->geocode(\%params);
  491: 	}
  492: 
  493: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  494: 	return;

  497: =head2 provenance
  498: 
  499:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
  500: 
  501: or, in scalar context, the same four as a hashref:
  502: 
  503:     my $provenance = $geocoder->provenance($point);

  505: 
  506: Where a result came from and how good it is, so that a caller does not have to
  507: reach for the hash keys itself (section 2.1 of F<BI-Phase6-Dependency-Specs.md>):
  508: 
  509: =over 4
  510: 
  511: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
  512: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
  513: that passed it on, such as C<Geo::Coder::List>.
  514: 
  515: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
  516: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
  517: the distribution's prefix removed, so that the two spellings the backends use -
  518: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
  519: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
  520: consumers that already match on it.
  521: 
  522: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
  523: 
  524: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
  525: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
  526: 
  527: =back
  528: 
  529: Returns an empty list - and an empty hashref in scalar context - when handed
  530: something that is not a result.  A key a result does not carry comes back
  531: C<undef> rather than being guessed at, because a plain hash from another
  532: geocoder has no provenance to report.
  533: 
  534: =cut
  535: 
  536: sub provenance {
  537: 	my ($self, $point) = @_;
  538: 
  539: 	return wantarray ? () : {} unless defined($point) && ref($point)
  540: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
  541: 
  542: 	my $dist    = $point->{'geocoder'};
  543: 	my $backend = $point->{'database'};
  544: 	$backend =~ s/^Geo::Coder::Free::// if defined($backend);
  545: 
  546: 	my %provenance = (
  547: 		dist       => $dist,
  548: 		backend    => $backend,
  549: 		confidence => $point->{'confidence'},
  550: 		accuracy   => $point->{'accuracy'},
  551: 	);
  552: 
  553: 	return wantarray ? @provenance{qw(dist backend confidence accuracy)} : \%provenance;
  554: }

  556: =head2 reverse_geocode
  557: 
  558: =head3 SYNOPSIS
  559: 
  560:     my $loc = $geo->reverse_geocode(latlng => '51.3341,-1.4159');
  561: 
  562: =head3 DESCRIPTION
  563: 
  564: Translates a latitude/longitude pair back to a place name.
  565: B<Partially implemented>: the MaxMind backend does not return meaningful results.
  566: OpenAddresses is attempted first when available.
  567: 
  568: =head3 API SPECIFICATION
  569: 
  570: =head4 input
  571: 
  572:     # Input schema (Params::Validate::Strict) — latlng required
  573:     latlng => { type => 'scalar' }  # "$lat,$long" comma-separated decimal degrees
  574:     # NOTE: separate lat/lon/long keys are NOT supported at the Geo::Coder::Free
  575:     # (facade) level.  When no OpenAddresses backend is configured, passing
  576:     # lat/lon/long instead of latlng will croak "not yet supported".
  577:     # To use separate coordinates call Geo::Coder::Free::Local::reverse_geocode.
  578: 
  579: =head4 output
  580: 
  581:     # Output schema (Return::Set)
  582:     { type => 'object', isa => 'Geo::Location::Point', optional => 1 }
  583: 
  584: =cut
  585: 
  586: sub reverse_geocode {
  587: 	my $self = shift;
  588: 
  589: 	if (!ref($self)) {
  590: 		if (scalar @_) {
  591: 			return __PACKAGE__->new()->reverse_geocode(@_);
  592: 		} elsif (!defined($self)) {
  593: 			Carp::croak(_i18n('usage_reverse', __PACKAGE__));
  594: 		} elsif ($self eq __PACKAGE__) {
  595: 			Carp::croak(_i18n('usage_reverse', $self));
  596: 		}
  597: 		return __PACKAGE__->new()->reverse_geocode($self);
  598: 	} elsif (ref($self) eq 'HASH') {
  599: 		return __PACKAGE__->new()->reverse_geocode($self);
  600: 	}
  601: 
  602: 	my %params = _normalize_args(_i18n('usage_reverse', __PACKAGE__), 'latlng', @_);
  603: 
  604: 	# M8 (tautology — same pattern fixed in geocode): both arms are identical;
  605: 	# context propagates implicitly through return.
  606: 	if ($self->{'openaddr'}) {
  607: 		return $self->{'openaddr'}->reverse_geocode(\%params);
  608: 	}
  609: 	if ($params{'latlng'}) {
  610: 		return $self->{'maxmind'}->reverse_geocode(\%params);
  611: 	}
  612: 
  613: 	Carp::croak(_i18n('reverse_unsupported'));
  614: }

  634: sub run {
  635: 	require Data::Dumper;
  636: 
  637: 	my $class    = shift;
  638: 	my $location = join ' ', @_;
  639: 
  640: 	my @rc = $ENV{'OPENADDR_HOME'}
  641: 		? $class->new(openaddr => $ENV{'OPENADDR_HOME'})->geocode($location)
  642: 		: $class->new()->geocode($location);

  649: # -----------------------------------------------------------------------
  650: # Private helpers
  651: # -----------------------------------------------------------------------
  652: 
  653: # Purpose:  Return a formatted message string from the message table.
  654: #           Falls back to the raw key so call sites never die on a missing key.
  655: # Entry:    $key — message key; @args — sprintf format arguments.
  656: # Exit:     Formatted string.
  657: sub _i18n {
  658: 	my ($key, @args) = @_;
  659: 	my $fmt = $_MESSAGES{$key} // $key;
  660: 	return @args ? sprintf($fmt, @args) : $fmt;
  661: }
  662: 
  663: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
  664: #             hashref, even-length key-val list, odd-length list, single bare string.
  665: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
  666: #           $bare_key  — hash key to assign to a single bare string argument
  667: #                        ('location' for geocode, 'latlng' for reverse_geocode).
  668: #           @args — raw @_ after $self has been shifted.
  669: # Exit:     Flat key-value %params hash.
  670: # Side Effects: None; croaks on unsupported reference argument.
  671: sub _normalize_args {
  672: 	my ($error_msg, $bare_key, @args) = @_;
  673: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
  674: 	Carp::croak($error_msg)         if ref($args[0]);
  675: 	return @args                    if @args && @args % 2 == 0;
  676: 	return ($bare_key => $args[0])  if @args == 1;
  677: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
  678: 	# The former code silently returned () here, discarding the trailing elements.
  679: 	# Fail fast instead of propagating a malformed argument list downstream.
  680: 	Carp::croak($error_msg)         if @args;
  681: 	return ();
  682: }
  683: 
  684: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
  685: #           annotating every hit with location/text/confidence metadata and
  686: #           memoising misses to avoid re-querying the same failing string.
  687: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
  688: #           $candidates — arrayref of place-name strings to probe.
  689: #           $region     — optional ISO country code appended to each candidate.
  690: #           $confidence — numeric confidence score assigned to all hits.
  691: #           $scantext   — original free text (stored inside each result object).
  692: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
  693: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
  694: sub _resolve_scan_candidates {
  695: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
  696: 	my @results;
  697: 	for my $place (@{$candidates}) {
  698: 		my $location = $region ? "$place, $region" : $place;
  699: 		next if $self->{'scantext_misses'}{$location};
  700: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
  701: 		if (@res) {
  702: 			for my $entry (@res) {
  703: 				$entry->{'location'}   = $location;
  704: 				$entry->{'text'}       = $scantext;
  705: 				$entry->{'confidence'} = $confidence;
  706: 			}
  707: 			push @results, @res;
  708: 		} else {
  709: 			$self->{'scantext_misses'}{$location} = 1;
  710: 		}
  711: 	}
  712: 	return \@results;
  713: }
  714: 
  715: # Purpose:  Slide a window of $n words across $text and return all comma-joined
  716: #           n-grams, excluding pure-numeric tokens and stopwords.
  717: #           Replaces the former _find_word_triplets ($n=3) and
  718: #           _find_word_duplets ($n=2) which were identical except for window size
  719: #           and the duplets version was missing the lc() normalisation on stopwords.
  720: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
  721: # Exit:     Flat list of n-gram strings.
  722: sub _find_word_ngrams {
  723: 	my ($text, $n, $stop) = @_;
  724: 	$text =~ s/,+/ /g;
  725: 	$text =~ s/\s+/ /g;
  726: 	$text =~ s/^\s+|\s+$//g;
  727: 	my @words = grep { !/^\d+$/ && !$stop->{lc $_} } split /\s+/, $text;
  728: 	my @ngrams;
  729: 	for my $i (0 .. $#words - ($n - 1)) {
  730: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
  731: 	}
  732: 	return @ngrams;
  733: }

  735: # Purpose:  Extract structured US street addresses from free text.
  736: # Entry:    $text — arbitrary string.
  737: # Exit:     List of full address strings matching the US pattern.
  738: sub _find_us_addresses {
  739: 	my $text = shift;
  740: 	my @addresses;
  741: 	my $re = qr/
  742: 		\b \d{1,5} \s+                                      # house number
  743: 		(?:[A-Za-z0-9]+(?:\s+[A-Za-z0-9]+){0,6}) \s+       # street name: 1–7 words (bounded)
  744: 		(?:Avenue|Ave\.?|Boulevard|Blvd\.?|Road|Rd\.?|Lane|Ln\.?|Drive|Dr\.?|Street|St\.?)
  745: 		(?:\s+[A-Za-z]{2})? ,\s*
  746: 		(?:[A-Za-z]+(?:\s+[A-Za-z]+){0,3}) ,\s*            # city: 1–4 words
  747: 		[A-Z]{2} \s* (?:\d{5}(?:-\d{4})?)? \b              # state + optional zip
  748: 	/x;
  749: 	while ($text =~ /$re/g) {
  750: 		push @addresses, $&;
  751: 	}
  752: 	return @addresses;
  753: }
  754: 
  755: # Purpose:  Extract British-style addresses from free text.
  756: # Entry:    $text — arbitrary string.
  757: # Exit:     List of trimmed address strings.
  758: sub _find_gb_addresses {
  759: 	my $text = shift;
  760: 	my @addresses;
  761: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
  762: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
  763: 	# possible splits of a long string among 5 overlapping space-containing
  764: 	# groups, causing exponential backtracking.  Making commas mandatory
  765: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
  766: 	# All groups are non-capturing (only $& is used).
  767: 	my $re = qr/
  768: 		\b
  769: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
  770: 		\s+
  771: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
  772: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
  773: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
  774: 		\s*,\s*                                   # COMMA REQUIRED
  775: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
  776: 		\s*,\s*                                   # COMMA REQUIRED
  777: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
  778: 		\b
  779: 	/x;
  780: 	while ($text =~ /$re/g) {
  781: 		(my $addr = $&) =~ s/[,\s]+$//;
  782: 		push @addresses, $addr;
  783: 	}
  784: 	return @addresses;
  785: }

  787: # Purpose:  Extract Canadian street addresses from free text.
  788: # Entry:    $text — arbitrary string.
  789: # Exit:     List of full address strings matching the Canadian pattern.
  790: sub _find_ca_addresses {
  791: 	my $text = shift;
  792: 	my @addresses;
  793: 	my $re = qr/
  794: 		\b \d{1,5} \s+                                         # house number
  795: 		(?:[A-Za-z0-9]+(?:\s+[A-Za-z0-9]+){0,6}) \s+          # street name: 1–7 words (bounded)
  796: 		(?:Avenue|Ave\.?|Boulevard|Blvd\.?|Road|Rd\.?|Lane|Ln\.?|Drive|Dr\.?|Street|St\.?|Circle|Crescent|Cres\.?)
  797: 		\s*,\s*
  798: 		(?:[A-Za-z]+(?:\s+[A-Za-z]+){0,3}) \s*,\s*            # city: 1–4 words
  799: 		[A-Z]{2} \s*,?\s*
  800: 		(?:[A-Z]\d[A-Z]\s?\d[A-Z]\d)? \b                      # optional postal code
  801: 	/x;
  802: 	while ($text =~ /$re/g) {
  803: 		push @addresses, $&;
  804: 	}
  805: 	return @addresses;

  810: =head1 GETTING STARTED
  811: 
  812: To download, import and set up the local database:
  813: before running C<make>, but after running C<perl Makefile.PL>, follow these instructions.
  814: 
  815: Optionally set C<OPENADDR_HOME> to point to an empty directory and download the data from
  816: L<http://results.openaddresses.io> into that directory; and
  817: optionally set C<WHOSONFIRST_HOME> to point to an empty directory and download the data using
  818: L<https://github.com/nigelhorne/NJH-Snippets/blob/master/bin/wof-clone>.
  819: The script C<bin/download_databases> (see below) will do those for you.
  820: You do not need to download the MaxMind data — that is downloaded automatically.
  821: 
  822: You will need to create the database used by C<Geo::Coder::Free>.
  823: 
  824: Install L<App::csv2sqlite> and L<https://github.com/nigelhorne/NJH-Snippets>.
  825: Run C<bin/create_sqlite> — this converts the MaxMind "cities" database from CSV to SQLite.
  826: 
  827: To use with MariaDB, set C<MARIADB_SERVER="$hostname;$port"> and
  828: C<MARIADB_USER="$user;$password"> (TODO: username/password should be asked for interactively).
  829: The code will use a database called C<geo_code_free>, which will be dropped and recreated if it exists.
  830: C<$user> needs only DROP, CREATE, SELECT, INSERT, and INDEX privileges on that database.
  831: 
  832: The following optional steps download and install large databases.
  833: This will take a long time and use a lot of disc space.
  834: 
  835: =over 4
  836: 
  837: =item 1
  838: 
  839: C<mkdir $WHOSONFIRST_HOME; cd $WHOSONFIRST_HOME> then run C<wof-clone> from NJH-Snippets.
  840: 
  841: This can take a long time because it contains many nested directories, which filesystem drivers
  842: can be slow to navigate (particularly on EXT4 and ZFS).
  843: 
  844: =item 2
  845: 
  846: Install L<https://github.com/dr5hn/countries-states-cities-database.git> into C<$DR5HN_HOME>.
  847: This data covers cities only, so it is not used when C<OSM_HOME> is set (OSM is far more
  848: comprehensive).  Only Australia, Canada, and the US are imported, as the UK data is difficult
  849: to parse.
  850: 
  851: =item 3
  852: 
  853: Run C<bin/download_databases> — this downloads the Who's On First, OpenAddr, OpenStreetMap,
  854: and dr5hn databases.
  855: OpenStreetMap now uses PBF files, so you will need C<apt install osmium-tool> first.
  856: Check the values of C<OSM_HOME>, C<OPENADDR_HOME>, C<DR5HN_HOME> and C<WHOSONFIRST_HOME>
  857: within that script and adjust them for your setup.
  858: The C<Makefile.PL> file downloads the MaxMind database automatically, as it is not optional.
  859: 
  860: =item 4
  861: 
  862: Run C<bin/create_db> — this creates the database used by C<Geo::Coder::Free> from the data you
  863: have just downloaded.
  864: The database is called C<openaddr.sql> for historical reasons (before Who's On First was added);
  865: it actually contains data from all sources above.
  866: 
  867: =back
  868: 
  869: Now you are ready to run C<make>.
  870: See the comment at the start of C<createdatabase.PL> for further details.
