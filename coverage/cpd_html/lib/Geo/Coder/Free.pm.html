   49: =head1 DESCRIPTION
   50: 
   51: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
   52: using local SQLite databases built from free data sources - MaxMind/GeoNames,
   53: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
   54: database.  It deliberately avoids paid or rate-limited online geocoding services.
   55: The module is designed to be flexible, supporting both command-line and programmatic usage.
   56: It also includes a sample CGI script for a web-based geocoding service.
   57: 
   58: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
   59: 
   60: B<With OpenAddresses data:>
   61: 
   62: =over 4
   63: 
   64: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
   65: 
   66: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
   67: 
   68: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
   69: 
   70: =back
   71: 
   72: B<Without OpenAddresses data:>
   73: 
   74: =over 4
   75: 
   76: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
   77: 
   78: =back
   79: 
   80: The C<cgi-bin> directory contains a simple DIY geo-coding website:
   81: 
   82:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
   83: 
   84: The sample website is currently down while a new host is sought.
   85: When it returns, you will be able to test it with:
   86: 
   87:     curl 'https://geocode.nigelhorne.com/cgi-bin/page.fcgi?page=query&q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA'
   88: 
   89: =head1 LIMITATIONS
   90: 
   91: =over 4
   92: 
   93: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
   94: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
   95: 
   96: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
   97: user-editable config file.
   98: 
   99: =item * The address-regex scantext path misses birth-year sentences such as
  100: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  101: a preceding capital-letter word directly before the city.
  102: 
  103: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  104: not return meaningful results.
  105: 
  106: =item * The C<alternatives> map loop uses C<each %{$alt}>, which retains its
  107: iterator position across calls.  After a successful match and early C<return>,
  108: the next C<geocode()> call on the same input starts iterating from the key
  109: B<after> the matched one, potentially missing the match entirely until C<each>
  110: wraps around.  Workaround: call C<keys %{$alt}> once to reset the iterator
  111: before iterating.
  112: 
  113: =back
  114:

  256: =head2 valid_location
  257: 
  258: =head3 SYNOPSIS
  259: 
  260:     if ($geo->valid_location($row->{'place'})) {
  261:         push @found, $geo->geocode(location => $row->{'place'});
  262:     }
  263: 
  264: =head3 DESCRIPTION
  265: 
  266: Answers whether a string is something this module will even try to look up.
  267: It is the public form of the rule C<geocode()> applies before it touches a
  268: backend, so a caller working down a spreadsheet column can skip a row whose
  269: value is a bare number - or is empty - instead of catching the croak that
  270: would otherwise kill the whole run.  That rule is defined once, in
  271: L<Geo::Coder::Free::Validate>, and the backends apply it too: what
  272: C<valid_location()> refuses is refused wherever it is looked up.
  273: 
  274: Only that cheap syntactic test is answered.  A true result means the string is
  275: not disqualified, B<not> that a backend knows it: C<'Ramsgate, Kent'> is valid
  276: and may still find nothing, while C<'0044'> is invalid and is never looked up.
  277: The rule rejects a string of digits only, which is what a numeric column holds
  278: when the wrong column has been read, so anything with a non-digit in it counts
  279: as valid - C<'3.14'> and C<'-'> included.  C<undef>, C<''> and a reference are
  280: not valid.
  281: 
  282: =head3 API SPECIFICATION
  283: 
  284: =head4 input
  285: 
  286:     location => { type => 'scalar', optional => 1 }  # the string to test
  287: 
  288: =head4 output
  289: 
  290:     { type => 'boolean' }  # false for undef, '' and a digit-only string
  291: 
  292: =head3 EXAMPLE
  293: 
  294:     my $geo = Geo::Coder::Free->new();
  295: 
  296:     $geo->valid_location('Ramsgate, Kent');   # true
  297:     $geo->valid_location('0044');             # false - never a location
  298:     $geo->valid_location('');                 # false
  299:     $geo->valid_location(undef);              # false
  300: 
  301: Accepts the three calling conventions the rest of this module does:
  302: 
  303:     $geo->valid_location('0044');
  304:     Geo::Coder::Free->valid_location('0044');
  305:     Geo::Coder::Free::valid_location('0044');
  306: 
  307: =cut

  309: sub valid_location {
  310: 	my $self = shift;
  311: 
  312: 	# The location is whichever argument is not the invocant, so that the
  313: 	# predicate reads the same whether it is called on an instance, on the
  314: 	# class or as a plain function.
  315: 	my $location;
  316: 	if (ref($self)) {
  317: 		$location = shift;
  318: 	} elsif (@_) {
  319: 		$location = shift;
  320: 	} elsif (defined($self) && $self ne __PACKAGE__) {
  321: 		$location = $self;
  322: 	}
  323: 
  324: 	return _valid_location($location) ? 1 : 0;
  325: }

  327: =head2 geocode
  328: 
  329: =head3 SYNOPSIS
  330: 
  331:     # Standard lookup (returns a Geo::Location::Point or undef)
  332:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  333:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  334: 
  335:     # Scantext - returns a list of Geo::Location::Point objects
  336:     my @hits = $geo->geocode(
  337:         scantext     => 'She lived in Ramsgate, Kent.',
  338:         region       => 'GB',
  339:         ignore_words => [qw(lived)],
  340:     );
  341: 
  342:     # Invocation flexibility (all equivalent)
  343:     $geo->geocode('Ramsgate, Kent, UK');
  344:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  345:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  346: 
  347:     # A batch caller with a dirty column: skip the row, do not kill the run
  348:     for my $place (@column) {
  349:         my $pt = $geo->geocode(location => $place, on_error => 'undef');
  350:         next unless defined $pt;
  351:         push @found, $pt;
  352:     }
  353: 
  354: =head3 DESCRIPTION
  355: 
  356: A location or a scantext that is not a location at all - a bare number, such as
  357: the C<0044> a numeric column holds - is refused before any backend is
  358: touched.  C<valid_location()> answers the same question, so a caller can filter
  359: first; C<on_error> chooses what happens when one gets through anyway:
  360: 
  361: =over 4
  362: 
  363: =item * C<'croak'> (the default) - C<Carp::croak>, the behaviour every existing
  364: caller already has.
  365: 
  366: =item * C<'undef'> - return C<undef>, so one bad row in a spreadsheet column is
  367: skipped rather than ending the run.  It changes the answer for B<only> the two
  368: documented input errors below; an exception from a backend is still an
  369: exception, and a malformed argument list still croaks.
  370: 
  371: =back
  372: 
  373: The option is deliberately narrow, so a batch caller wants C<valid_location()>
  374: with it: that predicate answers false for C<undef> and C<''> as well, which are
  375: the other two things an empty cell holds.  A call with neither a location nor a
  376: scantext is a usage error rather than an input error - the same croak as calling
  377: C<geocode()> with no arguments - and stays a croak on either setting.
  378: 
  379: =head3 API SPECIFICATION
  380: 
  381: =head4 input
  382: 
  383:     # Input schema (Params::Validate::Strict) - exactly one of location or scantext is required
  384:     location     => { type => 'scalar',   optional => 1 }  # address string (exclusive with scantext)
  385:     scantext     => { type => 'scalar',   optional => 1 }  # free text to scan for place names
  386:     region       => { type => 'scalar',   optional => 1 }  # ISO 3166-1 alpha-2 country code hint
  387:     ignore_words => { type => 'arrayref', optional => 1 }  # words to suppress during scantext scan
  388:     on_error     => { type => 'scalar',   optional => 1 }  # 'croak' (default) or 'undef'
  389: 
  390: =head4 output
  391: 
  392:     # Output schema (Return::Set)
  393:     # scalar context: { type => 'object',   isa => 'Geo::Location::Point', optional => 1 }
  394:     # list context:   { type => 'arrayref', of  => { isa => 'Geo::Location::Point' } }
  395: 
  396: =head4 provenance
  397: 
  398: Every result carries C<geocoder>, C<database>, C<confidence> and C<accuracy>
  399: (section 2.1 of F<BI-Phase6-Dependency-Specs.md>): which distribution produced
  400: it, which backend answered, how good the match was, and how precise the
  401: coordinate is.  C<provenance()> reads the four back.  C<location> is set by every
  402: path but the MaxMind cities one, and C<text> only by a scantext lookup; C<lat>,
  403: C<long> and C<lng> come from the value object itself.
  404: 
  405: =head3 MESSAGES
  406: 
  407:     Usage: ...::geocode(...)        No location or scantext argument given.
  408:     invalid location to geocode()   location is purely numeric.
  409:     invalid scantext to geocode()   scantext is purely numeric.
  410:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  411: 
  412: =head3 PSEUDOCODE
  413: 
  414:     if self is not a blessed object → delegate to new()->geocode(@args)
  415:     normalise @_ into %params
  416:     validate: on_error is 'croak' or 'undef' (croak if not)
  417:     validate: location is not purely numeric; scantext is not purely numeric
  418:               (undef instead of croaking when on_error is 'undef')
  419:     if openaddr backend is available:
  420:         if scantext:
  421:             try the raw scantext string as a direct location
  422:             build stopword set from %_COMMON_WORDS + ignore_words param
  423:             try 3-word windows (triplets) at confidence 0.8
  424:             try 2-word windows (duplets) at confidence 0.7
  425:             try the address-pattern regex at confidence 0.7
  426:             try region-specific address finders (GB / US / CA)
  427:             mark scantext as a miss; return undef
  428:         else:
  429:             try openaddr backend
  430:             try local backend
  431:             try __DATA__ alternatives map
  432:     try maxmind backend for location lookups
  433:     croak if no scantext and no location
  434: 
  435: =cut

  437: sub geocode {
  438: 	my $self = shift;
  439: 
  440: 	# Handle being called as a function rather than a method
  441: 	if (!ref($self)) {
  442: 		if (scalar @_) {
  443: 			return __PACKAGE__->new()->geocode(@_);
  444: 		} elsif (!defined($self)) {
  445: 			Carp::croak(_i18n('usage_geocode', __PACKAGE__));
  446: 		} elsif ($self eq __PACKAGE__) {
  447: 			Carp::croak(_i18n('usage_geocode', $self));
  448: 		}
  449: 		return __PACKAGE__->new()->geocode($self);
  450: 	} elsif (ref($self) eq 'HASH') {
  451: 		return __PACKAGE__->new()->geocode($self);
  452: 	}
  453: 
  454: 	my %params = _normalize_args(_i18n('usage_geocode', __PACKAGE__), 'location', @_);
  455: 
  456: 	# What to do with an input this module rejects before it touches a backend.
  457: 	# 'croak' is the historical behaviour and stays the default, so no existing
  458: 	# caller changes; 'undef' is for a batch caller working down a dirty column,
  459: 	# which wants the row skipped rather than the whole run killed.  Only the two
  460: 	# input errors below consult it: a backend that throws still throws, because
  461: 	# nothing here is wrapped in an eval (section 2.4 of
  462: 	# BI-Phase6-Dependency-Specs.md).
  463: 	my $on_error = $params{'on_error'} // 'croak';
  464: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  465: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  466: 
  467: 	# Reject pure-numeric inputs early — they are never valid addresses.
  468: 	# The rule is Geo::Coder::Free::Validate's, the same one the backends
  469: 	# apply, and valid_location() answers it in public, so a caller can
  470: 	# pre-filter with it and never reach this croak at all.
  471: 	if (defined($params{'location'}) && !_valid_location($params{'location'})) {
  472: 		return if !length($params{'location'}) || ($on_error eq 'undef');
  473: 		Carp::croak(_i18n('invalid_location', __PACKAGE__, $params{'location'}));
  474: 	}
  475: 	if (defined($params{'scantext'}) && !_valid_location($params{'scantext'})) {
  476: 		return if !length($params{'scantext'}) || ($on_error eq 'undef');
  477: 		Carp::croak(_i18n('invalid_scantext', __PACKAGE__, $params{'scantext'}));
  478: 	}
  479: 
  480: 	if ($self->{'openaddr'}) {
  481: 		if (my $scantext = $params{'scantext'}) {
  482: 			return if $self->{'scantext_misses'}{$scantext};
  483: 
  484: 			# First try the whole scantext as a direct location lookup —
  485: 			# saves work when the text happens to be a valid address string.
  486: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  487: 			my @direct = grep { defined }
  488: 				$self->{'local'}->geocode($scantext),
  489: 				$self->{'openaddr'}->geocode($scantext),
  490: 				$self->{'maxmind'}->geocode($scantext);
  491: 			return @direct if @direct;
  492: 
  493: 			my $region = $params{'region'};
  494: 
  495: 			# Build the effective stopword set.  When the caller supplies no
  496: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  497: 			# at runtime) by using a reference to it directly.  Only when extra
  498: 			# words are needed do we allocate and populate a merged hash.
  499: 			my $ignore_words;
  500: 			if (my $iw = $params{'ignore_words'}) {
  501: 				my %merged = %_COMMON_WORDS;
  502: 				$merged{lc $_} = 1 for @{$iw};
  503: 				$ignore_words = \%merged;
  504: 			} else {
  505: 				$ignore_words = \%_COMMON_WORDS;
  506: 			}
  507: 
  508: 			my @rc;
  509: 
  510: 			# 3-word window search
  511: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  512: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  513: 			if (@{$res}) {
  514: 				return wantarray ? @{$res} : $res->[0];
  515: 			}
  516: 
  517: 			# 2-word window search
  518: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  519: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  520: 			if (@{$res}) {
  521: 				return wantarray ? @{$res} : $res->[0];
  522: 			}
  523: 
  524: 			# Regex-based address pattern — catches "City, ST"-style fragments.
  525: 			# Note: misses sentences like "born May 21, 1937 in Noblesville, IN"
  526: 			# because the pattern requires a capitalised word before the city.
  527: 			my @regex_matches = $scantext =~
  528: 				/\b(?:\d+\s+)?(?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*\.?),\s*
  529: 				 (?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*(?:,\s*[A-Z]{2,})*)\b/gx;
  530: 			my @places = grep { defined && $_ ne '' } @regex_matches;
  531: 			$res = $self->_resolve_scan_candidates(\@places, $region, $CONF_REGEX, $scantext);
  532: 			if (@{$res}) {
  533: 				return wantarray ? @{$res} : $res->[0];
  534: 			}
  535: 
  536: 			# Region-specific structured address patterns
  537: 			if ($region) {
  538: 				my @candidates;
  539: 				if    ($region eq 'GB') { @candidates = _find_gb_addresses($scantext) }
  540: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  541: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }
  542: 
  543: 				if (@candidates) {
  544: 					my @regional;
  545: 					for my $candidate (@candidates) {
  546: 						next if $ignore_words->{lc $candidate};
  547: 						my @hits = grep { defined }
  548: 							$self->{'openaddr'}->geocode("$candidate, $region");
  549: 						push @regional, @hits if @hits;
  550: 					}
  551: 					return @regional if @regional;
  552: 				}
  553: 			}
  554: 
  555: 			$self->{'scantext_misses'}{$scantext} = 1;
  556: 			return;
  557: 		}
  558: 
  559: 		# Standard (non-scantext) lookup path
  560: 		if (wantarray) {
  561: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  562: 			return @rc if @rc && $rc[0];
  563: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  564: 			@rc = $self->{'local'}->geocode(\%params);
  565: 			return @rc if @rc && $rc[0];
  566: 		} else {
  567: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  568: 				return $rc;
  569: 			}
  570: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  571: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  572: 				return $rc;
  573: 			}
  574: 		}
  575: 
  576: 		# Try the alternatives table — hand-curated mappings for locations that
  577: 		# the databases have under slightly different names.
  578: 		# M3 (transitive reduction): every scantext path inside this block returned
  579: 		# early above; at this point $params{'scantext'} is provably falsy, so the
  580: 		# former `if (!$params{'scantext'})` guard was a tautology — removed.
  581: 		if (my $alt = $self->{'alternatives'}) {
  582: 			my $location = $params{'location'};
  583: 			while (my ($key, $value) = each %{$alt}) {
  584: 				next unless $location =~ $key;
  585: 				(my $new_loc = $location) =~ s/$key/$value/;
  586: 				$params{'location'} = $new_loc;
  587: 				if (my $rc = $self->geocode(\%params)) {
  588: 					return $rc;
  589: 				}
  590: 				# Also try the comma-free variant ("Tyne and Wear" etc.)
  591: 				if ($value =~ /, /) {
  592: 					(my $flat = $value) =~ s/,//g;
  593: 					($new_loc = $location) =~ s/$key/$flat/;
  594: 					$params{'location'} = $new_loc;
  595: 					if (my $rc = $self->geocode(\%params)) {
  596: 						return $rc;
  597: 					}
  598: 				}
  599: 				# Restore for the next iteration
  600: 				$params{'location'} = $location;
  601: 			}
  602: 		}
  603: 	}
  604: 
  605: 	# Final fallback: MaxMind for location lookups.
  606: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;
  607: 	# a proper fix would warn here (see LIMITATIONS).
  608: 	# M8 (tautology elimination): both arms of the former wantarray ternary were
  609: 	# identical — collapsed to a single call; context propagates implicitly.
  610: 	if ($params{'location'}) {
  611: 		return $self->{'maxmind'}->geocode(\%params);
  612: 	}
  613: 
  614: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  615: 	return;
  616: }

  618: =head2 provenance
  619: 
  620:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
  621: 
  622: or, in scalar context, the same four as a hashref:
  623: 
  624:     my $provenance = $geocoder->provenance($point);
  625:     print $provenance->{'backend'};
  626: 
  627: Where a result came from and how good it is, so that a caller does not have to
  628: reach for the hash keys itself (section 2.1 of F<BI-Phase6-Dependency-Specs.md>):
  629: 
  630: =over 4
  631: 
  632: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
  633: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
  634: that passed it on, such as C<Geo::Coder::List>.
  635: 
  636: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
  637: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
  638: the distribution's prefix removed, so that the two spellings the backends use -
  639: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
  640: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
  641: consumers that already match on it.
  642: 
  643: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
  644: 
  645: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
  646: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
  647: 
  648: =back
  649: 
  650: Returns an empty list - and an empty hashref in scalar context - when handed
  651: something that is not a result.  A key a result does not carry comes back
  652: C<undef> rather than being guessed at, because a plain hash from another
  653: geocoder has no provenance to report.
  654: 
  655: =cut
  656: 
  657: sub provenance {
  658: 	my ($self, $point) = @_;
  659: 
  660: 	return wantarray ? () : {} unless defined($point) && ref($point)
  661: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
  662: 
  663: 	my $dist    = $point->{'geocoder'};
  664: 	my $backend = $point->{'database'};
  665: 	$backend =~ s/^Geo::Coder::Free::// if defined($backend);
  666: 
  667: 	my %provenance = (
  668: 		dist       => $dist,
  669: 		backend    => $backend,
  670: 		confidence => $point->{'confidence'},
  671: 		accuracy   => $point->{'accuracy'},
  672: 	);
  673: 
  674: 	return wantarray ? @provenance{qw(dist backend confidence accuracy)} : \%provenance;
  675: }

  677: =head2 reverse_geocode
  678: 
  679: =head3 SYNOPSIS
  680: 
  681:     my $loc = $geo->reverse_geocode(latlng => '51.3341,-1.4159');
  682: 
  683: =head3 DESCRIPTION
  684: 
  685: Translates a latitude/longitude pair back to a place name.
  686: B<Partially implemented>: the MaxMind backend does not return meaningful results.
  687: OpenAddresses is attempted first when available.
  688: 
  689: =head3 API SPECIFICATION
  690: 
  691: =head4 input
  692: 
  693:     # Input schema (Params::Validate::Strict) — latlng required
  694:     latlng => { type => 'scalar' }  # "$lat,$long" comma-separated decimal degrees
  695:     # NOTE: separate lat/lon/long keys are NOT supported at the Geo::Coder::Free
  696:     # (facade) level.  When no OpenAddresses backend is configured, passing
  697:     # lat/lon/long instead of latlng will croak "not yet supported".
  698:     # To use separate coordinates call Geo::Coder::Free::Local::reverse_geocode.
  699: 
  700: =head4 output
  701: 
  702:     # Output schema (Return::Set)
  703:     { type => 'object', isa => 'Geo::Location::Point', optional => 1 }
  704: 
  705: =cut
  706: 
  707: sub reverse_geocode {
  708: 	my $self = shift;
  709: 
  710: 	if (!ref($self)) {
  711: 		if (scalar @_) {
  712: 			return __PACKAGE__->new()->reverse_geocode(@_);
  713: 		} elsif (!defined($self)) {
  714: 			Carp::croak(_i18n('usage_reverse', __PACKAGE__));
  715: 		} elsif ($self eq __PACKAGE__) {
  716: 			Carp::croak(_i18n('usage_reverse', $self));
  717: 		}
  718: 		return __PACKAGE__->new()->reverse_geocode($self);
  719: 	} elsif (ref($self) eq 'HASH') {
  720: 		return __PACKAGE__->new()->reverse_geocode($self);
  721: 	}
  722: 
  723: 	my %params = _normalize_args(_i18n('usage_reverse', __PACKAGE__), 'latlng', @_);
  724: 
  725: 	# M8 (tautology — same pattern fixed in geocode): both arms are identical;
  726: 	# context propagates implicitly through return.
  727: 	if ($self->{'openaddr'}) {
  728: 		return $self->{'openaddr'}->reverse_geocode(\%params);
  729: 	}
  730: 	if ($params{'latlng'}) {
  731: 		return $self->{'maxmind'}->reverse_geocode(\%params);
  732: 	}
  733: 
  734: 	Carp::croak(_i18n('reverse_unsupported'));
  735: }

  755: sub run {
  756: 	require Data::Dumper;
  757: 
  758: 	my $class    = shift;
  759: 	my $location = join ' ', @_;
  760: 
  761: 	my @rc = $ENV{'OPENADDR_HOME'}
  762: 		? $class->new(openaddr => $ENV{'OPENADDR_HOME'})->geocode($location)
  763: 		: $class->new()->geocode($location);

  770: # -----------------------------------------------------------------------
  771: # Private helpers
  772: # -----------------------------------------------------------------------
  773: 
  774: # The rule geocode() rejects on - whether a string could be a location at all -
  775: # is defined in Geo::Coder::Free::Validate, and imported above.  It is not
  776: # written out here as well: the backends ask the same question of what a caller
  777: # hands them, so one definition is what keeps valid_location(), the guard that
  778: # croaks and the backends from disagreeing about it.
  779: 
  780: # Purpose:  Return a formatted message string from the message table.
  781: #           Falls back to the raw key so call sites never die on a missing key.
  782: # Entry:    $key — message key; @args — sprintf format arguments.
  783: # Exit:     Formatted string.
  784: sub _i18n {
  785: 	my ($key, @args) = @_;
  786: 	my $fmt = $_MESSAGES{$key} // $key;
  787: 	return @args ? sprintf($fmt, @args) : $fmt;
  788: }
  789: 
  790: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
  791: #             hashref, even-length key-val list, odd-length list, single bare string.
  792: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
  793: #           $bare_key  — hash key to assign to a single bare string argument
  794: #                        ('location' for geocode, 'latlng' for reverse_geocode).
  795: #           @args — raw @_ after $self has been shifted.
  796: # Exit:     Flat key-value %params hash.
  797: # Side Effects: None; croaks on unsupported reference argument.
  798: sub _normalize_args {
  799: 	my ($error_msg, $bare_key, @args) = @_;
  800: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
  801: 	Carp::croak($error_msg)         if ref($args[0]);
  802: 	return @args                    if @args && @args % 2 == 0;
  803: 	return ($bare_key => $args[0])  if @args == 1;
  804: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
  805: 	# The former code silently returned () here, discarding the trailing elements.
  806: 	# Fail fast instead of propagating a malformed argument list downstream.
  807: 	Carp::croak($error_msg)         if @args;
  808: 	return ();
  809: }
  810: 
  811: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
  812: #           annotating every hit with location/text/confidence metadata and
  813: #           memoising misses to avoid re-querying the same failing string.
  814: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
  815: #           $candidates — arrayref of place-name strings to probe.
  816: #           $region     — optional ISO country code appended to each candidate.
  817: #           $confidence — numeric confidence score assigned to all hits.
  818: #           $scantext   — original free text (stored inside each result object).
  819: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
  820: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
  821: sub _resolve_scan_candidates {
  822: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
  823: 	my @results;
  824: 	for my $place (@{$candidates}) {
  825: 		my $location = $region ? "$place, $region" : $place;
  826: 		next if $self->{'scantext_misses'}{$location};
  827: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
  828: 		if (@res) {
  829: 			for my $entry (@res) {
  830: 				$entry->{'location'}   = $location;
  831: 				$entry->{'text'}       = $scantext;
  832: 				$entry->{'confidence'} = $confidence;
  833: 			}
  834: 			push @results, @res;
  835: 		} else {
  836: 			$self->{'scantext_misses'}{$location} = 1;
  837: 		}
  838: 	}
  839: 	return \@results;
  840: }
  841: 
  842: # Purpose:  Slide a window of $n words across $text and return all comma-joined
  843: #           n-grams, excluding pure-numeric tokens and stopwords.
  844: #           Replaces the former _find_word_triplets ($n=3) and
  845: #           _find_word_duplets ($n=2) which were identical except for window size
  846: #           and the duplets version was missing the lc() normalisation on stopwords.
  847: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
  848: # Exit:     Flat list of n-gram strings.
  849: sub _find_word_ngrams {
  850: 	my ($text, $n, $stop) = @_;
  851: 	$text =~ s/,+/ /g;
  852: 	$text =~ s/\s+/ /g;
  853: 	$text =~ s/^\s+|\s+$//g;
  854: 	my @words = grep { !/^\d+$/ && !$stop->{lc $_} } split /\s+/, $text;
  855: 	my @ngrams;
  856: 	for my $i (0 .. $#words - ($n - 1)) {
  857: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
  858: 	}
  859: 	return @ngrams;
  860: }

  862: # Purpose:  Extract structured US street addresses from free text.
  863: # Entry:    $text — arbitrary string.
  864: # Exit:     List of full address strings matching the US pattern.
  865: sub _find_us_addresses {
  866: 	my $text = shift;
  867: 	my @addresses;
  868: 	my $re = qr/
  869: 		\b \d{1,5} \s+                                      # house number
  870: 		(?:[A-Za-z0-9]+(?:\s+[A-Za-z0-9]+){0,6}) \s+       # street name: 1–7 words (bounded)
  871: 		(?:Avenue|Ave\.?|Boulevard|Blvd\.?|Road|Rd\.?|Lane|Ln\.?|Drive|Dr\.?|Street|St\.?)
  872: 		(?:\s+[A-Za-z]{2})? ,\s*
  873: 		(?:[A-Za-z]+(?:\s+[A-Za-z]+){0,3}) ,\s*            # city: 1–4 words
  874: 		[A-Z]{2} \s* (?:\d{5}(?:-\d{4})?)? \b              # state + optional zip
  875: 	/x;
  876: 	while ($text =~ /$re/g) {
  877: 		push @addresses, $&;
  878: 	}
  879: 	return @addresses;
  880: }
  881: 
  882: # Purpose:  Extract British-style addresses from free text.
  883: # Entry:    $text — arbitrary string.
  884: # Exit:     List of trimmed address strings.
  885: sub _find_gb_addresses {
  886: 	my $text = shift;
  887: 	my @addresses;
  888: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
  889: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
  890: 	# possible splits of a long string among 5 overlapping space-containing
  891: 	# groups, causing exponential backtracking.  Making commas mandatory
  892: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
  893: 	# All groups are non-capturing (only $& is used).
  894: 	my $re = qr/
  895: 		\b
  896: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
  897: 		\s+
  898: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
  899: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
  900: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
  901: 		\s*,\s*                                   # COMMA REQUIRED
  902: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
  903: 		\s*,\s*                                   # COMMA REQUIRED
  904: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
  905: 		\b
  906: 	/x;
  907: 	while ($text =~ /$re/g) {
  908: 		(my $addr = $&) =~ s/[,\s]+$//;
  909: 		push @addresses, $addr;
  910: 	}
  911: 	return @addresses;
  912: }

  914: # Purpose:  Extract Canadian street addresses from free text.
  915: # Entry:    $text — arbitrary string.
  916: # Exit:     List of full address strings matching the Canadian pattern.
  917: sub _find_ca_addresses {
  918: 	my $text = shift;
  919: 	my @addresses;
  920: 	my $re = qr/
  921: 		\b \d{1,5} \s+                                         # house number
  922: 		(?:[A-Za-z0-9]+(?:\s+[A-Za-z0-9]+){0,6}) \s+          # street name: 1–7 words (bounded)
  923: 		(?:Avenue|Ave\.?|Boulevard|Blvd\.?|Road|Rd\.?|Lane|Ln\.?|Drive|Dr\.?|Street|St\.?|Circle|Crescent|Cres\.?)
  924: 		\s*,\s*
  925: 		(?:[A-Za-z]+(?:\s+[A-Za-z]+){0,3}) \s*,\s*            # city: 1–4 words
  926: 		[A-Z]{2} \s*,?\s*
  927: 		(?:[A-Z]\d[A-Z]\s?\d[A-Z]\d)? \b                      # optional postal code
  928: 	/x;
  929: 	while ($text =~ /$re/g) {
  930: 		push @addresses, $&;
  931: 	}
  932: 	return @addresses;
  933: }

  937: =head1 GETTING STARTED
  938: 
  939: To download, import and set up the local database:
  940: before running C<make>, but after running C<perl Makefile.PL>, follow these instructions.
  941: 
  942: Optionally set C<OPENADDR_HOME> to point to an empty directory and download the data from
  943: L<http://results.openaddresses.io> into that directory; and
  944: optionally set C<WHOSONFIRST_HOME> to point to an empty directory and download the data using
  945: L<https://github.com/nigelhorne/NJH-Snippets/blob/master/bin/wof-clone>.
  946: The script C<bin/download_databases> (see below) will do those for you.
  947: You do not need to download the MaxMind data — that is downloaded automatically.
  948: 
  949: You will need to create the database used by C<Geo::Coder::Free>.
  950: 
  951: Install L<App::csv2sqlite> and L<https://github.com/nigelhorne/NJH-Snippets>.
  952: Run C<bin/create_sqlite> — this converts the MaxMind "cities" database from CSV to SQLite.
  953: 
  954: To use with MariaDB, set C<MARIADB_SERVER="$hostname;$port"> and
  955: C<MARIADB_USER="$user;$password"> (TODO: username/password should be asked for interactively).
  956: The code will use a database called C<geo_code_free>, which will be dropped and recreated if it exists.
  957: C<$user> needs only DROP, CREATE, SELECT, INSERT, and INDEX privileges on that database.
  958: 
  959: The following optional steps download and install large databases.
  960: This will take a long time and use a lot of disc space.
  961: 
  962: =over 4
  963: 
  964: =item 1
  965: 
  966: C<mkdir $WHOSONFIRST_HOME; cd $WHOSONFIRST_HOME> then run C<wof-clone> from NJH-Snippets.
  967: 
  968: This can take a long time because it contains many nested directories, which filesystem drivers
  969: can be slow to navigate (particularly on EXT4 and ZFS).
  970: 
  971: =item 2
  972: 
  973: Install L<https://github.com/dr5hn/countries-states-cities-database.git> into C<$DR5HN_HOME>.
  974: This data covers cities only, so it is not used when C<OSM_HOME> is set (OSM is far more
  975: comprehensive).  Only Australia, Canada, and the US are imported, as the UK data is difficult
  976: to parse.
  977: 
  978: =item 3
  979: 
  980: Run C<bin/download_databases> — this downloads the Who's On First, OpenAddr, OpenStreetMap,
  981: and dr5hn databases.
  982: OpenStreetMap now uses PBF files, so you will need C<apt install osmium-tool> first.
  983: Check the values of C<OSM_HOME>, C<OPENADDR_HOME>, C<DR5HN_HOME> and C<WHOSONFIRST_HOME>
  984: within that script and adjust them for your setup.
  985: The C<Makefile.PL> file downloads the MaxMind database automatically, as it is not optional.
  986: 
  987: =item 4
  988: 
  989: Run C<bin/create_db> — this creates the database used by C<Geo::Coder::Free> from the data you
  990: have just downloaded.
  991: The database is called C<openaddr.sql> for historical reasons (before Who's On First was added);
  992: it actually contains data from all sources above.
  993: 
  994: =back
  995: 
  996: Now you are ready to run C<make>.
  997: See the comment at the start of C<createdatabase.PL> for further details.

 1040:     GeoCoderFreeState ::= ⟨⟨ maxmind     : MaxMind_Geocoder;

 1042:                               alternatives: Map[STRING → STRING];
 1043:                               cache       : Cache | undef ⟩⟩

 1046:     ∀ p : Params •
 1047:       let oa_path == p.openaddr ∨ env.OPENADDR_HOME •
 1048:       GeoCoderFreeState.openaddr = if oa_path ≠ ∅ then OpenAddresses(oa_path) else undef fi

 1050: =head2 valid_location
 1051: 
 1052:     ValidLocation : Any → BOOLEAN
 1053:     ∀ x : Any •
 1054:       ValidLocation(x) = (x ≠ ∅ ∧ ¬ ref(x) ∧ x ≠ "" ∧ x ∋ non-digit)
 1055: 
 1056: =head2 geocode
 1057: 
 1058:     ErrorMode ::= "croak" | "undef"
 1059: 
 1060:     Geocode : Address × Region? × ErrorMode? → Point?
 1061:     ∀ addr : Address; r : Region?; e : ErrorMode? •
 1062:       let mode == e ∨ "croak" •
 1063:       let backends == (openaddr ≠ undef ⟹ [OpenAddresses, Local, MaxMind])
 1064:                     ∧ (openaddr = undef ⟹ [MaxMind]) •
 1065:       ¬ ValidLocation(addr) ⟹ (mode = "undef" ⟹ result = ∅ | mode = "croak" ⟹ ⊥)
 1066:       ∧ ValidLocation(addr) ⟹
 1067:       result = first { defined } map { b.geocode(addr, r) } backends

 1071:     Provenance : Point? → (DISTRIBUTION?, BACKEND?, CONFIDENCE?, ACCURACY?)
 1072:     ∀ p : Point? •

 1074:                       then ⟨⟨ p.geocoder,
 1075:                               strip("Geo::Coder::Free::", p.database),
 1076:                               p.confidence,
 1077:                               p.accuracy ⟩⟩
 1078:                       else ∅ fi
