   54: =head1 DESCRIPTION
   55: 
   56: C<Geo::Coder::Free> translates addresses into latitude/longitude coordinates
   57: using local SQLite databases built from free data sources - MaxMind/GeoNames,
   58: OpenAddresses, Who's On First, OpenStreetMap, and dr5hn's countries/states/cities
   59: database.  It deliberately avoids paid or rate-limited online geocoding services.
   60: The module is designed to be flexible, supporting both command-line and programmatic usage.
   61: It also includes a sample CGI script for a web-based geocoding service.
   62: 
   63: Geocoding dispatch order depends on whether C<OPENADDR_HOME> (or C<openaddr>) is set:
   64: 
   65: B<With OpenAddresses data:>
   66: 
   67: =over 4
   68: 
   69: =item 1. C<Geo::Coder::Free::OpenAddresses> - requires C<OPENADDR_HOME>
   70: 
   71: =item 2. C<Geo::Coder::Free::Local> - user-curated CSV entries (tried as fallback)
   72: 
   73: =item 3. C<Geo::Coder::Free::MaxMind> - bundled, always available
   74: 
   75: =back
   76: 
   77: B<Without OpenAddresses data:>
   78: 
   79: =over 4
   80: 
   81: =item 1. C<Geo::Coder::Free::MaxMind> only - Local is not consulted.
   82: 
   83: =back
   84: 
   85: The C<cgi-bin> directory contains a simple DIY geo-coding website:
   86: 
   87:     cgi-bin/page.fcgi page=query q=1600+Pennsylvania+Avenue+NW+Washington+DC+USA
   88: 
   89: The sample website is currently down while a new host is sought.
   90: When it returns, you will be able to test it with:
   91:

   95: 
   96: =over 4
   97: 
   98: =item * C<scantext> mode only finds locations in OpenAddresses; it falls back
   99: silently when C<OPENADDR_HOME> is not set (B<FIXME>: should warn).
  100: 
  101: =item * The C<__DATA__> alternatives table is hard-coded; it should live in a
  102: user-editable config file.
  103: 
  104: =item * The address-regex scantext path misses birth-year sentences such as
  105: C<"She was born May 21, 1937 in Noblesville, IN."> because the regex requires
  106: a preceding capital-letter word directly before the city.
  107: 
  108: =item * C<reverse_geocode> is only partially implemented; the MaxMind path does
  109: not return meaningful results.
  110: 
  111: =item * The C<alternatives> map loop uses C<each %{$alt}>, which retains its

  116: before iterating.

  283: =head2 valid_location
  284: 
  285: =head3 SYNOPSIS
  286: 
  287:     if ($geo->valid_location($row->{'place'})) {
  288:         push @found, $geo->geocode(location => $row->{'place'});
  289:     }
  290: 
  291: =head3 DESCRIPTION
  292: 
  293: Answers whether a string is something this module will even try to look up.
  294: It is the public form of the rule C<geocode()> applies before it touches a
  295: backend, so a caller working down a spreadsheet column can skip a row whose
  296: value is a bare number - or is empty - instead of catching the croak that
  297: would otherwise kill the whole run.  That rule is defined once, in
  298: L<Geo::Location::Predicate>, and the backends apply it too: what
  299: C<valid_location()> refuses is refused wherever it is looked up.
  300: 
  301: Only that cheap syntactic test is answered.  A true result means the string is
  302: not disqualified, B<not> that a backend knows it: C<'Ramsgate, Kent'> is valid
  303: and may still find nothing, while C<'0044'> is invalid and is never looked up.
  304: The rule rejects a string of digits only, which is what a numeric column holds
  305: when the wrong column has been read, so anything with a non-digit in it counts
  306: as valid - C<'3.14'> and C<'-'> included.  C<undef>, C<''> and a reference are
  307: not valid.
  308: 
  309: =head3 API SPECIFICATION
  310: 
  311: =head4 input
  312: 
  313:     location => { type => 'scalar', optional => 1 }  # the string to test
  314: 
  315: =head4 output
  316: 
  317:     { type => 'boolean' }  # false for undef, '' and a digit-only string
  318: 
  319: =head3 EXAMPLE
  320: 
  321:     my $geo = Geo::Coder::Free->new();
  322: 
  323:     $geo->valid_location('Ramsgate, Kent');   # true
  324:     $geo->valid_location('0044');             # false - never a location
  325:     $geo->valid_location('');                 # false
  326:     $geo->valid_location(undef);              # false
  327: 
  328: Accepts the three calling conventions the rest of this module does:
  329: 
  330:     $geo->valid_location('0044');
  331:     Geo::Coder::Free->valid_location('0044');
  332:     Geo::Coder::Free::valid_location('0044');
  333:

  354: =head2 geocode
  355: 
  356: =head3 SYNOPSIS
  357: 
  358:     # Standard lookup (returns a Geo::Location::Point or undef)
  359:     my $pt = $geo->geocode(location => 'Ramsgate, Kent, UK');
  360:     printf "lat=%.6f lon=%.6f\n", $pt->lat(), $pt->long();
  361: 
  362:     # Scantext - returns a list of Geo::Location::Point objects
  363:     my @hits = $geo->geocode(
  364:         scantext     => 'She lived in Ramsgate, Kent.',
  365:         region       => 'GB',
  366:         ignore_words => [qw(lived)],
  367:     );
  368: 
  369:     # Invocation flexibility (all equivalent)
  370:     $geo->geocode('Ramsgate, Kent, UK');
  371:     $geo->geocode({ location => 'Ramsgate, Kent, UK' });
  372:     $geo->geocode(location => 'Ramsgate, Kent, UK');
  373: 
  374:     # A batch caller with a dirty column: skip the row, do not kill the run
  375:     for my $place (@column) {
  376:         my $pt = $geo->geocode(location => $place, on_error => 'undef');
  377:         next unless defined $pt;
  378:         push @found, $pt;
  379:     }
  380: 
  381: =head3 DESCRIPTION
  382: 
  383: A location or a scantext that is not a location at all - a bare number, such as
  384: the C<0044> a numeric column holds - is refused before any backend is
  385: touched.  C<valid_location()> answers the same question, so a caller can filter
  386: first; C<on_error> chooses what happens when one gets through anyway:
  387: 
  388: =over 4
  389: 
  390: =item * C<'croak'> (the default) - C<Carp::croak>, the behaviour every existing
  391: caller already has.
  392: 
  393: =item * C<'undef'> - return C<undef>, so one bad row in a spreadsheet column is
  394: skipped rather than ending the run.  It changes the answer for B<only> the two
  395: documented input errors below; an exception from a backend is still an
  396: exception, and a malformed argument list still croaks.
  397: 
  398: =back
  399: 
  400: The option is deliberately narrow, so a batch caller wants C<valid_location()>
  401: with it: that predicate answers false for C<undef> and C<''> as well, which are
  402: the other two things an empty cell holds.  A call with neither a location nor a
  403: scantext is a usage error rather than an input error - the same croak as calling
  404: C<geocode()> with no arguments - and stays a croak on either setting.
  405:

  408: =head4 input
  409: 
  410:     # Input schema (Params::Validate::Strict) - exactly one of location or scantext is required

  412:     scantext     => { type => 'scalar',   optional => 1 }  # free text to scan for place names
  413:     region       => { type => 'scalar',   optional => 1 }  # ISO 3166-1 alpha-2 country code hint
  414:     ignore_words => { type => 'arrayref', optional => 1 }  # words to suppress during scantext scan
  415:     on_error     => { type => 'scalar',   optional => 1 }  # 'croak' (default) or 'undef'

  419:     # Output schema (Return::Set)

  425: Every result carries C<geocoder>, C<database>, C<confidence> and C<accuracy>

  441:     if self is not a blessed object -> delegate to new()->geocode(@args)

  444:     validate: location is not purely numeric; scantext is not purely numeric

  447:         if scantext:

  450:             try 3-word windows (triplets) at confidence 0.8
  451:             try 2-word windows (duplets) at confidence 0.7

  453:             try region-specific address finders (GB / US / CA)

  455:         else:

  457:             try local backend

  459:     try maxmind backend for location lookups
  460:     croak if no scantext and no location

  465: 	my $self = shift;
  466: 
  467: 	# Handle being called as a function rather than a method
  468: 	if (!ref($self)) {

  483: 	# What to do with an input this module rejects before it touches a backend.
  484: 	# 'croak' is the historical behaviour and stays the default, so no existing
  485: 	# caller changes; 'undef' is for a batch caller working down a dirty column,
  486: 	# which wants the row skipped rather than the whole run killed.  Only the two
  487: 	# input errors below consult it: a backend that throws still throws, because
  488: 	# nothing here is wrapped in an eval

  494: 	# The rule is Geo::Location::Predicate's, the same one the backends

  512: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  513: 			my @direct = grep { defined }
  514: 				$self->{'local'}->geocode($scantext),
  515: 				$self->{'openaddr'}->geocode($scantext),
  516: 				$self->{'maxmind'}->geocode($scantext);
  517: 			return @direct if @direct;
  518: 
  519: 			my $region = $params{'region'};
  520: 
  521: 			# Build the effective stopword set.  When the caller supplies no
  522: 			# ignore_words we avoid copying %_COMMON_WORDS (which is immutable
  523: 			# at runtime) by using a reference to it directly.  Only when extra
  524: 			# words are needed do we allocate and populate a merged hash.
  525: 			my $ignore_words;
  526: 			if (my $iw = $params{'ignore_words'}) {
  527: 				my %merged = %_COMMON_WORDS;
  528: 				$merged{lc $_} = 1 for @{$iw};
  529: 				$ignore_words = \%merged;
  530: 			} else {
  531: 				$ignore_words = \%_COMMON_WORDS;
  532: 			}
  533: 
  534: 			# 3-word window search
  535: 			my @triplets = _find_word_ngrams($scantext, 3, $ignore_words);
  536: 			my $res = $self->_resolve_scan_candidates(\@triplets, $region, $CONF_TRIPLET, $scantext);
  537: 			if (@{$res}) {
  538: 				return wantarray ? @{$res} : $res->[0];
  539: 			}
  540: 
  541: 			# 2-word window search
  542: 			my @duplets = _find_word_ngrams($scantext, 2, $ignore_words);
  543: 			$res = $self->_resolve_scan_candidates(\@duplets, $region, $CONF_DUPLET, $scantext);
  544: 			if (@{$res}) {
  545: 				return wantarray ? @{$res} : $res->[0];
  546: 			}
  547: 
  548: 			# Regex-based address pattern — catches "City, ST"-style fragments.
  549: 			# Note: misses sentences like "born May 21, 1937 in Noblesville, IN"
  550: 			# because the pattern requires a capitalised word before the city.
  551: 			my @regex_matches = $scantext =~
  552: 				/\b(?:\d+\s+)?(?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*\.?),\s*
  553: 				 (?:[A-Z][a-z]+(?:\s+[A-Z][a-z]+)*(?:,\s*[A-Z]{2,})*)\b/gx;
  554: 			my @places = grep { defined && $_ ne '' } @regex_matches;
  555: 			$res = $self->_resolve_scan_candidates(\@places, $region, $CONF_REGEX, $scantext);
  556: 			if (@{$res}) {
  557: 				return wantarray ? @{$res} : $res->[0];
  558: 			}
  559: 
  560: 			# Region-specific structured address patterns
  561: 			if ($region) {
  562: 				my @candidates;
  563: 				if    ($region eq 'GB') { @candidates = _find_gb_addresses($scantext) }
  564: 				elsif ($region eq 'US') { @candidates = _find_us_addresses($scantext) }
  565: 				elsif ($region eq 'Canada') { @candidates = _find_ca_addresses($scantext) }
  566: 
  567: 				if (@candidates) {
  568: 					my @regional;
  569: 					for my $candidate (@candidates) {
  570: 						next if $ignore_words->{lc $candidate};
  571: 						my @hits = grep { defined }
  572: 							$self->{'openaddr'}->geocode("$candidate, $region");
  573: 						push @regional, @hits if @hits;
  574: 					}
  575: 					return @regional if @regional;
  576: 				}
  577: 			}
  578: 
  579: 			$self->{'scantext_misses'}{$scantext} = 1;
  580: 			return;
  581: 		}
  582: 
  583: 		# Standard (non-scantext) lookup path
  584: 		if (wantarray) {
  585: 			my @rc = $self->{'openaddr'}->geocode(\%params);
  586: 			return @rc if @rc && $rc[0];
  587: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  588: 			@rc = $self->{'local'}->geocode(\%params);
  589: 			return @rc if @rc && $rc[0];
  590: 		} else {
  591: 			if (my $rc = $self->{'openaddr'}->geocode(\%params)) {
  592: 				return $rc;
  593: 			}
  594: 			$self->{'local'} ||= Geo::Coder::Free::Local->new();
  595: 			if (my $rc = $self->{'local'}->geocode(\%params)) {
  596: 				return $rc;
  597: 			}
  598: 		}
  599: 
  600: 		# Try the alternatives table — hand-curated mappings for locations that
  601: 		# the databases have under slightly different names.
  602: 		# M3 (transitive reduction): every scantext path inside this block returned
  603: 		# early above; at this point $params{'scantext'} is provably falsy, so the
  604: 		# former `if (!$params{'scantext'})` guard was a tautology — removed.
  605: 		if (my $alt = $self->{'alternatives'}) {
  606: 			my $location = $params{'location'};
  607: 			while (my ($key, $value) = each %{$alt}) {
  608: 				next unless $location =~ $key;
  609: 				(my $new_loc = $location) =~ s/$key/$value/;
  610: 				$params{'location'} = $new_loc;
  611: 				if (my $rc = $self->geocode(\%params)) {
  612: 					return $rc;
  613: 				}
  614: 				# Also try the comma-free variant ("Tyne and Wear" etc.)
  615: 				if ($value =~ /, /) {
  616: 					(my $flat = $value) =~ s/,//g;
  617: 					($new_loc = $location) =~ s/$key/$flat/;
  618: 					$params{'location'} = $new_loc;
  619: 					if (my $rc = $self->geocode(\%params)) {
  620: 						return $rc;
  621: 					}
  622: 				}
  623: 				# Restore for the next iteration
  624: 				$params{'location'} = $location;
  625: 			}
  626: 		}
  627: 	}
  628: 
  629: 	# Final fallback: MaxMind for location lookups.
  630: 	# Scantext without OPENADDR_HOME will silently reach here and return undef;
  631: 	# a proper fix would warn here (see LIMITATIONS).
  632: 	# M8 (tautology elimination): both arms of the former wantarray ternary were
  633: 	# identical — collapsed to a single call; context propagates implicitly.
  634: 	if ($params{'location'}) {
  635: 		return $self->{'maxmind'}->geocode(\%params);
  636: 	}
  637: 
  638: 	Carp::croak(_i18n('usage_geocode', __PACKAGE__)) unless $params{'scantext'};
  639: 	return;
  640: }

  642: =head2 geocode_many
  643: 
  644: =head3 SYNOPSIS
  645: 
  646:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  647: 
  648:     for my $place (@places) {
  649:         my $pt = $batch->{$place};              # a Geo::Location::Point, or undef
  650:         next unless defined $pt;
  651:         printf "%s is at %.4f, %.4f\n", $place, $pt->lat(), $pt->long();
  652:     }
  653: 
  654:     printf "geocoded %d of %d places in %d lookups\n",
  655:         $batch->{'resolved'},
  656:         $batch->{'resolved'} + $batch->{'unresolved'},
  657:         $batch->{'lookups'};
  658: 
  659: =head3 DESCRIPTION
  660: 
  661: The loop a batch caller writes around C<geocode()>, run for it: one lookup per
  662: B<distinct> value, with the same options and the same results, plus the counts
  663: that caller would otherwise keep itself - how many values made a backend read,
  664: how many resolved, how many did not, which ones, and which backend read for them
  665: 
  666: The hashref returned holds one entry per distinct value given, keyed by the
  667: value, plus five keys of its own:
  668: 
  669: =over 4
  670: 
  671: =item * C<< $batch->{$value} >> - the C<Geo::Location::Point> the value resolved
  672: to, or C<undef> if nothing did.  Every distinct value in the input is keyed, so
  673: a caller walking a column can look each row up without first asking whether the
  674: batch covered it.  An C<undef> in the input has no key of its own and shares the
  675: entry of the empty string, which is not a location either.
  676: 
  677: =item * C<lookups> - how many distinct values made a backend read to answer
  678: them: one per value, however many backends looked at it.  A value the module
  679: refuses before any backend is touched - a bare number, C<''>, C<undef>, a
  680: reference - is not counted, and neither is a value a backend answered from a
  681: cache or from a hand-curated entry, because nothing was read for it.  This is
  682: what makes the count the work a caller is capping rather than the work it asked
  683: for.  A value repeated in the batch is one lookup.  Every backend reports its
  684: reads through C<reads()>, and a value every backend has already missed is
  685: remembered in L<Geo::Coder::Free::MissCache>, one process-level cache that all
  686: backends and instances share, whose entries expire after an hour and can be
  687: emptied early with L</clear_miss_cache>.  A later batch in the same process is
  688: answered from those caches and so reports the reads it needed, often none, in
  689: place of the ones the first batch made.
  690: 
  691: =item * C<reads> - how many reads each backend made for the batch, keyed by the
  692: name C<provenance()> reports that backend under: C<MaxMind>, C<Local> or
  693: C<OpenAddresses>.  Every backend the object holds is named, at zero for one that
  694: read nothing, so a batch answered from a cache names its backends at zero rather
  695: than naming none.  C<lookups> counts values and this counts reads - a value that
  696: made two backends read is one lookup and a read for each of them, so these
  697: numbers can add up to more than C<lookups> - and the two vocabularies are the
  698: same, so a caller can put the backend that read a value beside the backend a
  699: result came from.
  700: 
  701: =item * C<resolved> - how many distinct values produced a point.
  702: 
  703: =item * C<unresolved> - how many produced nothing, the refused values included.
  704: 
  705: =item * C<unresolved_values> - those values, in the order they were first seen,
  706: so that a caller can record them as tried-and-failed rather than retrying them
  707: on every request.  Section 2.5 sketches this list under the name C<unresolved>;
  708: here C<unresolved> is the count a "geocoded N of M" message needs and the values
  709: themselves are C<unresolved_values>.
  710: 
  711: =back
  712: 
  713: C<resolved> and C<unresolved> always add up to the number of distinct values
  714: given, and the five keys above are reserved: a value equal to one of them is
  715: refused by name, before anything is looked up, rather than allowed to overwrite
  716: a count.
  717: 
  718: C<region> and C<on_error> are handed to every lookup and mean there what they
  719: mean in C<geocode()>, including the rule that a backend exception is still an
  720: exception - nothing here is wrapped in an C<eval>.  C<on_error> defaults to
  721: C<'croak'> for the same reason it does there: a batch should not quietly plot
  722: fewer points than its column holds unless the caller asked it to, and a caller
  723: working down a dirty column asks for C<'undef'>.  The two settings do not differ
  724: in which values are looked up, only in what happens to a value the module
  725: refuses: C<'croak'> dies on it with the message C<geocode()> gives for it,
  726: C<'undef'> counts it unresolved and carries on.
  727: 
  728: A batch of no values is not an error: the counts come back zero.
  729: 
  730: The values are treated as a set.  Repeating a value in the input looks it up
  731: once and every row is keyed to the same point object, so a column that repeats
  732: the same handful of places thousands of times costs the handful of lookups.
  733: 
  734: =head3 API SPECIFICATION
  735: 
  736: =head4 input
  737: 
  738:     # Input schema (Params::Validate::Strict) - values required, options optional
  739:     values   => { type => 'arrayref' }                  # location strings, one per row
  740:     region   => { type => 'scalar', optional => 1 }     # ISO 3166-1 alpha-2 country code hint
  741:     on_error => { type => 'scalar', optional => 1 }     # 'croak' (the default) or 'undef'
  742: 
  743: =head4 output
  744: 
  745:     # Output schema (Return::Set)
  746:     { type => 'hashref' }
  747:     #   $result->{$value}            => { isa => 'Geo::Location::Point', optional => 1 }
  748:     #   $result->{lookups}           => { type => 'integer' }
  749:     #   $result->{reads}             => { type => 'hashref' }
  750:     #   $result->{resolved}          => { type => 'integer' }
  751:     #   $result->{unresolved}        => { type => 'integer' }
  752:     #   $result->{unresolved_values} => { type => 'arrayref' }
  753: 
  754: =head3 MESSAGES
  755: 
  756:     Usage: ...::geocode_many(...)   No values argument, one that is not an arrayref,
  757:                                     or options that are neither a list nor a hashref.
  758:     invalid location to geocode()   A value refused under on_error => 'croak', with the
  759:                                     message geocode() gives for that value.
  760:     on_error must be ...            on_error is neither 'croak' nor 'undef'.
  761:     <value> is one of the keys ...  A value spelled like one of the five returned keys.
  762: 
  763: =head3 EXAMPLE
  764: 
  765:     my $geo = Geo::Coder::Free->new(openaddr => $ENV{OPENADDR_HOME});
  766: 
  767:     # A log file's place column: repeats, a few unreadable values, one empty cell.
  768:     my @places = ('Ramsgate, Kent', '0044', 'Nowhere, Imaginary, ZZ',
  769:                   'Ramsgate, Kent', undef);
  770: 
  771:     my $batch = $geo->geocode_many(\@places, region => 'GB', on_error => 'undef');
  772: 
  773:     printf "geocoded %d of %d distinct places in %d lookups\n",
  774:         $batch->{'resolved'},
  775:         $batch->{'resolved'} + $batch->{'unresolved'},
  776:         $batch->{'lookups'};        # 4 distinct places, 2 of them looked up
  777: 
  778:     # Which backend did the reading, and which answered from a cache: a backend
  779:     # at zero answered nothing by reading.
  780:     while (my ($backend, $reads) = each %{$batch->{'reads'}}) {
  781:         print "$backend read $reads times\n";
  782:     }
  783: 
  784:     for my $place ($batch->{'unresolved_values'}) {
  785:         warn "no coordinates for '" . (defined($place) ? $place : '') . "'\n";
  786:     }

  790: sub geocode_many {
  791: 	my $self = shift;
  792: 
  793: 	# The same calling conventions as the rest of the module, with the batch's
  794: 	# own spelling for the plain-function form: the values are always an
  795: 	# arrayref, so that is what a function call arrives holding.
  796: 	if (!Scalar::Util::blessed($self)) {
  797: 		return __PACKAGE__->new()->geocode_many($self, @_)
  798: 			if ref($self) eq 'ARRAY';
  799: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless @_;
  800: 		return __PACKAGE__->new()->geocode_many(@_);
  801: 	}
  802: 
  803: 	my $values = shift;
  804: 	Carp::croak(_i18n('usage_geocode_many', __PACKAGE__)) unless ref($values) eq 'ARRAY';
  805: 
  806: 	# Options are a hashref or an even list.  A lone scalar is neither: there is
  807: 	# no bare-string form of a batch, so it is refused rather than guessed at.
  808: 	my $opts;
  809: 	if (@_ == 1 && ref($_[0]) eq 'HASH') {
  810: 		$opts = { %{$_[0]} };
  811: 	} elsif ((scalar @_) % 2 == 0 && !grep { ref } @_) {
  812: 		$opts = { @_ };
  813: 	} else {
  814: 		Carp::croak(_i18n('usage_geocode_many', __PACKAGE__));
  815: 	}
  816: 
  817: 	my $on_error = $opts->{'on_error'} // 'croak';
  818: 	Carp::croak(_i18n('invalid_on_error', __PACKAGE__, $on_error))
  819: 		unless $on_error eq 'croak' || $on_error eq 'undef';
  820: 
  821: 	my $region = $opts->{'region'};
  822: 
  823: 	# A value spelled like one of the keys this method answers with would
  824: 	# overwrite it, so it is refused by name - before anything is looked up,
  825: 	# rather than after a count has been lost.
  826: 	my %reserved = map { $_ => 1 } @RESULT_KEYS;
  827: 	for my $value (@{$values}) {
  828: 		my $key = defined($value) ? $value : '';
  829: 		Carp::croak(_i18n('reserved_location', __PACKAGE__, $key)) if $reserved{$key};
  830: 	}
  831: 
  832: 	my %results = map { $_ => 0 } @RESULT_KEYS;
  833: 	$results{'unresolved_values'} = [];
  834: 	$results{'reads'} = {};
  835: 
  836: 	# A batch is a set: a value repeated in the input is looked up once, and
  837: 	# every row holding it is keyed to the same object.
  838: 	my %seen;
  839: 	for my $value (@{$values}) {
  840: 		# undef has no key of its own, and the empty string it shares is not a
  841: 		# location either, so it is unresolved without reaching a backend.
  842: 		my $key = defined($value) ? $value : '';
  843: 		next if $seen{$key}++;
  844: 
  845: 		# What geocode() makes of this value on this setting is asked of
  846: 		# geocode() rather than written out again here: the guard, its message and
  847: 		# the choice of backend are all its own.  The backends' read counters are
  848: 		# taken around the call, so the value is counted as a lookup only if one of
  849: 		# them actually read: a value answered from a cache, or from a hand-curated
  850: 		# entry, is not counted as work the batch did not do.  Taking them per
  851: 		# backend rather than in total says which backend read, and which answered
  852: 		# from somewhere else: a read is added to the name of the backend that made
  853: 		# it, so a value two backends read through is one lookup and a read each.
  854: 		my $reads_before = $self->_backend_reads();
  855: 		my $point = $self->geocode(
  856: 			location => $key,
  857: 			defined($region) ? (region => $region) : (),
  858: 			on_error => $on_error,
  859: 		);
  860: 		my $reads_after = $self->_backend_reads();
  861: 
  862: 		my $read = 0;
  863: 		foreach my $backend (keys %{$reads_after}) {
  864: 			my $reads = $reads_after->{$backend} - ($reads_before->{$backend} // 0);
  865: 			next unless $reads > 0;
  866: 			$results{'reads'}{$backend} += $reads;
  867: 			$read += $reads;
  868: 		}
  869: 
  870: 		# A value the module refuses is not a lookup: it never reached a backend,
  871: 		# so it does not count against the work a caller is capping.
  872: 		$results{'lookups'}++ if _valid_location($key) && $read;
  873: 		$results{$key} = $point;
  874: 
  875: 		if (defined($point)) {
  876: 			$results{'resolved'}++;
  877: 		} else {
  878: 			$results{'unresolved'}++;
  879: 			push @{$results{'unresolved_values'}}, $value;
  880: 		}
  881: 	}
  882: 
  883: 	# A backend that read nothing is reported as well, at zero: what a caller is
  884: 	# asking is which backend read and which answered from a cache, and a backend
  885: 	# left out of the answer cannot be told from one that answered from one.
  886: 	# Local is built the first time a lookup falls through to it, so it appears
  887: 	# once it has been consulted, whether or not it found anything.
  888: 	foreach my $backend (keys %{$self->_backend_reads()}) {
  889: 		$results{'reads'}{$backend} //= 0;
  890: 	}
  891: 
  892: 	return \%results;
  893: }
  894: 
  895: # How much reading each backend has done so far, by the name it is reported
  896: # under.  Counters rather than flags: the change across a call says which
  897: # backend read for that value, and a backend that was never called cannot leave
  898: # a stale flag behind.  A backend object may not exist yet - Local is built on
  899: # first use - and a test may hand the facade a stand-in, so each slot is asked
  900: # only if it holds something that can answer.
  901: sub _backend_reads {
  902: 	my $self = shift;
  903: 
  904: 	my %reads;
  905: 	foreach my $slot (sort keys %_BACKEND_NAMES) {
  906: 		my $backend = $self->{$slot} or next;
  907: 		next unless Scalar::Util::blessed($backend) && $backend->can('reads');
  908: 		$reads{$_BACKEND_NAMES{$slot}} = $backend->reads() // 0;
  909: 	}
  910: 
  911: 	return \%reads;
  912: }

  914: =head2 clear_miss_cache
  915: 
  916:     Geo::Coder::Free->clear_miss_cache();
  917:     $geo->clear_miss_cache();
  918:     Geo::Coder::Free->clear_miss_cache('OpenAddresses');
  919: 
  920: Forgets the lookups that found nothing.  Each backend remembers a miss in
  921: L<Geo::Coder::Free::MissCache>, one process-level cache that every backend and
  922: every instance shares, so an address that is not in the data is searched for
  923: once per process rather than once per call.  Entries expire after an hour; this
  924: method empties them now, for a caller that has rebuilt a database or downloaded
  925: a data set while the process is running.
  926: 
  927: With a scope - C<OpenAddresses>, C<Local> or C<MaxMind> - only that backend's
  928: entries go; C<OpenAddresses> covers every OpenAddresses directory this process
  929: has opened.  A scope that names no backend, such as
  930: C<clear_miss_cache('Nonsense')>, forgets nothing and is not an error.  Returns
  931: true.
  932: 
  933: =head3 API SPECIFICATION
  934: 
  935: =head4 input
  936: 
  937:     scope => { type => 'string', optional => 1 }  # OpenAddresses, Local or MaxMind
  938: 
  939: =head4 output
  940: 
  941:     { type => 'boolean', value => 1 }
  942: 
  943: =cut
  944: 
  945: sub clear_miss_cache {
  946: 	# The invocant is $_[0] and is not needed; anything after it is the scope.
  947: 	Geo::Coder::Free::MissCache->clear(@_ > 1 ? $_[1] : undef);
  948: 
  949: 	return 1;
  950: }

  952: =head2 provenance
  953: 
  954:     my ($dist, $backend, $confidence, $accuracy) = $geocoder->provenance($point);
  955: 
  956: or, in scalar context, the same four as a hashref:
  957: 
  958:     my $provenance = $geocoder->provenance($point);
  959:     print $provenance->{'backend'};
  960: 
  961: Where a result came from and how good it is, so that a caller does not have to
  962: reach for the hash keys itself:
  963: 
  964: =over 4
  965: 
  966: =item * C<$dist> - the distribution that produced the result: the C<geocoder>
  967: key, C<Geo::Coder::Free> for a result from this distribution, or the wrapper
  968: that passed it on, such as C<Geo::Coder::List>.
  969: 
  970: =item * C<$backend> - which backend answered, in a short vocabulary: C<Local>,
  971: C<MaxMind>, C<OpenAddresses> or C<GeoNames>.  This is the C<database> key with
  972: the distribution's prefix removed, so that the two spellings the backends use -
  973: C<Geo::Coder::Free::Local> from C<Local>, and C<MaxMind> from C<MaxMind> - speak
  974: the same vocabulary here.  B<The C<database> key itself is unchanged>, for the
  975: consumers that already match on it.
  976: 
  977: =item * C<$confidence> - how good the match was, 0.0 to 1.0, where 1.0 is exact.
  978: 
  979: =item * C<$accuracy> - how precise the coordinate is: C<address>, C<street>,
  980: C<postcode>, C<locality>, C<city>, C<region> or C<country>.
  981: 
  982: =back
  983: 
  984: Returns an empty list - and an empty hashref in scalar context - when handed
  985: something that is not a result.  A key a result does not carry comes back
  986: C<undef> rather than being guessed at, because a plain hash from another
  987: geocoder has no provenance to report.
  988: 
  989: =head3 API SPECIFICATION
  990: 
  991: =head4 input
  992: 
  993:     point => { type => 'hashref', optional => 1 }  # a result, usually a Geo::Location::Point
  994: 
  995: =head4 output
  996: 
  997:     # list context
  998:     { type => 'array', min => 0, max => 4 }   # dist, backend, confidence, accuracy; or ()
  999: 
 1000:     # scalar context
 1001:     {
 1002:         type   => 'hashref',
 1003:         schema => {
 1004:             dist       => { type => 'string', optional => 1 },
 1005:             backend    => { type => 'string', optional => 1 },
 1006:             confidence => { type => 'number', optional => 1, min => 0, max => 1 },
 1007:             accuracy   => { type => 'string', optional => 1 },
 1008:         },
 1009:     }   # {} when handed something that is not a result
 1010: 
 1011: =cut

 1013: sub provenance {
 1014: 	my ($self, $point) = @_;
 1015: 
 1016: 	return wantarray ? () : {} unless defined($point) && ref($point)
 1017: 		&& ((Scalar::Util::reftype($point) || '') eq 'HASH');
 1018: 
 1019: 	my $dist    = $point->{'geocoder'};
 1020: 	my $backend = $point->{'database'};
 1021: 	$backend =~ s/^Geo::Coder::Free::// if defined($backend);
 1022: 
 1023: 	my %provenance = (
 1024: 		dist       => $dist,
 1025: 		backend    => $backend,
 1026: 		confidence => $point->{'confidence'},
 1027: 		accuracy   => $point->{'accuracy'},
 1028: 	);
 1029: 
 1030: 	return wantarray ? @provenance{qw(dist backend confidence accuracy)} : \%provenance;
 1031: }

 1063: sub reverse_geocode {
 1064: 	my $self = shift;
 1065: 
 1066: 	if (!ref($self)) {
 1067: 		if (scalar @_) {
 1068: 			return __PACKAGE__->new()->reverse_geocode(@_);
 1069: 		} elsif (!defined($self)) {
 1070: 			Carp::croak(_i18n('usage_reverse', __PACKAGE__));
 1071: 		} elsif ($self eq __PACKAGE__) {
 1072: 			Carp::croak(_i18n('usage_reverse', $self));
 1073: 		}
 1074: 		return __PACKAGE__->new()->reverse_geocode($self);

 1077: 	}

 1079: 	my %params = _normalize_args(_i18n('usage_reverse', __PACKAGE__), 'latlng', @_);

 1082: 	# context propagates implicitly through return.

 1088: 	}

 1090: 	Carp::croak(_i18n('reverse_unsupported'));

 1130: # The rule geocode() rejects on - whether a string could be a location at all -
 1131: # is defined in Geo::Location::Predicate, and imported above.  It is not
 1132: # written out here as well: the backends ask the same question of what a caller
 1133: # hands them, so one definition is what keeps valid_location(), the guard that
 1134: # croaks and the backends from disagreeing about it.
 1135: 
 1136: # Purpose:  Return a formatted message string from the message table.
 1137: #           Falls back to the raw key so call sites never die on a missing key.
 1138: # Entry:    $key — message key; @args — sprintf format arguments.
 1139: # Exit:     Formatted string.
 1140: sub _i18n {
 1141: 	my ($key, @args) = @_;
 1142: 	my $fmt = $_MESSAGES{$key} // $key;
 1143: 	return @args ? sprintf($fmt, @args) : $fmt;
 1144: }

 1146: # Purpose:  Normalise the four calling conventions accepted by geocode/reverse_geocode:
 1147: #             hashref, even-length key-val list, odd-length list, single bare string.
 1148: # Entry:    $error_msg — message to croak if a non-hash reference is passed.
 1149: #           $bare_key  — hash key to assign to a single bare string argument
 1150: #                        ('location' for geocode, 'latlng' for reverse_geocode).
 1151: #           @args — raw @_ after $self has been shifted.
 1152: # Exit:     Flat key-value %params hash.
 1153: # Side Effects: None; croaks on unsupported reference argument.
 1154: sub _normalize_args {
 1155: 	my ($error_msg, $bare_key, @args) = @_;
 1156: 	return %{$args[0]}              if ref($args[0]) eq 'HASH';
 1157: 	Carp::croak($error_msg)         if ref($args[0]);
 1158: 	return @args                    if @args && @args % 2 == 0;
 1159: 	return ($bare_key => $args[0])  if @args == 1;
 1160: 	# M7 (logic-gap closure): odd-count > 1 is not a valid calling convention.
 1161: 	# The former code silently returned () here, discarding the trailing elements.
 1162: 	# Fail fast instead of propagating a malformed argument list downstream.
 1163: 	Carp::croak($error_msg)         if @args;
 1164: 	return ();
 1165: }

 1167: # Purpose:  Try to geocode each candidate place string via the openaddr backend,
 1168: #           annotating every hit with location/text/confidence metadata and
 1169: #           memoising misses to avoid re-querying the same failing string.
 1170: # Entry:    $self       — geocoder instance with {openaddr} and {scantext_misses}.
 1171: #           $candidates — arrayref of place-name strings to probe.
 1172: #           $region     — optional ISO country code appended to each candidate.
 1173: #           $confidence — numeric confidence score assigned to all hits.
 1174: #           $scantext   — original free text (stored inside each result object).
 1175: # Exit:     Arrayref of Geo::Location::Point objects; empty arrayref on no hits.
 1176: # Side Effects: Populates $self->{scantext_misses} for every non-matching place.
 1177: sub _resolve_scan_candidates {
 1178: 	my ($self, $candidates, $region, $confidence, $scantext) = @_;
 1179: 	my @results;
 1180: 	for my $place (@{$candidates}) {
 1181: 		my $location = $region ? "$place, $region" : $place;
 1182: 		next if $self->{'scantext_misses'}{$location};
 1183: 		my @res = grep { defined } $self->{'openaddr'}->geocode($location);
 1184: 		if (@res) {
 1185: 			for my $entry (@res) {
 1186: 				$entry->{'location'}   = $location;
 1187: 				$entry->{'text'}       = $scantext;
 1188: 				$entry->{'confidence'} = $confidence;
 1189: 			}
 1190: 			push @results, @res;
 1191: 		} else {
 1192: 			$self->{'scantext_misses'}{$location} = 1;
 1193: 		}
 1194: 	}
 1195: 	return \@results;
 1196: }

 1198: # Purpose:  Slide a window of $n words across $text and return all comma-joined
 1199: #           n-grams, excluding pure-numeric tokens and stopwords.  A token of
 1200: #           digits only is not a word of a place name, which is the question
 1201: #           Geo::Location::Predicate::_valid_location() answers, so it is asked
 1202: #           there rather than spelled out here (t/location-rule.t fails if the
 1203: #           rule is written out again).
 1204: #           Replaces the former _find_word_triplets ($n=3) and
 1205: #           _find_word_duplets ($n=2) which were identical except for window size
 1206: #           and the duplets version was missing the lc() normalisation on stopwords.
 1207: # Entry:    $text — raw string; $n — window size; $stop — stopword hashref.
 1208: # Exit:     Flat list of n-gram strings.
 1209: sub _find_word_ngrams {
 1210: 	my ($text, $n, $stop) = @_;
 1211: 	$text =~ s/,+/ /g;
 1212: 	$text =~ s/\s+/ /g;
 1213: 	$text =~ s/^\s+|\s+$//g;
 1214: 	my @words = grep { !$stop->{lc $_} && _valid_location($_) } split /\s+/, $text;
 1215: 	my @ngrams;
 1216: 	for my $i (0 .. $#words - ($n - 1)) {
 1217: 		push @ngrams, join ', ', @words[$i .. $i + $n - 1];
 1218: 	}
 1219: 	return @ngrams;
 1220: }

 1242: # Purpose:  Extract British-style addresses from free text.
 1243: # Entry:    $text — arbitrary string.
 1244: # Exit:     List of trimmed address strings.
 1245: sub _find_gb_addresses {
 1246: 	my $text = shift;
 1247: 	my @addresses;
 1248: 	# ReDoS fix: the former pattern used \s*,?\s* between all parts and
 1249: 	# [A-Za-z\s'-]+ groups — with commas optional, the engine must try all
 1250: 	# possible splits of a long string among 5 overlapping space-containing
 1251: 	# groups, causing exponential backtracking.  Making commas mandatory
 1252: 	# eliminates the ambiguity entirely: UK postal addresses always have commas.
 1253: 	# All groups are non-capturing (only $& is used).
 1254: 	my $re = qr/
 1255: 		\b
 1256: 		(?:\d{1,5} | [\w'-]+)                   # house number or single-word name
 1257: 		\s+
 1258: 		(?:[\w'-]+(?:\s+[\w'-]+){0,5})           # street name (up to 6 words)
 1259: 		\s*,\s*                                   # COMMA REQUIRED — kills the ambiguity
 1260: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # town (up to 4 words)
 1261: 		\s*,\s*                                   # COMMA REQUIRED
 1262: 		(?:[\w'-]+(?:\s+[\w'-]+){0,3})           # county (up to 4 words)
 1263: 		\s*,\s*                                   # COMMA REQUIRED
 1264: 		(?:[\w'-]+(?:\s+[\w'-]+){0,2})           # country (up to 3 words)
 1265: 		\b
 1266: 	/x;
 1267: 	while ($text =~ /$re/g) {
 1268: 		(my $addr = $&) =~ s/[,\s]+$//;
 1269: 		push @addresses, $addr;
 1270: 	}
 1271: 	return @addresses;
 1272: }
