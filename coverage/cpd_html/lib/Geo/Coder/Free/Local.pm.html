   38: =head1 SYNOPSIS
   39: 
   40:     use Geo::Coder::Free::Local;
   41: 
   42:     my $geocoder = Geo::Coder::Free::Local->new();
   43:     my $location = $geocoder->geocode(location => 'Ramsgate, Kent, UK');
   44:     printf "lat=%.6f lon=%.6f\n", $location->lat(), $location->long();
   45: 
   46: =head1 DESCRIPTION
   47: 
   48: Provides geocoding via a user-curated CSV dataset embedded in the module's
   49: C<__DATA__> section.  Locations in the data were verified by GPS and by
   50: inspecting geotagged photographs.  The data is read once at construction time
   51: and indexed for fast lookup.
   52: 
   53: This is the highest-priority backend tried by C<Geo::Coder::Free>.
   54: 
   55: =head1 LIMITATIONS
   56: 
   57: =over 4
   58: 
   59: =item * The embedded C<__DATA__> dataset covers only a small set of hand-picked locations.
   60: There is no mechanism for non-authors to contribute data without patching the module.
   61: 
   62: =item * Canadian and Australian address parsing is not yet implemented; those queries return C<undef>.
   63: 
   64: =item * C<_search> performs an O(n) linear scan through all rows.  The hash-based
   65: index in C<new()> handles exact string matches; no index exists for partial field matches.
   66: 
   67: =item * C<our %alternatives> duplicates mappings in C<Geo::Coder::Free::__DATA__>.
   68: Both should be consolidated into a shared external config file.
   69: 
   70: =item * C<$libpostal_is_installed> is a module-level (effectively global) flag.
   71: Not thread-safe in a forking or threaded Perl deployment.
   72: 
   73: =item * The C<__DATA__> filehandle is a one-shot resource.  The first call to
   74: C<new()> exhausts it with C<my @data = E<lt>DATAE<gt>>; every subsequent
   75: C<new()> in the same process reads zero rows and builds an empty index.
   76: Construct exactly one C<Local> object per process and share it.
   77: 
   78: =item * The hash-index key is C<lc(Geo::Location::Point-E<gt>new($row)-E<gt>as_string())>,
   79: which B<includes the C<name> field>.  To get a direct index hit the caller must
   80: supply the full string with the venue/place name as the leading component;
   81: an address that omits the name falls through to the slower O(n) C<_search> path.
   82: 
   83: =back
   84: 
   85: =cut

  125: =head3 DESCRIPTION
  126: 
  127: Constructor.  Reads the C<__DATA__> CSV block, builds a hash-based lookup
  128: index, and derives the geographic centre of any city/state/country cluster
  129: containing three or more data points.
  130: 
  131: B<One-shot filehandle>: the C<DATA> handle is consumed on the first call to
  132: C<new()>.  Any subsequent call to C<new()> returns an object whose dataset and
  133: index are both empty.  In code that constructs multiple C<Local> objects (e.g.
  134: in tests) construct B<exactly one> instance and reuse it across all callers.
  135: 
  136: =head3 API SPECIFICATION
  137: 
  138: =head4 input
  139: 
  140:     # Input schema (Params::Validate::Strict)
  141:     cache => { type => 'object', optional => 1, can => ['get', 'set'] }  # CHI-compatible cache object
  142: 
  143: =head4 output
  144: 
  145:     # Output schema (Return::Set)
  146:     { type => 'object', isa => 'Geo::Coder::Free::Local' }

  148: =head3 FORMAL SPECIFICATION
  149: 
  150:     LocalState ::= ⟨⟨ data  : seq Row;
  151:                        index : Map[STRING → Row];

  270: 
  271: =head3 SYNOPSIS
  272: 
  273:     my $pt = $geocoder->geocode(location => '203 E Chatsworth Rd, Reisterstown, Baltimore, MD, US');
  274:     print $pt->lat(), "\n";
  275: 
  276:     # All calling forms are accepted:
  277:     $geocoder->geocode('203 E Chatsworth Rd, Reisterstown, MD, US');
  278:     $geocoder->geocode({ location => '203 E Chatsworth Rd, Reisterstown, MD, US' });
  279: 
  280: =head3 API SPECIFICATION
  281: 
  282: =head4 input
  283: 
  284:     # Input schema (Params::Validate::Strict)
  285:     location => { type => 'scalar' }  # address string; must contain at least two commas
  286: 
  287: The domain of C<location>:
  288: 
  289: =over 4
  290: 
  291: =item * A whole row of the data matches in any case, and C<USA> is the same as
  292: C<US>.
  293: 
  294: =item * Fewer than two commas, or two commas with nothing between them
  295: (C<'Road,,GB'>), finds nothing and searches nothing.  Two commas with one
  296: character between them (C<'Road, ,GB'>) is enough to go on to the search.
  297: 
  298: =item * Any characters are accepted, and an address that isn't found is remembered
  299: as a miss.  Undecoded bytes are a different key from the characters they encode.
  300: 
  301: =item * C<undef>, C<''> and C<'0'>, an empty hashref or no arguments croak
  302: C<Usage: geocode(location =E<gt> $location)>.  A reference other than a hashref, or an
  303: odd list longer than one, croaks C<Usage: ...::geocode(...)>.
  304: 
  305: =back
  306: 
  307: =head4 output
  308: 
  309:     # Output schema (Return::Set)
  310:     { type => 'object', isa => 'Geo::Location::Point', optional => 1 }
  311: 
  312: =head3 PROVENANCE
  313: 
  314: Every result carries C<geocoder>, C<database>, C<confidence> and C<accuracy>
  315: (section 2.1 of F<BI-Phase6-Dependency-Specs.md>).  This backend reports
  316: C<database> as C<Geo::Coder::Free::Local>, and C<accuracy> is what the matched
  317: columns justify: a house number makes it an C<address>, a road a C<street>, a
  318: name or city a C<locality>, a state a C<region> and a country a C<country>.  A
  319: lookup answered from the index, which matches a whole row, is an exact match
  320: (C<confidence> of 1.0) whose accuracy comes from the row's own fields - so a
  321: derived geographic centre, which carries a city, state and country and nothing
  322: narrower, is a C<locality>.
  323: 
  324: =head3 MESSAGES
  325: 
  326:     Usage: ...::geocode(...)   No location argument given.
  327: 
  328: =head3 FORMAL SPECIFICATION
  329: 
  330:     Geocode : STRING → Point?
  331:     ∀ addr : STRING •
  332:       let norm == lc(replace_usa(addr)) •
  333:       (norm ∈ cache ⟹ result = cache[norm]) ∧
  334:       (norm ∈ index ⟹ result = index[norm]) ∧
  335:       (¬ result ⟹ result = parse_and_search(addr))
  336: 
  337: =head3 PSEUDOCODE
  338: 
  339:     normalise @_ into %params
  340:     reject if location does not contain two or more commas (not a full address)
  341:     check cache; return hit
  342:     check hash index; return hit and cache it
  343:     # index key includes the 'name' field; supply the venue/place name as the
  344:     # leading address component to guarantee an index hit
  345:     attempt country-specific parser (US, GB; skip CA/AU pending implementation)
  346:     attempt Geo::StreetAddress::US for "..., USA" addresses
  347:     attempt Geo::Address::Parser
  348:     attempt Geo::libpostal (large memory footprint; loaded lazily)
  349:     attempt 4-part regex decomposition (name/road/city/state/country)
  350:     attempt %alternatives mapping
  351:     return undef
  352: 
  353: =cut

  359: 	local $@;

  361: 	# Handle being called as a function rather than a method
  362: 	if (!ref($self)) {
  363: 		if (scalar @_) {
  364: 			return __PACKAGE__->new()->geocode(@_);

  366: 			Carp::croak('Usage: ', __PACKAGE__, '::geocode(location => $location)');

  368: 			Carp::croak("Usage: $self", '::geocode(location => $location)');
  369: 		}
  370: 		return __PACKAGE__->new()->geocode($self);
  371: 	} elsif (ref($self) eq 'HASH') {
  372: 		return __PACKAGE__->new()->geocode($self);
  373: 	}
  374: 
  375: 	my %params = _normalize_args(
  376: 		'Usage: ' . __PACKAGE__ . '::geocode(location => $location)',
  377: 		'location', @_
  378: 	);
  379: 
  380: 	my $location = $params{'location'}
  381: 		or Carp::croak('Usage: geocode(location => $location)');
  382: 
  383: 	# Normalise the lookup key - "USA" is treated the same as "US"
  384: 	my $lc = lc($location);
  385: 	$lc =~ s/,\s*usa$/, us/i;

  387: 	return $self->{'cache'}{$lc}  if exists $self->{'cache'}{$lc};

  404: 	} elsif ($location =~ /(England|Scotland|Wales|Northern Ireland|UK|GB)$/i) {
  405: 		$ap = $self->{'ap'}{'gb'} //= Lingua::EN::AddressParse->new(
  406: 			country => 'GB', auto_clean => 1, force_case => 1, force_post_code => 0

  411: 	} elsif ($location =~ /Australia$/) {
  412: 		# TODO: Australian address parsing not yet implemented
  413: 		return $self->_remember_miss($lc);
  414: 	}

  442: 					$addr{'state'}   = _to_two_letter_state('Canada', $c{'subcountry'});

  444: 					$addr{'country'} = 'US';
  445: 					$addr{'state'}   = _to_two_letter_state('US', $c{'subcountry'});
  446: 				} elsif ($country_raw) {
  447: 					$addr{'country'} = $country_raw;
  448: 					$addr{'state'}   = $c{'subcountry'} if $c{'subcountry'};
  449: 				}
  450: 			}
  451: 			$addr{'number'} = $c{'property_identifier'};
  452: 			$addr{'city'}   = $c{'suburb'};

  454: 			if (my $rc = $self->_search(\%addr, qw(number road city state country))) {
  455: 				return $self->_cache_and_return($lc, $rc);
  456: 			}
  457: 			if ($addr{'number'}) {
  458: 				if (my $rc = $self->_search(\%addr, qw(road city state country))) {
  459: 					return $self->_cache_and_return($lc, $rc);
  460: 				}
  461: 			}
  462:

  464: 			# saves traversing the full dataset for every remaining strategy.

  473: 			# Minor: if target pair is absent, no _search call can match.
  474: 			# Conclusion: early return is equivalent and faster.

  477: 		}

  697: =head2 reverse_geocode
  698: 
  699: =head3 SYNOPSIS
  700: 
  701:     my $loc = $geocoder->reverse_geocode(latlng => '51.3341,-1.4159');
  702:     # Returns the location string(s) for that lat/lon pair.
  703: 
  704: =head3 API SPECIFICATION
  705: 
  706: =head4 input
  707: 
  708:     # Input schema (Params::Validate::Strict) - latlng or lat+lon required
  709:     latlng => { type => 'scalar', optional => 1 }  # "$lat,$long" comma-separated decimal degrees
  710:     lat    => { type => 'scalar', optional => 1 }  # latitude  (alternative to latlng)
  711:     lon    => { type => 'scalar', optional => 1 }  # longitude (alternative to latlng)
  712:     long   => { type => 'scalar', optional => 1 }  # alias for lon
  713: 
  714: The domain of the coordinates:
  715: 
  716: =over 4
  717: 
  718: =item * Each is compared to the data at four significant figures, not four decimal
  719: places: C<39.4749> and C<39.47> both match a row at C<39.46727>, and C<39.4751>
  720: does not.
  721: 
  722: =item * No range check applies.  C<'0,0'> and C<'91,181'> find nothing and are
  723: not errors.  A third part is dropped.
  724: 
  725: =item * Each must be an optional minus, ASCII digits, then an optional point and more
  726: digits, as in L<Geo::Coder::Free::MaxMind/reverse_geocode>.  Anything else croaks
  727: C<Invalid coordinate value for reverse_geocode>.
  728: 
  729: =item * C<latlng> is used when it is true.  No arguments, C<''> or C<'0'>, one part
  730: with no comma, or only one of C<lat> and C<lon>, croak C<Usage:>.  So do a reference
  731: other than a hashref and an odd list longer than one.
  732: 
  733: =item * Nothing found is C<0> in scalar context and an empty list in list context.
  734: 
  735: =back
  736: 
  737: =head4 output
  738: 
  739:     # Output schema (Return::Set)
  740:     # scalar context: { type => 'scalar',   optional => 1 }  # location string
  741:     # list context:   { type => 'arrayref', of => { type => 'scalar' } }
  742: 
  743: =cut

  745: sub reverse_geocode {
  746: 	my $self = shift;
  747: 
  748: 	if (!ref($self)) {
  749: 		if (scalar @_) {
  750: 			return __PACKAGE__->new()->reverse_geocode(@_);
  751: 		} elsif (!defined($self)) {
  752: 			Carp::croak('Usage: ', __PACKAGE__, '::reverse_geocode(latlng => "$lat,$long")');
  753: 		} elsif ($self eq __PACKAGE__) {
  754: 			Carp::croak("Usage: $self", '::reverse_geocode(latlng => "$lat,$long")');
  755: 		}
  756: 		return __PACKAGE__->new()->reverse_geocode($self);
  757: 	} elsif (ref($self) eq 'HASH') {
  758: 		return __PACKAGE__->new()->reverse_geocode($self);
  759: 	}
  760: 
  761: 	my %params = _normalize_args(
  762: 		'Usage: ' . __PACKAGE__ . '::reverse_geocode(latlng => "$lat,$long")',
  763: 		'latlng', @_
  764: 	);
  765: 
  766: 	my ($latitude, $longitude);
  767: 	if (my $latlng = $params{'latlng'}) {
  768: 		($latitude, $longitude) = split /,/, $latlng;
  769: 	} else {
  770: 		$latitude  = $params{'lat'};
  771: 		$longitude = $params{'lon'} // $params{'long'};
  772: 	}
  773: 
  774: 	if (!defined($latitude) || !defined($longitude)) {
  775: 		Carp::croak('Usage: ', __PACKAGE__, '::reverse_geocode(latlng => "$lat,$long")');
  776: 	}
  777: 
  778: 	# The same test MaxMind::reverse_geocode applies, so the backends agree
  779: 	for my $c ($latitude, $longitude) {
  780: 		Carp::croak('Invalid coordinate value for reverse_geocode')
  781: 			unless $c =~ /\A-?[0-9]+\.?[0-9]*\z/;
  782: 	}
  783: 
  784: 	my @rc;
  785: 	for my $row (@{$self->{'data'}}) {
  786: 		next unless defined($row->{'latitude'}) && defined($row->{'longitude'});
  787: 		next unless _equal($row->{'latitude'}, $latitude, 4)
  788: 		         && _equal($row->{'longitude'}, $longitude, 4);
  789: 
  790: 		# Rows in $self->{'data'} are blessed as Geo::Location::Point by
  791: 		# the index-building loop in new() - calling as_string() is safe here.
  792: 		my $location = uc($row->as_string());
  793: 		if (wantarray) {
  794: 			push @rc, $location;
  795: 			# Add any reverse-alternative mappings for this location
  796: 			# keys, not each(): %alternatives is package-wide, and an each()
  797: 			# iterator left part-way would make the next pass skip entries
  798: 			foreach my $left (sort keys %alternatives) {
  799: 				my $right = $alternatives{$left};
  800: 				if ($location =~ $right) {
  801: 					(my $l = $location) =~ s/$right/$left/;
  802: 					push @rc, $l;
  803: 				}
  804: 			}
  805: 		} else {
  806: 			return $location;
  807: 		}
  808: 	}
  809: 	return @rc;
  810: }

  890: # Purpose:  Match parsed address components against all data rows.
  891: #           Each named column must match (case-insensitively) the corresponding
  892: #           data field; a minimum of 3 columns must match for a result.
  893: # Entry:    $self, $data - hashref of address components,
  894: #           @columns - ordered list of keys to compare.

  897: sub _search {
  898: 	my ($self, $data, @columns) = @_;
  899: 
  900: 	$self->{'reads'}++;
  901: 
  902: 	# M5 (boolean reduction): the $failed flag was set-and-break in the inner loop
  903: 	# then tested in the outer loop - eliminated by using a labeled 'next ROW'
  904: 	# that short-circuits directly, removing one boolean gate per iteration.
  905: 	ROW: for my $row (@{$self->{'data'}}) {
  906: 		my $matched = 0;
  907: 		my @matched_columns;
  908: 
  909: 		for my $column (@columns) {
  910: 			if (defined($data->{$column})) {
  911: 				next ROW unless defined($row->{$column});
  912: 				next ROW if uc($row->{$column}) ne uc($data->{$column});
  913: 				$matched++;
  914: 				# The accuracy is reported from the columns that matched, not
  915: 				# every column this call site offered: a caller trying
  916: 				# 'number road city...' for a town that has no road must not have
  917: 				# its match described as an address.
  918: 				push @matched_columns, $column;
  919: 			} elsif (exists $data->{$column}) {
  920: 				delete $data->{$column};
  921: 			}
  922: 		}
  923: 
  924: 		next if $matched < 3;
  925: 
  926: 		# Assign confidence based on how many columns contributed to the match
  927: 		my $confidence = $matched == scalar(@columns) ? $CONF_EXACT
  928: 		               : $matched >= 4                ? $CONF_HIGH
  929: 		               :                               $CONF_MEDIUM;
  930: 
  931: 		# Provenance (Phase 6 dependency specs section 2.1).  Set after %{$row}
  932: 		# so that a dataset column that happens to be called accuracy cannot stand
  933: 		# in for the match this code actually made.
  934: 		return Geo::Location::Point->new(
  935: 			location   => $data->{'location'},
  936: 			confidence => $confidence,
  937: 			database   => __PACKAGE__,
  938: 			%{$row},
  939: 			geocoder   => GEOCODER,
  940: 			accuracy   => Geo::Location::Point::accuracy_for(@matched_columns),
  941: 		);
  942: 	}
  943: 	return;
  944: }

  986: 		next unless $row->{'longitude'} =~ /^-?\d+\.?\d*$/;
  987: 		my $key = join '|',
  988: 			$row->{'city'}    // '',
  989: 			$row->{'state'}   // '',
  990: 			$row->{'country'} // '';
  991: 		push @{$groups{$key}}, $row;
  992: 	}
  993: 
  994: 	my @centres;
  995: 	for my $key (keys %groups) {
  996: 		my $locs = $groups{$key};
  997: 		next if @{$locs} < 3;
  998: 
  999: 		my ($city, $state, $country) = split /\|/, $key;
 1000: 		my ($lat, $lon) = _calculate_centre($locs);
 1001: 
 1002: 		push @centres, {
 1003: 			city      => $city,
 1004: 			state     => $state,
 1005: 			country   => $country,
 1006: 			lat       => $lat,
 1007: 			latitude  => $lat,
 1008: 			longitude => $lon,
 1009: 			long      => $lon,
 1010: 			lng       => $lon,
 1011: 		};
 1012: 	}
 1013: 
 1014: 	return @centres ? \@centres : undef;
 1015: }
 1016: 
 1017: # Purpose:  Compute the arithmetic mean of latitude and longitude for a group
 1018: #           of locations.  Accurate for small geographic areas; for large areas
 1019: #           or locations crossing the antimeridian, a vector-mean is needed.
 1020: # Entry:    $locs - arrayref of hashrefs each with 'latitude' and 'longitude'.
 1021: # Exit:     ($centre_lat, $centre_lon) as decimal degree strings to 6dp.
 1022: # Side Effects: None.
 1023: sub _calculate_centre {
 1024: 	my $locs  = $_[0];
 1025: 	my ($sum_lat, $sum_lon) = (0, 0);
 1026: 	$sum_lat += $_->{'latitude'}, $sum_lon += $_->{'longitude'} for @{$locs};
 1027: 	my $n = scalar @{$locs};
 1028: 	return (sprintf('%.6f', $sum_lat / $n), sprintf('%.6f', $sum_lon / $n));
 1029: }
 1030: 
 1031: # https://www.oreilly.com/library/view/perl-cookbook/1565922433/ch02s03.html
 1032: # Equal within $dp decimal places - avoids floating-point equality pitfalls.
 1033: sub _equal {
 1034: 	my ($A, $B, $dp) = @_;
 1035: 	return sprintf("%.${dp}g", $A) eq sprintf("%.${dp}g", $B);
 1036: }
